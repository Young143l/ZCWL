# 第五章 CSS盒模型与布局

## 5.1 CSS盒模型

### 5.1.1 盒模型概述

CSS盒模型是Web布局的基础。每个HTML元素都被视为一个矩形盒子，这个盒子由内容区域、内边距、边框和外边距组成。

盒模型的组成部分：

- **Content（内容）**：元素的实际内容区域，显示文本、图像等
- **Padding（内边距）**：内容与边框之间的空间
- **Border（边框）**：包围内边距和内容的外框
- **Margin（外边距）**：边框外部的空间，控制元素之间的距离

### 5.1.2 标准盒模型与替代盒模型

**标准盒模型（content-box）**

在标准盒模型中，`width`和`height`只包括内容区域：

```css
.box {
    box-sizing: content-box; /* 默认值 */
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
}
/* 实际占用宽度 = 300 + 20*2 + 5*2 + 10*2 = 370px */
```

**替代盒模型（border-box）**

在替代盒模型中，`width`和`height`包括内容、内边距和边框：

```css
.box {
    box-sizing: border-box;
    width: 300px;
    padding: 20px;
    border: 5px solid black;
    margin: 10px;
}
/* 实际占用宽度 = 300px + 10*2 = 320px */
/* 内容宽度 = 300 - 20*2 - 5*2 = 250px */
```

**全局设置替代盒模型**

推荐在所有项目中使用替代盒模型：

```css
*,
*::before,
*::after {
    box-sizing: border-box;
}
```

### 5.1.3 内容区域

内容区域是元素显示实际内容的部分：

```css
.content-box {
    width: 500px;      /* 内容宽度 */
    height: 300px;     /* 内容高度 */
    min-width: 200px;  /* 最小宽度 */
    max-width: 800px;  /* 最大宽度 */
    min-height: 100px; /* 最小高度 */
    max-height: 600px; /* 最大高度 */
}
```

### 5.1.4 内边距

内边距是内容与边框之间的空间：

```css
/* 统一设置 */
.box {
    padding: 20px; /* 四边均为20px */
}

/* 分别设置 */
.box {
    padding-top: 10px;
    padding-right: 20px;
    padding-bottom: 10px;
    padding-left: 20px;
}

/* 简写形式 */
.box {
    padding: 10px 20px; /* 上下 左右 */
}

.box {
    padding: 10px 20px 15px; /* 上 左右 下 */
}

.box {
    padding: 10px 20px 15px 25px; /* 上 右 下 左（顺时针） */
}
```

### 5.1.5 边框

边框是包围内容和内边距的线：

```css
/* 边框简写 */
.box {
    border: 2px solid #333; /* 宽度 样式 颜色 */
}

/* 分别设置 */
.box {
    border-width: 2px;
    border-style: solid;
    border-color: #333;
}

/* 单边边框 */
.box {
    border-top: 2px solid red;
    border-right: 1px dashed blue;
    border-bottom: 2px solid red;
    border-left: 1px dashed blue;
}

/* 圆角边框 */
.box {
    border-radius: 10px; /* 统一圆角 */
    border-radius: 10px 20px; /* 左上右下 右上左下 */
    border-radius: 10px 20px 30px 40px; /* 左上 右上 右下 左下 */
    border-radius: 50%; /* 圆形 */
}
```

边框样式：

- `solid`：实线
- `dashed`：虚线
- `dotted`：点线
- `double`：双线
- `groove`：凹槽
- `ridge`：凸槽
- `inset`：内嵌
- `outset`：外凸
- `none`：无边框
- `hidden`：隐藏边框

### 5.1.6 外边距

外边距是边框外部的空间：

```css
/* 统一设置 */
.box {
    margin: 20px; /* 四边均为20px */
}

/* 分别设置 */
.box {
    margin-top: 10px;
    margin-right: 20px;
    margin-bottom: 10px;
    margin-left: 20px;
}

/* 简写形式 */
.box {
    margin: 10px 20px; /* 上下 左右 */
}

.box {
    margin: 10px 20px 15px; /* 上 左右 下 */
}

.box {
    margin: 10px 20px 15px 25px; /* 上 右 下 左 */
}

/* 水平居中 */
.box {
    margin: 0 auto; /* 上下0，左右自动（居中） */
}

/* 负外边距 */
.box {
    margin-top: -10px; /* 向上移动10px */
}
```

### 5.1.7 外边距折叠

垂直相邻的两个块级元素的外边距会发生折叠（合并），最终外边距等于两者中的较大值：

```html
<style>
.box1 {
    margin-bottom: 20px;
}
.box2 {
    margin-top: 30px;
}
</style>
<div class="box1">Box 1</div>
<div class="box2">Box 2</div>
<!-- 两盒之间的间距是30px，不是50px -->
```

外边距折叠的情况：

- 相邻兄弟元素之间
- 父元素与第一个/最后一个子元素之间（如果没有边框或内边距隔离）
- 空元素（如果没有边框、内边距、内容或高度）

防止外边距折叠的方法：

```css
/* 添加边框 */
.parent {
    border: 1px solid transparent;
}

/* 添加内边距 */
.parent {
    padding: 1px;
}

/* 创建BFC */
.parent {
    overflow: hidden;
}
```

## 5.2 元素的显示类型

### 5.2.1 块级元素

块级元素独占一行，可以设置宽高：

```css
.block-element {
    display: block;
    width: 500px;
    height: 200px;
}
```

常见块级元素：`div`、`p`、`h1`-`h6`、`ul`、`ol`、`li`、`section`、`article`、`header`、`footer`等。

### 5.2.2 内联元素

内联元素不独占一行，宽度和高度由内容决定：

```css
.inline-element {
    display: inline;
    /* width和height无效 */
    padding: 5px; /* 水平有效，垂直可能影响行高 */
    margin: 5px; /* 水平有效，垂直无效 */
}
```

常见内联元素：`span`、`a`、`strong`、`em`、`code`、`br`、`img`等。

### 5.2.3 内联块级元素

内联块级元素兼具两者的特性，不独占一行但可以设置宽高：

```css
.inline-block-element {
    display: inline-block;
    width: 100px;
    height: 50px;
    padding: 10px;
    margin: 10px;
}
```

### 5.2.4 隐藏元素

```css
/* 不占据空间 */
.hidden {
    display: none;
}

/* 占据空间但不可见 */
.invisible {
    visibility: hidden;
}

/* 透明度为0 */
.transparent {
    opacity: 0;
}
```

## 5.3 传统布局方法

### 5.3.1 浮动布局

浮动是最早用于创建多列布局的方法：

```css
.column {
    float: left;
    width: 33.33%;
    padding: 15px;
}

/* 清除浮动 */
.clearfix::after {
    content: '';
    display: table;
    clear: both;
}
```

```html
<div class="clearfix">
    <div class="column">列1</div>
    <div class="column">列2</div>
    <div class="column">列3</div>
</div>
```

浮动属性的值：

- `float: left`：向左浮动
- `float: right`：向右浮动
- `float: none`：不浮动（默认值）

清除浮动的方法：

```css
/* 方法1：clear属性 */
.clear {
    clear: both;
}

/* 方法2：伪元素 */
.clearfix::after {
    content: '';
    display: table;
    clear: both;
}

/* 方法3：overflow */
.container {
    overflow: hidden;
}
```

### 5.3.2 定位布局

定位允许精确控制元素的位置：

```css
/* 相对定位 */
.relative {
    position: relative;
    top: 10px;    /* 向下移动10px */
    left: 20px;   /* 向右移动20px */
}

/* 绝对定位 */
.absolute {
    position: absolute;
    top: 0;
    right: 0;
}

/* 固定定位 */
.fixed {
    position: fixed;
    top: 0;
    left: 0;
    width: 100%;
}

/* 粘性定位 */
.sticky {
    position: sticky;
    top: 0;
}
```

定位属性的值：

- `static`：正常文档流（默认值）
- `relative`：相对定位，相对于元素正常位置
- `absolute`：绝对定位，相对于最近的定位祖先元素
- `fixed`：固定定位，相对于视口
- `sticky`：粘性定位，根据滚动位置在相对和固定之间切换

定位偏移属性：`top`、`right`、`bottom`、`left`、`z-index`

**z-index**

`z-index`控制定位元素的堆叠顺序：

```css
.box1 {
    position: absolute;
    z-index: 1;
}

.box2 {
    position: absolute;
    z-index: 2; /* 在box1之上 */
}
```

### 5.3.3 两列布局示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <style>
        * {
            box-sizing: border-box;
            margin: 0;
            padding: 0;
        }
        
        .container {
            overflow: hidden;
        }
        
        .sidebar {
            float: left;
            width: 25%;
            background-color: #f4f4f4;
            padding: 20px;
        }
        
        .main-content {
            float: left;
            width: 75%;
            padding: 20px;
        }
    </style>
</head>
<body>
    <div class="container">
        <aside class="sidebar">
            <h2>侧边栏</h2>
            <p>侧边栏内容</p>
        </aside>
        <main class="main-content">
            <h1>主内容</h1>
            <p>主内容区域</p>
        </main>
    </div>
</body>
</html>
```

## 5.4 格式化上下文

### 5.4.1 块级格式化上下文（BFC）

BFC是Web页面的可视化CSS渲染的一部分，是布局过程中生成块级盒子的区域。

创建BFC的方法：

```css
.bfc {
    overflow: hidden; /* 或 auto、scroll */
}

.bfc {
    display: flow-root; /* 专门用于创建BFC */
}

.bfc {
    float: left; /* 或 right */
}

.bfc {
    position: absolute; /* 或 fixed */
}

.bfc {
    display: inline-block;
}
```

BFC的特性：

- BFC内部的浮动元素会被包含
- BFC区域不会与浮动元素重叠
- BFC内部的块级盒子垂直排列
- 同一BFC内的相邻块级盒子会发生外边距折叠

### 5.4.2 BFC的应用

**清除浮动**

```css
.container {
    overflow: hidden; /* 创建BFC，包含浮动子元素 */
}

.float-item {
    float: left;
}
```

**防止外边距折叠**

```css
.parent {
    overflow: hidden; /* 创建BFC */
}

.child {
    margin-top: 20px; /* 不会与父元素折叠 */
}
```

**创建自适应两列布局**

```css
.sidebar {
    float: left;
    width: 200px;
}

.main {
    overflow: hidden; /* 创建BFC，自适应剩余宽度 */
}
```

## 5.5 溢出处理

### 5.5.1 overflow属性

`overflow`属性控制内容溢出容器时的显示方式：

```css
/* 可见（默认） */
.box {
    overflow: visible;
}

/* 隐藏溢出内容 */
.box {
    overflow: hidden;
}

/* 显示滚动条 */
.box {
    overflow: scroll; /* 始终显示滚动条 */
}

/* 自动显示滚动条 */
.box {
    overflow: auto; /* 需要时显示滚动条 */
}
```

### 5.5.2 文本溢出处理

```css
/* 单行文本溢出显示省略号 */
.ellipsis {
    white-space: nowrap;
    overflow: hidden;
    text-overflow: ellipsis;
}

/* 多行文本溢出显示省略号 */
.multi-line-ellipsis {
    display: -webkit-box;
    -webkit-line-clamp: 3;
    -webkit-box-orient: vertical;
    overflow: hidden;
}
```

## 5.6 可见性与透明度

### 5.6.1 visibility属性

```css
/* 可见 */
.visible {
    visibility: visible;
}

/* 不可见但占据空间 */
.hidden {
    visibility: hidden;
}

/* 表格行/列折叠 */
.collapse {
    visibility: collapse;
}
```

### 5.6.2 opacity属性

```css
/* 完全不透明 */
.opaque {
    opacity: 1;
}

/* 半透明 */
.semi-transparent {
    opacity: 0.5;
}

/* 完全透明 */
.transparent {
    opacity: 0;
}
```

`opacity`与`visibility`的区别：

- `opacity: 0`的元素仍然可以接收鼠标事件
- `visibility: hidden`的元素不会接收鼠标事件

---

本章详细介绍了CSS盒模型和传统布局方法。理解盒模型是掌握CSS布局的基础，而浮动和定位是传统布局的核心技术。虽然现代布局（Flexbox和Grid）已经成为主流，但理解这些基础概念对于处理兼容性问题和理解布局原理仍然非常重要。
