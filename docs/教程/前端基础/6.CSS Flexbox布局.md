# 第六章 CSS Flexbox布局

## 6.1 Flexbox概述

### 6.1.1 什么是Flexbox

Flexbox（Flexible Box Layout，弹性盒子布局）是CSS3引入的一种一维布局模型，旨在提供一种更有效的方式来布局、对齐和分配容器中项目之间的空间，即使它们的大小未知或动态变化。

Flexbox特别适合以下场景：

- 水平和垂直居中
- 等高列布局
- 底部固定布局
- 响应式导航栏
- 卡片布局

### 6.1.2 Flexbox的基本概念

Flexbox布局涉及两个核心概念：

**Flex容器（Flex Container）**：应用了`display: flex`或`display: inline-flex`的元素。

**Flex项目（Flex Items）**：Flex容器的直接子元素。

Flexbox的两个轴：

- **主轴（Main Axis）**：Flex项目排列的主要方向，由`flex-direction`决定
- **交叉轴（Cross Axis）**：垂直于主轴的轴线

## 6.2 创建Flex容器

### 6.2.1 启用Flex布局

```css
/* 块级Flex容器 */
.container {
    display: flex;
}

/* 内联Flex容器 */
.container {
    display: inline-flex;
}
```

### 6.2.2 基本示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <style>
        .container {
            display: flex;
            background-color: #f0f0f0;
            padding: 10px;
        }
        
        .item {
            background-color: #3498db;
            color: white;
            padding: 20px;
            margin: 10px;
        }
    </style>
</head>
<body>
    <div class="container">
        <div class="item">项目1</div>
        <div class="item">项目2</div>
        <div class="item">项目3</div>
    </div>
</body>
</html>
```

## 6.3 Flex容器属性

### 6.3.1 flex-direction

`flex-direction`定义主轴的方向，即Flex项目的排列方向：

```css
.container {
    flex-direction: row;           /* 水平排列，从左到右（默认） */
    flex-direction: row-reverse;   /* 水平排列，从右到左 */
    flex-direction: column;        /* 垂直排列，从上到下 */
    flex-direction: column-reverse;/* 垂直排列，从下到上 */
}
```

### 6.3.2 flex-wrap

`flex-wrap`定义Flex项目是否换行：

```css
.container {
    flex-wrap: nowrap;      /* 不换行（默认） */
    flex-wrap: wrap;        /* 换行，第一行在上方 */
    flex-wrap: wrap-reverse;/* 换行，第一行在下方 */
}
```

### 6.3.3 flex-flow

`flex-flow`是`flex-direction`和`flex-wrap`的简写属性：

```css
.container {
    flex-flow: row wrap;           /* 水平排列，允许换行 */
    flex-flow: column nowrap;      /* 垂直排列，不换行 */
    flex-flow: row-reverse wrap;   /* 水平反向排列，允许换行 */
}
```

### 6.3.4 justify-content

`justify-content`定义Flex项目在主轴上的对齐方式：

```css
.container {
    justify-content: flex-start;    /* 左对齐（默认） */
    justify-content: flex-end;      /* 右对齐 */
    justify-content: center;        /* 居中 */
    justify-content: space-between; /* 两端对齐，项目间间隔相等 */
    justify-content: space-around;  /* 项目两侧间隔相等 */
    justify-content: space-evenly;  /* 项目间及两端间隔相等 */
}
```

### 6.3.5 align-items

`align-items`定义Flex项目在交叉轴上的对齐方式：

```css
.container {
    align-items: stretch;       /* 拉伸填满容器（默认） */
    align-items: flex-start;    /* 顶部对齐 */
    align-items: flex-end;      /* 底部对齐 */
    align-items: center;        /* 居中对齐 */
    align-items: baseline;      /* 基线对齐 */
}
```

### 6.3.6 align-content

`align-content`定义多行Flex项目在交叉轴上的对齐方式（仅在有多行时生效）：

```css
.container {
    align-content: stretch;       /* 拉伸填满容器（默认） */
    align-content: flex-start;    /* 顶部对齐 */
    align-content: flex-end;      /* 底部对齐 */
    align-content: center;        /* 居中对齐 */
    align-content: space-between; /* 两端对齐 */
    align-content: space-around;  /* 各行两侧间隔相等 */
    align-content: space-evenly;  /* 各行间及两端间隔相等 */
}
```

### 6.3.7 gap

`gap`属性定义Flex项目之间的间隔：

```css
.container {
    gap: 20px;              /* 行和列间隔均为20px */
    gap: 20px 10px;         /* 行间隔20px，列间隔10px */
    row-gap: 20px;          /* 行间隔 */
    column-gap: 10px;       /* 列间隔 */
}
```

## 6.4 Flex项目属性

### 6.4.1 order

`order`定义Flex项目的排列顺序，数值越小越靠前：

```css
.item1 {
    order: 2;
}

.item2 {
    order: 1;
}

.item3 {
    order: 3;
}
/* 显示顺序：item2, item1, item3 */
```

### 6.4.2 flex-grow

`flex-grow`定义Flex项目的放大比例，默认为0（不放大）：

```css
.item1 {
    flex-grow: 1; /* 占据剩余空间的1份 */
}

.item2 {
    flex-grow: 2; /* 占据剩余空间的2份 */
}

.item3 {
    flex-grow: 1; /* 占据剩余空间的1份 */
}
/* item2的宽度是item1和item3的两倍 */
```

### 6.4.3 flex-shrink

`flex-shrink`定义Flex项目的缩小比例，默认为1（可以缩小）：

```css
.item1 {
    flex-shrink: 0; /* 不缩小 */
}

.item2 {
    flex-shrink: 1; /* 可以缩小（默认） */
}

.item3 {
    flex-shrink: 2; /* 缩小速度是其他的2倍 */
}
```

### 6.4.4 flex-basis

`flex-basis`定义Flex项目在分配剩余空间之前的初始大小：

```css
.item {
    flex-basis: 200px;      /* 初始宽度200px */
    flex-basis: 30%;        /* 初始宽度为容器的30% */
    flex-basis: auto;       /* 根据内容自动计算（默认） */
    flex-basis: content;    /* 根据内容自动计算 */
}
```

### 6.4.5 flex简写

`flex`是`flex-grow`、`flex-shrink`和`flex-basis`的简写：

```css
.item {
    flex: 0 1 auto;     /* 默认：不放大，可缩小，自动基础大小 */
    flex: 1;            /* 等价于 flex: 1 1 0% */
    flex: auto;         /* 等价于 flex: 1 1 auto */
    flex: none;         /* 等价于 flex: 0 0 auto */
    flex: 2 1 200px;    /* 放大比例2，缩小比例1，基础大小200px */
}
```

### 6.4.6 align-self

`align-self`定义单个Flex项目在交叉轴上的对齐方式，覆盖容器的`align-items`：

```css
.item {
    align-self: auto;       /* 继承容器的align-items（默认） */
    align-self: flex-start; /* 顶部对齐 */
    align-self: flex-end;   /* 底部对齐 */
    align-self: center;     /* 居中对齐 */
    align-self: baseline;   /* 基线对齐 */
    align-self: stretch;    /* 拉伸填满 */
}
```

## 6.5 常见布局模式

### 6.5.1 水平垂直居中

```css
.container {
    display: flex;
    justify-content: center; /* 水平居中 */
    align-items: center;     /* 垂直居中 */
    height: 100vh;
}
```

### 6.5.2 等高列布局

```css
.container {
    display: flex;
}

.column {
    flex: 1;
    padding: 20px;
}
```

### 6.5.3 侧边栏布局

```css
.container {
    display: flex;
}

.sidebar {
    flex: 0 0 250px; /* 固定宽度250px，不放大不缩小 */
}

.main {
    flex: 1; /* 占据剩余空间 */
}
```

### 6.5.4 底部固定布局

```css
body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
    margin: 0;
}

header, footer {
    flex-shrink: 0; /* 不缩小 */
}

main {
    flex: 1; /* 占据剩余空间 */
}
```

### 6.5.5 响应式导航栏

```css
.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 0 20px;
}

.nav-links {
    display: flex;
    gap: 20px;
    list-style: none;
}

@media (max-width: 768px) {
    .navbar {
        flex-direction: column;
    }
    
    .nav-links {
        flex-direction: column;
        gap: 10px;
    }
}
```

### 6.5.6 卡片网格布局

```css
.card-grid {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.card {
    flex: 1 1 300px; /* 基础宽度300px，可放大缩小 */
    min-width: 250px;
    max-width: 400px;
}
```

## 6.6 完整示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Flexbox布局示例</title>
    <style>
        * {
            box-sizing: border-box;
            margin: 0;
            padding: 0;
        }
        
        body {
            font-family: Arial, sans-serif;
        }
        
        /* 页面布局 */
        .page {
            display: flex;
            flex-direction: column;
            min-height: 100vh;
        }
        
        /* 头部 */
        .header {
            display: flex;
            justify-content: space-between;
            align-items: center;
            padding: 20px;
            background-color: #333;
            color: white;
        }
        
        .logo {
            font-size: 24px;
            font-weight: bold;
        }
        
        .nav {
            display: flex;
            gap: 20px;
        }
        
        .nav a {
            color: white;
            text-decoration: none;
        }
        
        /* 主体 */
        .body {
            display: flex;
            flex: 1;
        }
        
        /* 侧边栏 */
        .sidebar {
            flex: 0 0 200px;
            background-color: #f4f4f4;
            padding: 20px;
        }
        
        .sidebar-menu {
            list-style: none;
        }
        
        .sidebar-menu li {
            padding: 10px 0;
            border-bottom: 1px solid #ddd;
        }
        
        /* 主内容 */
        .main {
            flex: 1;
            padding: 20px;
        }
        
        /* 卡片网格 */
        .card-grid {
            display: flex;
            flex-wrap: wrap;
            gap: 20px;
            margin-top: 20px;
        }
        
        .card {
            flex: 1 1 250px;
            border: 1px solid #ddd;
            border-radius: 8px;
            padding: 20px;
            background-color: white;
        }
        
        .card h3 {
            margin-bottom: 10px;
        }
        
        /* 底部 */
        .footer {
            display: flex;
            justify-content: center;
            align-items: center;
            padding: 20px;
            background-color: #333;
            color: white;
        }
        
        /* 响应式 */
        @media (max-width: 768px) {
            .header {
                flex-direction: column;
                gap: 10px;
            }
            
            .body {
                flex-direction: column;
            }
            
            .sidebar {
                flex: none;
            }
        }
    </style>
</head>
<body>
    <div class="page">
        <header class="header">
            <div class="logo">Logo</div>
            <nav class="nav">
                <a href="#">首页</a>
                <a href="#">关于</a>
                <a href="#">服务</a>
                <a href="#">联系</a>
            </nav>
        </header>
        
        <div class="body">
            <aside class="sidebar">
                <ul class="sidebar-menu">
                    <li>菜单项1</li>
                    <li>菜单项2</li>
                    <li>菜单项3</li>
                    <li>菜单项4</li>
                </ul>
            </aside>
            
            <main class="main">
                <h1>主内容区域</h1>
                <p>这是页面的主要内容。</p>
                
                <div class="card-grid">
                    <div class="card">
                        <h3>卡片1</h3>
                        <p>卡片内容描述...</p>
                    </div>
                    <div class="card">
                        <h3>卡片2</h3>
                        <p>卡片内容描述...</p>
                    </div>
                    <div class="card">
                        <h3>卡片3</h3>
                        <p>卡片内容描述...</p>
                    </div>
                    <div class="card">
                        <h3>卡片4</h3>
                        <p>卡片内容描述...</p>
                    </div>
                </div>
            </main>
        </div>
        
        <footer class="footer">
            <p>版权所有 &copy; 2024</p>
        </footer>
    </div>
</body>
</html>
```

Flexbox是现代CSS布局的重要工具，它简化了复杂的布局任务，如居中、等高列、响应式设计等。掌握Flexbox的各种属性和常见布局模式，可以大大提高前端开发效率。下一章将介绍更强大的二维布局系统：CSS Grid。
