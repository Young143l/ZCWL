# 第九章 JavaScript基础语法

## 9.1 JavaScript概述

### 9.1.1 什么是JavaScript

JavaScript是一种轻量级、解释型的编程语言，主要用于网页开发。它是Web的三大核心技术之一（HTML、CSS、JavaScript），负责实现网页的交互功能、动态内容更新和复杂逻辑处理。

JavaScript最初由Brendan Eich于1995年在Netscape公司创建，最初名为LiveScript，后更名为JavaScript。尽管名称中包含"Java"，但JavaScript与Java是完全不同的语言。

### 9.1.2 JavaScript的特点

- **解释型语言**：代码在运行时逐行解释执行，无需编译
- **动态类型**：变量类型在运行时确定，可以随时改变
- **基于原型**：使用原型而非类来实现面向对象编程
- **一等函数**：函数可以作为值传递、赋值给变量、作为参数和返回值
- **事件驱动**：通过事件处理实现用户交互
- **跨平台**：可以在任何支持JavaScript的环境中运行

### 9.1.3 JavaScript的应用场景

- 网页交互和动态效果
- 表单验证
- 数据获取和处理（AJAX/Fetch）
- 服务器端开发（Node.js）
- 移动应用开发
- 桌面应用开发
- 游戏开发

## 9.2 JavaScript引入方式

### 9.2.1 内联脚本

将JavaScript代码直接写在HTML元素的`onclick`等事件属性中：

```html
<button onclick="alert('Hello World')">点击我</button>
```

### 9.2.2 内部脚本

使用`<script>`标签在HTML文档中嵌入JavaScript代码：

```html
<!DOCTYPE html>
<html>
<head>
    <script>
        function greet() {
            alert('Hello World');
        }
    </script>
</head>
<body>
    <button onclick="greet()">点击我</button>
</body>
</html>
```

### 9.2.3 外部脚本

将JavaScript代码保存在独立的`.js`文件中，通过`<script>`标签引入：

```html
<!DOCTYPE html>
<html>
<head>
    <script src="script.js"></script>
</head>
<body>
    <button onclick="greet()">点击我</button>
</body>
</html>
```

`script.js`文件内容：

```javascript
function greet() {
    alert('Hello World');
}
```

### 9.2.4 脚本加载位置

**`<head>`中加载**

```html
<head>
    <script src="script.js"></script>
</head>
```

这种方式会阻塞HTML解析，可能导致页面加载延迟。

**`<body>`末尾加载（推荐）**

```html
<body>
    <!-- 页面内容 -->
    <script src="script.js"></script>
</body>
```

这种方式确保DOM完全加载后再执行脚本。

**使用`defer`属性**

```html
<head>
    <script src="script.js" defer></script>
</head>
```

`defer`属性使脚本延迟到HTML解析完成后执行，按顺序执行。

**使用`async`属性**

```html
<head>
    <script src="script.js" async></script>
</head>
```

`async`属性使脚本异步加载，加载完成后立即执行，不保证执行顺序。

## 9.3 基本语法

### 9.3.1 语句和表达式

JavaScript程序由语句组成，每条语句以分号结束（分号在大多数情况下可以省略）：

```javascript
let x = 5;          // 变量声明和赋值语句
console.log(x);     // 函数调用语句
```

### 9.3.2 注释

```javascript
// 单行注释

/*
    多行注释
    可以跨越多行
*/

/**
 * 文档注释（JSDoc）
 * @param {number} x - 第一个数字
 * @param {number} y - 第二个数字
 * @returns {number} 两数之和
 */
function add(x, y) {
    return x + y;
}
```

### 9.3.3 严格模式

严格模式是一种更严格的JavaScript解析和执行模式，有助于编写更安全的代码：

```javascript
// 全局严格模式
'use strict';

// 函数级严格模式
function myFunction() {
    'use strict';
    // 函数体
}
```

严格模式的限制：

- 不允许使用未声明的变量
- 不允许删除变量或函数
- 不允许重复的参数名
- 不允许使用八进制数字
- `this`在全局函数中不再指向全局对象

## 9.4 变量与数据类型

### 9.4.1 变量声明

JavaScript有三种声明变量的方式：

```javascript
// var：函数作用域，可重复声明，可重新赋值
var name = 'John';
var name = 'Jane'; // 允许重复声明

// let：块级作用域，不可重复声明，可重新赋值
let age = 25;
// let age = 30; // 错误：不能重复声明
age = 30; // 允许重新赋值

// const：块级作用域，不可重复声明，不可重新赋值
const PI = 3.14159;
// PI = 3.14; // 错误：不能重新赋值
```

推荐使用`let`和`const`，避免使用`var`。

### 9.4.2 数据类型

JavaScript有8种基本数据类型：

**原始类型**

```javascript
// Number：数字（整数和浮点数）
let integer = 42;
let float = 3.14;
let infinity = Infinity;
let notANumber = NaN;

// String：字符串
let singleQuote = 'Hello';
let doubleQuote = "World";
let templateLiteral = `Hello ${singleQuote}`;

// Boolean：布尔值
let isTrue = true;
let isFalse = false;

// Undefined：未定义
let undefinedVar;
console.log(undefinedVar); // undefined

// Null：空值
let nullVar = null;

// Symbol：符号（ES6新增）
let sym = Symbol('description');

// BigInt：大整数（ES2020新增）
let bigNumber = 9007199254740991n;
```

**引用类型**

```javascript
// Object：对象
let person = {
    name: 'John',
    age: 30
};

// Array：数组
let numbers = [1, 2, 3, 4, 5];

// Function：函数
function greet() {
    return 'Hello';
}
```

### 9.4.3 类型检测

```javascript
// typeof操作符
console.log(typeof 42);          // "number"
console.log(typeof 'hello');     // "string"
console.log(typeof true);        // "boolean"
console.log(typeof undefined);   // "undefined"
console.log(typeof null);        // "object"（历史遗留bug）
console.log(typeof {});          // "object"
console.log(typeof []);          // "object"
console.log(typeof function(){});// "function"
console.log(typeof Symbol());    // "symbol"
console.log(typeof 123n);        // "bigint"

// instanceof操作符
console.log([] instanceof Array);     // true
console.log({} instanceof Object);    // true
console.log(function(){} instanceof Function); // true

// Array.isArray()
console.log(Array.isArray([]));       // true
console.log(Array.isArray({}));       // false
```

### 9.4.4 类型转换

**隐式类型转换**

```javascript
console.log('5' + 3);      // "53"（字符串拼接）
console.log('5' - 3);      // 2（数值运算）
console.log('5' * 3);      // 15
console.log(true + 1);     // 2
console.log(false + 1);    // 1
```

**显式类型转换**

```javascript
// 转换为字符串
String(123);               // "123"
(123).toString();          // "123"

// 转换为数字
Number('123');             // 123
Number('12.3');            // 12.3
Number('');                // 0
Number('abc');             // NaN
parseInt('123.45');        // 123
parseFloat('123.45');      // 123.45

// 转换为布尔值
Boolean(1);                // true
Boolean(0);                // false
Boolean('');               // false
Boolean('hello');          // true
Boolean(null);             // false
Boolean(undefined);        // false

// 简写形式
!!'hello';                 // true（双重否定）
+'123';                    // 123（一元加号）
```

## 9.5 运算符

### 9.5.1 算术运算符

```javascript
let a = 10, b = 3;

console.log(a + b);   // 13（加法）
console.log(a - b);   // 7（减法）
console.log(a * b);   // 30（乘法）
console.log(a / b);   // 3.333...（除法）
console.log(a % b);   // 1（取余）
console.log(a ** b);  // 1000（幂运算）

// 自增自减
let c = 5;
console.log(c++);     // 5（后自增，先返回后加1）
console.log(++c);     // 7（先自增，先加1后返回）
console.log(c--);     // 7（后自减）
console.log(--c);     // 5（先自减）
```

### 9.5.2 赋值运算符

```javascript
let x = 10;

x += 5;   // x = x + 5; 结果为15
x -= 3;   // x = x - 3; 结果为12
x *= 2;   // x = x * 2; 结果为24
x /= 4;   // x = x / 4; 结果为6
x %= 4;   // x = x % 4; 结果为2
x **= 3;  // x = x ** 3; 结果为8
```

### 9.5.3 比较运算符

```javascript
console.log(5 == '5');    // true（相等，类型转换后比较）
console.log(5 === '5');   // false（全等，类型和值都相同）
console.log(5 != '5');    // false（不相等）
console.log(5 !== '5');   // true（不全等）
console.log(5 > 3);       // true（大于）
console.log(5 < 3);       // false（小于）
console.log(5 >= 5);      // true（大于等于）
console.log(5 <= 4);      // false（小于等于）
```

推荐使用`===`和`!==`，避免意外的类型转换。

### 9.5.4 逻辑运算符

```javascript
// 逻辑与
console.log(true && true);   // true
console.log(true && false);  // false

// 逻辑或
console.log(true || false);  // true
console.log(false || false); // false

// 逻辑非
console.log(!true);          // false
console.log(!false);         // true

// 短路求值
let result = null || 'default';  // 'default'
let value = 'hello' && 'world';  // 'world'
```

### 9.5.5 三元运算符

```javascript
let age = 18;
let status = age >= 18 ? '成年' : '未成年';
console.log(status);  // "成年"

// 嵌套三元运算符
let score = 85;
let grade = score >= 90 ? 'A' : score >= 80 ? 'B' : score >= 60 ? 'C' : 'D';
```

### 9.5.6 其他运算符

```javascript
// 展开运算符
let arr1 = [1, 2, 3];
let arr2 = [...arr1, 4, 5];  // [1, 2, 3, 4, 5]
let obj1 = { a: 1, b: 2 };
let obj2 = { ...obj1, c: 3 }; // { a: 1, b: 2, c: 3 }

// 解构赋值
let [a, b] = [1, 2];
let { name, age } = { name: 'John', age: 30 };

// 空值合并运算符（ES2020）
let value = null ?? 'default';  // 'default'
let num = 0 ?? 100;             // 0

// 可选链运算符（ES2020）
let user = { profile: { name: 'John' } };
console.log(user?.profile?.name);  // 'John'
console.log(user?.settings?.theme); // undefined
```

## 9.6 流程控制

### 9.6.1 条件语句

**if语句**

```javascript
let age = 18;

if (age < 13) {
    console.log('儿童');
} else if (age < 20) {
    console.log('青少年');
} else if (age < 60) {
    console.log('成年人');
} else {
    console.log('老年人');
}
```

**switch语句**

```javascript
let day = 1;

switch (day) {
    case 1:
        console.log('星期一');
        break;
    case 2:
        console.log('星期二');
        break;
    case 3:
        console.log('星期三');
        break;
    default:
        console.log('其他');
}
```

### 9.6.2 循环语句

**for循环**

```javascript
// 基本for循环
for (let i = 0; i < 5; i++) {
    console.log(i);
}

// 遍历数组
let fruits = ['apple', 'banana', 'orange'];
for (let i = 0; i < fruits.length; i++) {
    console.log(fruits[i]);
}

// for...of（遍历可迭代对象）
for (let fruit of fruits) {
    console.log(fruit);
}

// for...in（遍历对象属性）
let person = { name: 'John', age: 30 };
for (let key in person) {
    console.log(key + ': ' + person[key]);
}
```

**while循环**

```javascript
let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}
```

**do...while循环**

```javascript
let i = 0;
do {
    console.log(i);
    i++;
} while (i < 5);
```

**循环控制**

```javascript
// break：跳出循环
for (let i = 0; i < 10; i++) {
    if (i === 5) break;
    console.log(i);  // 0, 1, 2, 3, 4
}

// continue：跳过当前迭代
for (let i = 0; i < 5; i++) {
    if (i === 2) continue;
    console.log(i);  // 0, 1, 3, 4
}
```

## 9.7 函数

### 9.7.1 函数声明

```javascript
// 函数声明
function greet(name) {
    return 'Hello, ' + name;
}

// 函数表达式
const sayHello = function(name) {
    return 'Hello, ' + name;
};

// 箭头函数
const add = (a, b) => a + b;
const square = x => x * x;
const greetUser = () => 'Hello, User';

// 带函数体的箭头函数
const multiply = (a, b) => {
    const result = a * b;
    return result;
};
```

### 9.7.2 函数参数

```javascript
// 默认参数
function greet(name = 'Guest') {
    return 'Hello, ' + name;
}

// 剩余参数
function sum(...numbers) {
    return numbers.reduce((total, num) => total + num, 0);
}

sum(1, 2, 3, 4, 5);  // 15

// 解构参数
function displayUser({ name, age }) {
    console.log(`${name} is ${age} years old`);
}

displayUser({ name: 'John', age: 30 });
```

### 9.7.3 作用域

```javascript
// 全局作用域
let globalVar = 'I am global';

function myFunction() {
    // 函数作用域
    let functionVar = 'I am in function';
    
    if (true) {
        // 块级作用域
        let blockVar = 'I am in block';
        const alsoBlockVar = 'Me too';
        var notBlockVar = 'I am function scoped';
    }
    
    console.log(functionVar);    // 可以访问
    // console.log(blockVar);    // 错误：不可访问
    console.log(notBlockVar);    // 可以访问
}

console.log(globalVar);          // 可以访问
// console.log(functionVar);     // 错误：不可访问
```

### 9.7.4 闭包

闭包是指函数能够记住并访问其词法作用域，即使函数在其词法作用域之外执行。

```javascript
function createCounter() {
    let count = 0;
    
    return {
        increment: function() {
            count++;
            return count;
        },
        decrement: function() {
            count--;
            return count;
        },
        getCount: function() {
            return count;
        }
    };
}

const counter = createCounter();
console.log(counter.increment());  // 1
console.log(counter.increment());  // 2
console.log(counter.getCount());   // 2
```

## 9.8 数组

### 9.8.1 数组创建

```javascript
// 数组字面量
let fruits = ['apple', 'banana', 'orange'];

// Array构造函数
let numbers = new Array(1, 2, 3, 4, 5);
let emptyArray = new Array(5);  // 创建长度为5的空数组

// Array.of()
let arr = Array.of(1, 2, 3);

// Array.from()
let fromString = Array.from('hello');  // ['h', 'e', 'l', 'l', 'o']
```

### 9.8.2 数组访问和修改

```javascript
let arr = ['a', 'b', 'c', 'd', 'e'];

// 访问元素
console.log(arr[0]);      // 'a'
console.log(arr.length);  // 5

// 修改元素
arr[0] = 'z';             // ['z', 'b', 'c', 'd', 'e']

// 添加元素
arr.push('f');            // 末尾添加
arr.unshift('start');     // 开头添加

// 删除元素
arr.pop();                // 删除末尾
arr.shift();              // 删除开头
arr.splice(1, 2);         // 从索引1开始删除2个元素

// 查找索引
let index = arr.indexOf('c');
let foundIndex = arr.findIndex(x => x === 'c');
```

### 9.8.3 数组方法

**遍历方法**

```javascript
let numbers = [1, 2, 3, 4, 5];

// forEach
numbers.forEach(num => console.log(num));

// map
let doubled = numbers.map(num => num * 2);  // [2, 4, 6, 8, 10]

// filter
let evens = numbers.filter(num => num % 2 === 0);  // [2, 4]

// find
let firstEven = numbers.find(num => num % 2 === 0);  // 2

// findIndex
let firstEvenIndex = numbers.findIndex(num => num % 2 === 0);  // 1

// some
let hasEven = numbers.some(num => num % 2 === 0);  // true

// every
let allPositive = numbers.every(num => num > 0);  // true

// reduce
let sum = numbers.reduce((total, num) => total + num, 0);  // 15

// reduceRight
let reversed = numbers.reduceRight((arr, num) => [...arr, num], []);
```

**其他常用方法**

```javascript
let arr = [3, 1, 4, 1, 5, 9];

// sort
arr.sort((a, b) => a - b);  // [1, 1, 3, 4, 5, 9]

// reverse
arr.reverse();  // [9, 5, 4, 3, 1, 1]

// includes
arr.includes(5);  // true

// join
arr.join('-');  // '9-5-4-3-1-1'

// slice
arr.slice(1, 4);  // [5, 4, 3]

// concat
arr.concat([2, 7]);  // [9, 5, 4, 3, 1, 1, 2, 7]

// flat
[1, [2, 3], [4, [5]]].flat(2);  // [1, 2, 3, 4, 5]

// flatMap
[1, 2, 3].flatMap(x => [x, x * 2]);  // [1, 2, 2, 4, 3, 6]
```

## 9.9 对象

### 9.9.1 对象创建

```javascript
// 对象字面量
let person = {
    firstName: 'John',
    lastName: 'Doe',
    age: 30,
    greet: function() {
        return 'Hello, ' + this.firstName;
    }
};

// 构造函数
function Person(firstName, lastName, age) {
    this.firstName = firstName;
    this.lastName = lastName;
    this.age = age;
}

let john = new Person('John', 'Doe', 30);

// Object.create()
let personPrototype = {
    greet: function() {
        return 'Hello, ' + this.name;
    }
};

let jane = Object.create(personPrototype);
jane.name = 'Jane';

// ES6类
class PersonClass {
    constructor(firstName, lastName, age) {
        this.firstName = firstName;
        this.lastName = lastName;
        this.age = age;
    }
    
    greet() {
        return `Hello, ${this.firstName}`;
    }
    
    get fullName() {
        return `${this.firstName} ${this.lastName}`;
    }
}

let bob = new PersonClass('Bob', 'Smith', 25);
```

### 9.9.2 对象操作

```javascript
let person = { name: 'John', age: 30 };

// 访问属性
console.log(person.name);       // 'John'
console.log(person['age']);     // 30

// 添加/修改属性
person.job = 'Developer';
person['city'] = 'New York';

// 删除属性
delete person.age;

// 检查属性
console.log('name' in person);              // true
console.log(person.hasOwnProperty('name')); // true

// 获取所有键
console.log(Object.keys(person));   // ['name', 'job', 'city']

// 获取所有值
console.log(Object.values(person)); // ['John', 'Developer', 'New York']

// 获取所有键值对
console.log(Object.entries(person)); // [['name', 'John'], ...]

// 合并对象
let obj1 = { a: 1 };
let obj2 = { b: 2 };
let merged = { ...obj1, ...obj2 };  // { a: 1, b: 2 }
let assigned = Object.assign({}, obj1, obj2);

// 冻结对象
let frozen = Object.freeze({ a: 1 });
// frozen.a = 2;  // 严格模式下报错

// 密封对象
let sealed = Object.seal({ a: 1 });
sealed.a = 2;  // 可以修改现有属性
// sealed.b = 3;  // 不能添加新属性
```
