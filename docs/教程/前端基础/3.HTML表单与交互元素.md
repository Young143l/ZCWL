# 第三章 HTML表单与交互元素

## 3.1 表单基础

### 3.1.1 表单的概念

HTML表单是用户与Web应用程序交互的主要方式。表单用于收集用户输入，如文本、选择、文件等，并将数据提交到服务器进行处理。

### 3.1.2 表单的基本结构

表单使用`<form>`元素定义，表单控件（如输入框、按钮等）放置在`<form>`元素内部。

```html
<form action="/submit" method="POST">
    <!-- 表单控件 -->
    <label for="username">用户名：</label>
    <input type="text" id="username" name="username">
    
    <button type="submit">提交</button>
</form>
```

`<form>`元素的常用属性：

- `action`：指定表单数据提交的目标URL
- `method`：指定提交表单时使用的HTTP方法（`GET`或`POST`）
- `enctype`：指定表单数据编码类型（用于文件上传）
- `name`：表单的名称
- `target`：指定提交表单后响应的显示位置

### 3.1.3 GET与POST方法

**GET方法**

- 表单数据附加在URL后面，以查询字符串形式发送
- 数据可见于URL，不适合传输敏感信息
- 有数据长度限制（约2048个字符）
- 适用于搜索、筛选等非敏感操作

```html
<form action="/search" method="GET">
    <input type="text" name="q" placeholder="搜索关键词">
    <button type="submit">搜索</button>
</form>
<!-- 提交后URL可能为：/search?q=关键词 -->
```

**POST方法**

- 表单数据包含在HTTP请求体中发送
- 数据不会显示在URL中
- 没有数据长度限制（实际限制取决于服务器配置）
- 适用于登录、注册、数据提交等操作

```html
<form action="/login" method="POST">
    <input type="text" name="username" placeholder="用户名">
    <input type="password" name="password" placeholder="密码">
    <button type="submit">登录</button>
</form>
```

## 3.2 输入元素

### 3.2.1 input元素概述

`<input>`元素是表单中最常用的控件，通过`type`属性的不同值，可以创建多种类型的输入字段。

```html
<input type="text" name="fieldname">
```

### 3.2.2 文本输入类型

**单行文本输入（text）**

```html
<label for="username">用户名：</label>
<input type="text" id="username" name="username" placeholder="请输入用户名" maxlength="20">
```

常用属性：
- `placeholder`：输入提示文本
- `maxlength`：最大字符数
- `minlength`：最小字符数
- `value`：默认值
- `readonly`：只读
- `disabled`：禁用
- `required`：必填

**密码输入（password）**

```html
<label for="password">密码：</label>
<input type="password" id="password" name="password" minlength="6">
```

**多行文本输入（textarea）**

`<textarea>`元素用于多行文本输入：

```html
<label for="comment">评论：</label>
<textarea id="comment" name="comment" rows="4" cols="50" placeholder="请输入评论"></textarea>
```

常用属性：
- `rows`：可见行数
- `cols`：可见列数
- `maxlength`：最大字符数

### 3.2.3 数值输入类型

**数字输入（number）**

```html
<label for="age">年龄：</label>
<input type="number" id="age" name="age" min="0" max="150" step="1">
```

常用属性：
- `min`：最小值
- `max`：最大值
- `step`：步长（增量值）

**范围选择（range）**

```html
<label for="volume">音量：</label>
<input type="range" id="volume" name="volume" min="0" max="100" value="50">
```

### 3.2.4 日期和时间输入类型

HTML5引入了多种日期和时间输入类型：

```html
<!-- 日期选择 -->
<label for="birthdate">出生日期：</label>
<input type="date" id="birthdate" name="birthdate" min="1900-01-01" max="2024-12-31">

<!-- 时间选择 -->
<label for="meeting-time">会议时间：</label>
<input type="time" id="meeting-time" name="meeting-time">

<!-- 日期时间选择 -->
<label for="appointment">预约时间：</label>
<input type="datetime-local" id="appointment" name="appointment">

<!-- 月份选择 -->
<label for="birth-month">出生月份：</label>
<input type="month" id="birth-month" name="birth-month">

<!-- 星期选择 -->
<label for="week">选择周：</label>
<input type="week" id="week" name="week">
```

### 3.2.5 选择类输入类型

**单选按钮（radio）**

```html
<fieldset>
    <legend>性别：</legend>
    <input type="radio" id="male" name="gender" value="male">
    <label for="male">男</label>
    
    <input type="radio" id="female" name="gender" value="female">
    <label for="female">女</label>
    
    <input type="radio" id="other" name="gender" value="other">
    <label for="other">其他</label>
</fieldset>
```

注意：同一组单选按钮的`name`属性必须相同。

**复选框（checkbox）**

```html
<fieldset>
    <legend>兴趣爱好：</legend>
    <input type="checkbox" id="reading" name="hobby" value="reading">
    <label for="reading">阅读</label>
    
    <input type="checkbox" id="sports" name="hobby" value="sports">
    <label for="sports">运动</label>
    
    <input type="checkbox" id="music" name="hobby" value="music">
    <label for="music">音乐</label>
</fieldset>
```

**下拉选择（select）**

```html
<label for="city">城市：</label>
<select id="city" name="city">
    <option value="">请选择</option>
    <option value="beijing">北京</option>
    <option value="shanghai">上海</option>
    <option value="guangzhou">广州</option>
    <option value="shenzhen">深圳</option>
</select>
```

分组选项：

```html
<label for="course">课程：</label>
<select id="course" name="course">
    <optgroup label="前端开发">
        <option value="html">HTML</option>
        <option value="css">CSS</option>
        <option value="javascript">JavaScript</option>
    </optgroup>
    <optgroup label="后端开发">
        <option value="nodejs">Node.js</option>
        <option value="python">Python</option>
        <option value="java">Java</option>
    </optgroup>
</select>
```

多选下拉：

```html
<label for="skills">技能：</label>
<select id="skills" name="skills" multiple size="4">
    <option value="html">HTML</option>
    <option value="css">CSS</option>
    <option value="javascript">JavaScript</option>
    <option value="vue">Vue</option>
    <option value="react">React</option>
</select>
```

### 3.2.6 其他输入类型

**邮箱输入（email）**

```html
<label for="email">邮箱：</label>
<input type="email" id="email" name="email" placeholder="example@email.com" required>
```

**URL输入（url）**

```html
<label for="website">个人网站：</label>
<input type="url" id="website" name="website" placeholder="https://example.com">
```

**电话输入（tel）**

```html
<label for="phone">电话：</label>
<input type="tel" id="phone" name="phone" pattern="[0-9]{11}" placeholder="11位手机号">
```

**搜索输入（search）**

```html
<label for="search">搜索：</label>
<input type="search" id="search" name="search" placeholder="搜索内容">
```

**颜色选择（color）**

```html
<label for="favorite-color">喜欢的颜色：</label>
<input type="color" id="favorite-color" name="favorite-color" value="#ff0000">
```

**文件上传（file）**

```html
<label for="avatar">头像：</label>
<input type="file" id="avatar" name="avatar" accept="image/*">

<!-- 多文件上传 -->
<label for="documents">文档：</label>
<input type="file" id="documents" name="documents" multiple accept=".pdf,.doc,.docx">
```

`accept`属性值：
- `image/*`：所有图像文件
- `video/*`：所有视频文件
- `audio/*`：所有音频文件
- `.pdf,.doc`：指定扩展名

**隐藏字段（hidden）**

```html
<input type="hidden" name="user_id" value="12345">
```

## 3.3 表单控件属性

### 3.3.1 验证属性

HTML5提供了内置的表单验证功能：

```html
<!-- 必填字段 -->
<input type="text" name="username" required>

<!-- 模式验证（正则表达式） -->
<input type="text" name="zipcode" pattern="[0-9]{6}" title="请输入6位数字邮编">

<!-- 长度限制 -->
<input type="text" name="password" minlength="6" maxlength="20">

<!-- 数值范围 -->
<input type="number" name="quantity" min="1" max="100">
```

### 3.3.2 其他常用属性

```html
<!-- 自动聚焦 -->
<input type="text" name="search" autofocus>

<!-- 自动完成 -->
<input type="text" name="username" autocomplete="username">
<input type="password" name="password" autocomplete="current-password">

<!-- 禁用自动完成 -->
<input type="text" name="code" autocomplete="off">

<!-- 禁用字段 -->
<input type="text" name="disabled-field" disabled>

<!-- 只读字段 -->
<input type="text" name="readonly-field" value="不可编辑" readonly>

<!-- 占位符 -->
<input type="text" name="email" placeholder="请输入邮箱地址">

<!-- 多值输入（用于email和file类型） -->
<input type="email" name="emails" multiple>
```

## 3.4 表单按钮

### 3.4.1 提交按钮

```html
<!-- 使用button元素（推荐） -->
<button type="submit">提交</button>

<!-- 使用input元素 -->
<input type="submit" value="提交">

<!-- 带图标的提交按钮 -->
<button type="submit">
    <span>提交</span>
</button>
```

### 3.4.2 重置按钮

```html
<!-- 使用button元素 -->
<button type="reset">重置</button>

<!-- 使用input元素 -->
<input type="reset" value="重置">
```

### 3.4.3 普通按钮

```html
<!-- 使用button元素 -->
<button type="button" onclick="doSomething()">点击我</button>

<!-- 使用input元素 -->
<input type="button" value="点击我" onclick="doSomething()">
```

### 3.4.4 按钮的disabled状态

```html
<button type="submit" disabled>提交中...</button>
```

## 3.5 表单组织与可访问性

### 3.5.1 使用fieldset和legend分组

```html
<fieldset>
    <legend>个人信息</legend>
    
    <label for="fullname">姓名：</label>
    <input type="text" id="fullname" name="fullname">
    
    <label for="birthdate">出生日期：</label>
    <input type="date" id="birthdate" name="birthdate">
</fieldset>

<fieldset>
    <legend>联系方式</legend>
    
    <label for="email">邮箱：</label>
    <input type="email" id="email" name="email">
    
    <label for="phone">电话：</label>
    <input type="tel" id="phone" name="phone">
</fieldset>
```

### 3.5.2 label元素的正确使用

每个表单控件都应与`<label>`元素关联，以提升可访问性：

```html
<!-- 显式关联（推荐） -->
<label for="username">用户名：</label>
<input type="text" id="username" name="username">

<!-- 隐式关联 -->
<label>
    用户名：
    <input type="text" name="username">
</label>
```

### 3.5.3 使用aria属性增强可访问性

```html
<label for="password">密码：</label>
<input 
    type="password" 
    id="password" 
    name="password"
    aria-required="true"
    aria-describedby="password-help"
    minlength="8"
>
<p id="password-help">密码长度至少8位</p>

<!-- 错误提示 -->
<input 
    type="email" 
    id="email" 
    name="email"
    aria-invalid="true"
    aria-errormessage="email-error"
>
<p id="email-error" role="alert">请输入有效的邮箱地址</p>
```

---

本章详细介绍了HTML表单的各种元素和属性。表单是Web应用程序中用户交互的核心组件，掌握表单的正确使用方法对于前端开发至关重要。在实际开发中，应注意表单的可访问性，确保所有用户都能顺利使用表单功能。
