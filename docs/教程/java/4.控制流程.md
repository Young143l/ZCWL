# 第四章 控制流程

## 4.1 程序控制概述

程序的控制结构决定了代码的执行顺序。Java提供了三种基本控制结构：顺序结构、选择结构和循环结构。顺序结构按照代码的先后顺序依次执行；选择结构根据条件判断执行不同的代码分支；循环结构重复执行某段代码直到满足退出条件。

## 4.2 选择结构

### if语句

if语句是最基本的选择结构：

```java
if (条件表达式) {
    // 条件为true时执行的语句
}
```

```java
int score = 85;
if (score >= 60) {
    System.out.println("及格");
}
```

### if-else语句

if-else语句提供两个分支选择：

```java
if (条件表达式) {
    // 条件为true时执行
} else {
    // 条件为false时执行
}
```

```java
int score = 55;
if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

### if-else if-else语句

多个条件的判断：

```java
if (条件1) {
    // 条件1为true
} else if (条件2) {
    // 条件1为false，条件2为true
} else if (条件3) {
    // 条件1、2为false，条件3为true
} else {
    // 所有条件都为false
}
```

```java
int score = 85;
if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好");
} else if (score >= 70) {
    System.out.println("中等");
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

### 嵌套if语句

if语句可以嵌套使用：

```java
int age = 25;
int income = 50000;

if (age >= 18) {
    if (income >= 30000) {
        System.out.println("符合贷款条件");
    } else {
        System.out.println("收入不足");
    }
} else {
    System.out.println("年龄不符合要求");
}
```

### switch语句

switch语句用于多分支选择，适用于离散值的判断：

```java
switch (表达式) {
    case 常量1:
        // 语句
        break;
    case 常量2:
        // 语句
        break;
    default:
        // 默认语句
}
```

```java
int day = 3;
switch (day) {
    case 1:
        System.out.println("星期一");
        break;
    case 2:
        System.out.println("星期二");
        break;
    case 3:
        System.out.println("星期三");
        break;
    case 4:
        System.out.println("星期四");
        break;
    case 5:
        System.out.println("星期五");
        break;
    case 6:
    case 7:
        System.out.println("周末");
        break;
    default:
        System.out.println("无效的日期");
}
```

Java 12引入了switch表达式：

```java
// 传统写法
String dayName;
switch (day) {
    case 1:
        dayName = "星期一";
        break;
    case 2:
        dayName = "星期二";
        break;
    default:
        dayName = "未知";
}

// switch表达式（Java 12+）
String dayName = switch (day) {
    case 1 -> "星期一";
    case 2 -> "星期二";
    default -> "未知";
};

// 使用yield返回值（Java 13+）
int numLetters = switch (day) {
    case 1, 2, 3, 4, 5 -> 5;
    case 6, 7 -> {
        System.out.println("周末");
        yield 2;
    }
    default -> 0;
};
```

注意：
- switch表达式的值必须是整型、字符型、字符串或枚举类型
- case标签必须是常量表达式
- 每个case通常以break结束，否则会继续执行下一个case（穿透）
- default分支是可选的

## 4.3 循环结构

### while循环

while循环先判断条件，条件为true时执行循环体：

```java
while (条件表达式) {
    // 循环体
}
```

```java
// 计算1到100的和
int i = 1;
int sum = 0;
while (i <= 100) {
    sum += i;
    i++;
}
System.out.println("1到100的和：" + sum);
```

### do-while循环

do-while循环先执行循环体，再判断条件，至少执行一次：

```java
do {
    // 循环体
} while (条件表达式);
```

```java
// 用户输入验证
import java.util.Scanner;

Scanner scanner = new Scanner(System.in);
int num;
do {
    System.out.print("请输入一个正数：");
    num = scanner.nextInt();
} while (num <= 0);
System.out.println("你输入了：" + num);
```

### for循环

for循环将初始化、条件判断和迭代操作集中在一行：

```java
for (初始化; 条件; 迭代) {
    // 循环体
}
```

```java
// 计算1到100的和
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
System.out.println("1到100的和：" + sum);
```

for循环的三个部分都可以省略：

```java
// 无限循环
for (;;) {
    // 循环体
}

// 省略初始化
int i = 0;
for (; i < 10; i++) {
    // 循环体
}
```

### 增强for循环

增强for循环用于遍历数组或集合：

```java
for (元素类型 变量 : 数组或集合) {
    // 循环体
}
```

```java
int[] numbers = {1, 2, 3, 4, 5};
for (int num : numbers) {
    System.out.println(num);
}

String[] names = {"Alice", "Bob", "Charlie"};
for (String name : names) {
    System.out.println(name);
}
```

### 循环比较

三种循环的选择建议：

- **for循环**：循环次数已知，或需要计数器控制
- **while循环**：循环次数不确定，先判断后执行
- **do-while循环**：至少需要执行一次循环体
- **增强for循环**：遍历数组或集合，无需索引

## 4.4 跳转语句

### break语句

break用于立即退出当前循环或switch语句：

```java
// 查找数组中第一个负数
int[] arr = {3, 7, -2, 5, 8};
int foundIndex = -1;
for (int i = 0; i < arr.length; i++) {
    if (arr[i] < 0) {
        foundIndex = i;
        break;          // 找到后立即退出循环
    }
}
```

### 带标签的break

用于跳出多层嵌套循环：

```java
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i * j > 4) {
            break outer;    // 跳出外层循环
        }
        System.out.println(i + ", " + j);
    }
}
```

### continue语句

continue跳过当前迭代，继续下一次循环：

```java
// 打印1到10中的奇数
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;       // 偶数跳过
    }
    System.out.print(i + " ");
}
```

### 带标签的continue

```java
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (j == 1) {
            continue outer; // 跳到外层循环的下一次迭代
        }
        System.out.println(i + ", " + j);
    }
}
```

### return语句

return用于从方法中返回：

```java
public int find(int[] arr, int target) {
    for (int i = 0; i < arr.length; i++) {
        if (arr[i] == target) {
            return i;       // 找到后返回索引
        }
    }
    return -1;              // 未找到返回-1
}
```

## 4.5 嵌套循环

循环可以嵌套使用，常用于处理多维数据结构：

```java
// 打印九九乘法表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.printf("%d*%d=%-2d ", j, i, i * j);
    }
    System.out.println();
}
```

## 4.6 综合示例

### 示例1：判断素数

```java
public class PrimeCheck {
    
    public static boolean isPrime(int n) {
        if (n <= 1) {
            return false;
        }
        if (n == 2) {
            return true;
        }
        if (n % 2 == 0) {
            return false;
        }
        for (int i = 3; i <= Math.sqrt(n); i += 2) {
            if (n % i == 0) {
                return false;
            }
        }
        return true;
    }
    
    public static void main(String[] args) {
        int num = 29;
        if (isPrime(num)) {
            System.out.println(num + "是素数");
        } else {
            System.out.println(num + "不是素数");
        }
    }
}
```

### 示例2：计算阶乘

```java
public class Factorial {
    
    public static long factorial(int n) {
        if (n < 0) {
            throw new IllegalArgumentException("n不能为负数");
        }
        long result = 1;
        for (int i = 2; i <= n; i++) {
            result *= i;
        }
        return result;
    }
    
    public static void main(String[] args) {
        int num = 5;
        System.out.println(num + "! = " + factorial(num));
    }
}
```

### 示例3：斐波那契数列

```java
public class Fibonacci {
    
    public static void printFibonacci(int n) {
        if (n <= 0) {
            return;
        }
        
        long first = 0, second = 1;
        
        System.out.print("斐波那契数列前" + n + "项：");
        
        for (int i = 0; i < n; i++) {
            if (i == 0) {
                System.out.print(first + " ");
            } else if (i == 1) {
                System.out.print(second + " ");
            } else {
                long next = first + second;
                System.out.print(next + " ");
                first = second;
                second = next;
            }
        }
        System.out.println();
    }
    
    public static void main(String[] args) {
        printFibonacci(10);
    }
}
```

### 示例4：猜数字游戏

```java
import java.util.Scanner;
import java.util.Random;

public class GuessNumber {
    
    public static void main(String[] args) {
        Random random = new Random();
        Scanner scanner = new Scanner(System.in);
        
        int target = random.nextInt(100) + 1;   // 1到100的随机数
        int guess;
        int attempts = 0;
        
        System.out.println("猜数字游戏（1-100）");
        
        do {
            System.out.print("请输入你的猜测：");
            guess = scanner.nextInt();
            attempts++;
            
            if (guess > target) {
                System.out.println("太大了！");
            } else if (guess < target) {
                System.out.println("太小了！");
            } else {
                System.out.println("恭喜你猜对了！用了" + attempts + "次");
            }
        } while (guess != target);
        
        scanner.close();
    }
}
```
