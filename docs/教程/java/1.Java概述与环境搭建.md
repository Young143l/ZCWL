# 第一章 Java概述与环境搭建

## 1.1 Java语言的历史与发展

Java语言由Sun Microsystems公司于1995年正式发布，由James Gosling领导的团队开发。Java的设计初衷是创建一种能够在各种消费电子设备上运行的编程语言，其核心理念是"一次编写，到处运行"（Write Once, Run Anywhere）。

1996年，JDK 1.0发布，标志着Java正式进入商业应用阶段。此后，Java经历了多个重要版本的演进：

- Java 1.2（1998年）：引入Swing、Collections Framework等重要特性
- Java 5（2004年）：引入泛型、增强for循环、注解等重大特性
- Java 8（2014年）：引入Lambda表达式、Stream API，是Java历史上最重要的版本之一
- Java 11（2018年）：长期支持版本，移除了部分过时模块
- Java 17（2021年）：新的长期支持版本，引入密封类等特性

2010年，Oracle公司收购Sun Microsystems，Java的开发和维护由Oracle接手。

## 1.2 Java语言的特点

Java语言具有以下显著特点：

**面向对象**：Java是完全的面向对象编程语言，所有代码都必须定义在类中，支持封装、继承和多态三大特性。

**平台无关性**：Java程序编译为字节码（bytecode），由Java虚拟机（JVM）解释执行，可在任何安装了JVM的平台上运行。

**自动内存管理**：Java提供垃圾回收机制（Garbage Collection），自动回收不再使用的内存，减少内存泄漏风险。

**强类型语言**：Java在编译时进行严格的类型检查，有助于在开发阶段发现错误。

**安全性**：Java提供安全管理器、字节码验证等机制，防止恶意代码执行。

**丰富的类库**：Java拥有庞大的标准类库，涵盖网络、数据库、图形界面、并发编程等各个领域。

## 1.3 Java技术体系

Java技术体系主要包括以下三个版本：

**Java SE（Standard Edition）**：标准版，包含Java语言核心类库，是其他版本的基础。

**Java EE（Enterprise Edition）**：企业版，在SE基础上增加了企业级开发所需的API，如Servlet、JSP、EJB等。现更名为Jakarta EE。

**Java ME（Micro Edition）**：微型版，针对嵌入式和移动设备开发。随着智能手机的发展，ME的使用已大幅减少。

## 1.4 Java程序运行机制

Java程序的执行过程分为两个阶段：

**编译阶段**：Java源代码（.java文件）通过javac编译器编译为字节码（.class文件）。字节码是一种与平台无关的中间代码。

**运行阶段**：字节码由Java虚拟机（JVM）加载、验证、解释执行。JVM包含类加载器、字节码验证器、解释器/即时编译器（JIT）等组件。

即时编译器将热点代码编译为本地机器码，提高执行效率。现代JVM采用混合模式，结合解释执行和编译执行的优势。

## 1.5 开发环境搭建

### 1.5.1 JDK的安装与配置

JDK（Java Development Kit）是Java开发工具包，包含JRE（Java Runtime Environment）和开发工具。

**Windows平台安装**：

1. 从Oracle官网或OpenJDK网站下载JDK安装包
2. 运行安装程序，按提示完成安装
3. 配置环境变量：
   - 新建系统变量`JAVA_HOME`，值为JDK安装路径
   - 编辑系统变量`Path`，添加`%JAVA_HOME%\bin`

**Linux平台安装**：

```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install openjdk-17-jdk

# CentOS/RHEL
sudo yum install java-17-openjdk-devel
```

**macOS平台安装**：

```bash
# 使用Homebrew
brew install openjdk@17
```

### 1.5.2 验证安装

打开命令行，执行以下命令验证安装：

```bash
java -version
javac -version
```

正常输出应显示Java版本信息。

### 1.5.3 集成开发环境

常用的Java集成开发环境包括：

**IntelliJ IDEA**：JetBrains公司开发的IDE，功能强大，有社区版（免费）和旗舰版（付费）。

**Visual Studio Code**：微软开发的轻量级编辑器，配合Java扩展插件可进行Java开发。

## 1.6 第一个Java程序

下面是一个经典的入门程序：

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### 代码解析

**public class HelloWorld**：定义一个公共类，类名必须与文件名相同（HelloWorld.java）。

**public static void main(String[] args)**：程序的主方法，是程序执行的入口点。
- `public`：公共访问修饰符
- `static`：静态方法，无需创建对象即可调用
- `void`：方法不返回任何值
- `String[] args`：命令行参数数组

**System.out.println("Hello, World!")**：输出语句，向控制台打印字符串并换行。

### 编译与运行

保存上述代码到文件`HelloWorld.java`，然后执行：

```bash
# 编译
javac HelloWorld.java

# 运行
java HelloWorld
```

编译成功后，将生成`HelloWorld.class`字节码文件，运行后输出：

```
Hello, World!
```

## 1.7 Java程序的基本结构

一个完整的Java程序通常包含以下组成部分：

```java
// 包声明
package com.example;

// 导入语句
import java.util.Scanner;
import java.util.Date;

// 类定义
public class Example {
    
    // 成员变量（字段）
    private int id;
    private String name;
    
    // 构造方法
    public Example(int id, String name) {
        this.id = id;
        this.name = name;
    }
    
    // 成员方法
    public void display() {
        System.out.println("ID: " + id + ", Name: " + name);
    }
    
    // 主方法
    public static void main(String[] args) {
        Example obj = new Example(1, "Test");
        obj.display();
    }
}
```

## 1.8 编程规范与命名约定

良好的编程规范有助于提高代码的可读性和可维护性：

**类名**：使用大驼峰命名法（UpperCamelCase），如`StudentInfo`、`ArrayList`。

**方法名**：使用小驼峰命名法（lowerCamelCase），如`getName`、`calculateTotal`。

**变量名**：使用小驼峰命名法，如`studentName`、`maxSize`。

**常量名**：使用全大写字母，单词间用下划线分隔，如`MAX_SIZE`、`PI`。

**包名**：使用全小写字母，多级包用点号分隔，通常以组织域名的反写开头，如`com.company.project`。

**缩进**：使用4个空格进行缩进，避免使用Tab字符。

**大括号**：左大括号放在行末，右大括号独占一行。

## 1.9 注释

Java支持三种注释方式：

```java
// 单行注释

/*
 * 多行注释
 * 可以跨越多行
 */

/**
 * 文档注释
 * 用于生成API文档
 * @param args 命令行参数
 */
```

文档注释使用Javadoc工具可以生成HTML格式的API文档。
