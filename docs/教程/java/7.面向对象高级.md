# 第七章 面向对象高级

## 7.1 继承

继承是面向对象编程的重要特性，允许一个类继承另一个类的属性和方法。被继承的类称为父类（或基类、超类），继承的类称为子类（或派生类）。

### 继承的语法

```java
class 子类 extends 父类 {
    // 子类特有的属性和方法
}
```

```java
// 父类
public class Animal {
    protected String name;
    protected int age;
    
    public Animal(String name, int age) {
        this.name = name;
        this.age = age;
    }
    
    public void eat() {
        System.out.println(name + "正在吃东西");
    }
    
    public void sleep() {
        System.out.println(name + "正在睡觉");
    }
}

// 子类
public class Dog extends Animal {
    private String breed;
    
    public Dog(String name, int age, String breed) {
        super(name, age);       // 调用父类构造方法
        this.breed = breed;
    }
    
    public void bark() {
        System.out.println(name + "在汪汪叫");
    }
    
    @Override
    public void eat() {
        System.out.println(name + "正在吃狗粮");
    }
}
```

### 继承的特点

- Java只支持单继承，一个类只能直接继承一个父类
- 子类继承父类所有非private的成员
- 子类可以添加新的成员和方法
- 子类可以重写父类的方法

## 7.2 super关键字

super关键字用于访问父类的成员：

### 调用父类构造方法

```java
public Dog(String name, int age, String breed) {
    super(name, age);       // 必须是构造方法的第一条语句
    this.breed = breed;
}
```

### 访问父类成员

```java
@Override
public void eat() {
    super.eat();            // 调用父类的方法
    System.out.println(name + "吃完了");
}
```

## 7.3 方法重写

子类可以重写父类的方法，提供特定的实现：

### 重写规则

- 方法名、参数列表、返回类型必须相同
- 访问修饰符不能比父类更严格
- 不能抛出比父类更宽泛的异常
- 使用@Override注解标识

```java
public class Cat extends Animal {
    public Cat(String name, int age) {
        super(name, age);
    }
    
    @Override
    public void eat() {
        System.out.println(name + "正在吃猫粮");
    }
    
    public void meow() {
        System.out.println(name + "在喵喵叫");
    }
}
```

## 7.4 多态

多态是指同一操作作用于不同的对象，可以产生不同的解释和执行结果。Java中的多态主要通过继承和接口实现。

### 向上转型

子类对象可以赋值给父类引用：

```java
Animal animal1 = new Dog("旺财", 3, "金毛");
Animal animal2 = new Cat("咪咪", 2);

animal1.eat();      // 输出：旺财正在吃狗粮
animal2.eat();      // 输出：咪咪正在吃猫粮
```

### 动态绑定

方法的调用在运行时确定：

```java
public void feed(Animal animal) {
    animal.eat();   // 根据实际对象类型调用相应的方法
}

// 使用
feed(new Dog("旺财", 3, "金毛"));    // 调用Dog的eat
feed(new Cat("咪咪", 2));            // 调用Cat的eat
```

### 向下转型

父类引用转换为子类引用：

```java
Animal animal = new Dog("旺财", 3, "金毛");

// 使用instanceof检查类型
if (animal instanceof Dog) {
    Dog dog = (Dog) animal;     // 向下转型
    dog.bark();
}

// Java 16+ 模式匹配
if (animal instanceof Dog dog) {
    dog.bark();
}
```

## 7.5 抽象类

抽象类是不能实例化的类，用于定义子类的共同行为：

```java
public abstract class Shape {
    protected String color;
    
    public Shape(String color) {
        this.color = color;
    }
    
    // 抽象方法，子类必须实现
    public abstract double getArea();
    public abstract double getPerimeter();
    
    // 具体方法
    public String getColor() {
        return color;
    }
    
    public void display() {
        System.out.println("颜色：" + color);
        System.out.println("面积：" + getArea());
        System.out.println("周长：" + getPerimeter());
    }
}

public class Circle extends Shape {
    private double radius;
    
    public Circle(String color, double radius) {
        super(color);
        this.radius = radius;
    }
    
    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }
    
    @Override
    public double getPerimeter() {
        return 2 * Math.PI * radius;
    }
}
```

### 抽象类的特点

- 使用abstract关键字修饰
- 可以包含抽象方法和具体方法
- 抽象方法只有声明，没有实现
- 子类必须实现所有抽象方法，除非子类也是抽象类
- 不能实例化，但可以有构造方法

## 7.6 接口

接口定义了一组方法规范，实现类必须遵循这些规范：

```java
public interface Drawable {
    void draw();                    // 隐式public abstract
    
    // 默认方法（Java 8+）
    default void print() {
        System.out.println("正在打印");
    }
    
    // 静态方法（Java 8+）
    static void info() {
        System.out.println("这是Drawable接口");
    }
}

public interface Movable {
    void move(int x, int y);
}

// 实现多个接口
public class Rectangle implements Drawable, Movable {
    private int x, y;
    private int width, height;
    
    public Rectangle(int x, int y, int width, int height) {
        this.x = x;
        this.y = y;
        this.width = width;
        this.height = height;
    }
    
    @Override
    public void draw() {
        System.out.println("绘制矩形在(" + x + ", " + y + ")");
    }
    
    @Override
    public void move(int dx, int dy) {
        this.x += dx;
        this.y += dy;
    }
}
```

### 接口的特点

- 使用interface关键字定义
- 方法默认是public abstract
- 字段默认是public static final
- 一个类可以实现多个接口
- 接口可以继承多个接口
- Java 8+支持默认方法和静态方法
- Java 9+支持私有方法

## 7.7 接口与抽象类的区别

| 特性 | 抽象类 | 接口 |
|------|--------|------|
| 关键字 | abstract class | interface |
| 继承/实现 | extends | implements |
| 多重继承 | 不支持 | 支持 |
| 构造方法 | 可以有 | 不能有 |
| 实例变量 | 可以有 | 只能是常量 |
| 方法实现 | 可以有具体方法 | Java 8+可以有默认方法 |
| 访问修饰符 | 可以有限制 | 默认public |

## 7.8 final关键字

final关键字可以修饰类、方法和变量：

### final类

不能被继承：

```java
public final class String {
    // ...
}

// public class MyString extends String {}  // 错误
```

### final方法

不能被重写：

```java
public class Parent {
    public final void finalMethod() {
        // ...
    }
}

public class Child extends Parent {
    // public void finalMethod() {}  // 错误
}
```

### final变量

只能赋值一次：

```java
public class Example {
    private final int MAX_SIZE = 100;   // 常量
    private final String name;          // 必须在构造方法中初始化
    
    public Example(String name) {
        this.name = name;
    }
}
```

## 7.9 Object类

Object是所有类的根类，提供了一些通用方法：

### toString方法

返回对象的字符串表示：

```java
@Override
public String toString() {
    return "Person[name=" + name + ", age=" + age + "]";
}
```

### equals方法

比较两个对象是否相等：

```java
@Override
public boolean equals(Object obj) {
    if (this == obj) return true;
    if (obj == null || getClass() != obj.getClass()) return false;
    Person person = (Person) obj;
    return age == person.age && Objects.equals(name, person.name);
}
```

### hashCode方法

返回对象的哈希码：

```java
@Override
public int hashCode() {
    return Objects.hash(name, age);
}
```

注意：重写equals方法时，必须同时重写hashCode方法。

## 7.10 内部类

内部类是定义在另一个类内部的类：

### 成员内部类

```java
public class Outer {
    private int x = 10;
    
    public class Inner {
        public void print() {
            System.out.println("x = " + x);     // 可以访问外部类成员
        }
    }
    
    public void createInner() {
        Inner inner = new Inner();
        inner.print();
    }
}

// 使用
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
inner.print();
```

### 静态内部类

```java
public class Outer {
    private static int x = 10;
    
    public static class Inner {
        public void print() {
            System.out.println("x = " + x);     // 只能访问静态成员
        }
    }
}

// 使用
Outer.Inner inner = new Outer.Inner();
inner.print();
```

### 局部内部类

```java
public class Outer {
    public void method() {
        class LocalInner {
            public void print() {
                System.out.println("局部内部类");
            }
        }
        
        LocalInner inner = new LocalInner();
        inner.print();
    }
}
```

### 匿名内部类

```java
// 实现接口
Runnable runnable = new Runnable() {
    @Override
    public void run() {
        System.out.println("运行中");
    }
};

// Lambda表达式简化
Runnable runnable2 = () -> System.out.println("运行中");

// 继承类
Animal dog = new Animal("旺财", 3) {
    @Override
    public void eat() {
        System.out.println(name + "正在吃狗粮");
    }
};
```

## 7.11 枚举类

枚举是一种特殊的类，用于定义固定的常量集合：

```java
public enum Day {
    SUNDAY, MONDAY, TUESDAY, WEDNESDAY, 
    THURSDAY, FRIDAY, SATURDAY
}

// 带构造方法和字段的枚举
public enum Status {
    SUCCESS(200, "成功"),
    NOT_FOUND(404, "未找到"),
    ERROR(500, "服务器错误");
    
    private final int code;
    private final String message;
    
    Status(int code, String message) {
        this.code = code;
        this.message = message;
    }
    
    public int getCode() {
        return code;
    }
    
    public String getMessage() {
        return message;
    }
}

// 使用
Status status = Status.SUCCESS;
System.out.println(status.getCode());       // 200
System.out.println(status.getMessage());    // 成功
```

## 7.12 综合示例

### 示例1：图形类层次结构

```java
// 抽象类
public abstract class Shape {
    protected String name;
    
    public Shape(String name) {
        this.name = name;
    }
    
    public abstract double getArea();
    public abstract double getPerimeter();
    
    public void display() {
        System.out.println("图形：" + name);
        System.out.println("面积：" + getArea());
        System.out.println("周长：" + getPerimeter());
    }
}

// 接口
public interface Resizable {
    void scale(double factor);
}

// 具体类
public class Circle extends Shape implements Resizable {
    private double radius;
    
    public Circle(double radius) {
        super("圆形");
        this.radius = radius;
    }
    
    @Override
    public double getArea() {
        return Math.PI * radius * radius;
    }
    
    @Override
    public double getPerimeter() {
        return 2 * Math.PI * radius;
    }
    
    @Override
    public void scale(double factor) {
        radius *= factor;
    }
}

public class Rectangle extends Shape implements Resizable {
    private double width;
    private double height;
    
    public Rectangle(double width, double height) {
        super("矩形");
        this.width = width;
        this.height = height;
    }
    
    @Override
    public double getArea() {
        return width * height;
    }
    
    @Override
    public double getPerimeter() {
        return 2 * (width + height);
    }
    
    @Override
    public void scale(double factor) {
        width *= factor;
        height *= factor;
    }
}

// 测试
public class ShapeTest {
    public static void main(String[] args) {
        Shape[] shapes = {
            new Circle(5),
            new Rectangle(4, 6),
            new Circle(3)
        };
        
        for (Shape shape : shapes) {
            shape.display();
            System.out.println();
        }
        
        // 使用接口
        Resizable[] resizables = {
            new Circle(5),
            new Rectangle(4, 6)
        };
        
        for (Resizable r : resizables) {
            r.scale(2);
        }
    }
}
```
