# 第十一章 输入输出流

## 11.1 IO流概述

Java的IO（Input/Output）流用于处理数据的输入和输出。流是一组有序的数据序列，可以从源读取数据或向目标写入数据。

### 流的分类

**按数据类型分类**：
- 字节流：以字节为单位处理数据，适用于所有类型文件
- 字符流：以字符为单位处理数据，适用于文本文件

**按流向分类**：
- 输入流：从源读取数据
- 输出流：向目标写入数据

**按功能分类**：
- 节点流：直接连接到数据源或目标
- 处理流：包装其他流，提供额外功能

### IO流类层次结构

```
字节流
├── InputStream
│   ├── FileInputStream
│   ├── BufferedInputStream
│   ├── DataInputStream
│   └── ObjectInputStream
└── OutputStream
    ├── FileOutputStream
    ├── BufferedOutputStream
    ├── DataOutputStream
    ├── ObjectOutputStream
    └── PrintStream

字符流
├── Reader
│   ├── FileReader
│   ├── BufferedReader
│   ├── InputStreamReader
│   └── StringReader
└── Writer
    ├── FileWriter
    ├── BufferedWriter
    ├── OutputStreamWriter
    ├── PrintWriter
    └── StringWriter
```

## 11.2 字节流

### FileInputStream和FileOutputStream

```java
import java.io.*;

// 文件复制（字节流）
public static void copyFile(String sourcePath, String destPath) throws IOException {
    try (InputStream in = new FileInputStream(sourcePath);
         OutputStream out = new FileOutputStream(destPath)) {
        
        byte[] buffer = new byte[4096];
        int bytesRead;
        while ((bytesRead = in.read(buffer)) != -1) {
            out.write(buffer, 0, bytesRead);
        }
    }
}
```

### BufferedInputStream和BufferedOutputStream

带缓冲的字节流，提高读写效率：

```java
try (BufferedInputStream bis = new BufferedInputStream(
        new FileInputStream("source.txt"));
     BufferedOutputStream bos = new BufferedOutputStream(
        new FileOutputStream("dest.txt"))) {
    
    byte[] buffer = new byte[4096];
    int len;
    while ((len = bis.read(buffer)) != -1) {
        bos.write(buffer, 0, len);
    }
}
```

### DataInputStream和DataOutputStream

读写基本数据类型：

```java
// 写入数据
try (DataOutputStream dos = new DataOutputStream(
        new FileOutputStream("data.bin"))) {
    dos.writeInt(100);
    dos.writeDouble(3.14);
    dos.writeBoolean(true);
    dos.writeUTF("Hello");
}

// 读取数据
try (DataInputStream dis = new DataInputStream(
        new FileInputStream("data.bin"))) {
    int i = dis.readInt();
    double d = dis.readDouble();
    boolean b = dis.readBoolean();
    String s = dis.readUTF();
}
```

## 11.3 字符流

### FileReader和FileWriter

```java
// 复制文本文件
try (Reader reader = new FileReader("source.txt");
     Writer writer = new FileWriter("dest.txt")) {
    
    char[] buffer = new char[4096];
    int len;
    while ((len = reader.read(buffer)) != -1) {
        writer.write(buffer, 0, len);
    }
}
```

### BufferedReader和BufferedWriter

带缓冲的字符流，支持按行读写：

```java
// 按行读取
List<String> lines = new ArrayList<>();
try (BufferedReader reader = new BufferedReader(
        new FileReader("input.txt"))) {
    String line;
    while ((line = reader.readLine()) != null) {
        lines.add(line);
    }
}

// 按行写入
try (BufferedWriter writer = new BufferedWriter(
        new FileWriter("output.txt"))) {
    for (String line : lines) {
        writer.write(line);
        writer.newLine();       // 写入换行符
    }
}
```

### InputStreamReader和OutputStreamWriter

字节流与字符流的桥梁，支持指定字符编码：

```java
// 指定编码读取
try (Reader reader = new InputStreamReader(
        new FileInputStream("input.txt"), "UTF-8")) {
    // 读取...
}

// 指定编码写入
try (Writer writer = new OutputStreamWriter(
        new FileOutputStream("output.txt"), "UTF-8")) {
    // 写入...
}
```

## 11.5 对象序列化

### ObjectInputStream和ObjectOutputStream

实现对象的持久化存储：

```java
// 可序列化的类
import java.io.Serializable;

public class Student implements Serializable {
    private static final long serialVersionUID = 1L;
    
    private String name;
    private int age;
    private transient String password;  // transient字段不会被序列化
    
    // 构造方法、getter、setter省略
}

// 序列化（写入对象）
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("student.dat"))) {
    Student student = new Student("Alice", 20, "123456");
    oos.writeObject(student);
}

// 反序列化（读取对象）
try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("student.dat"))) {
    Student student = (Student) ois.readObject();
    System.out.println(student.getName());      // Alice
    System.out.println(student.getAge());       // 20
    System.out.println(student.getPassword());  // null（transient字段）
}
```

## 11.8 综合示例

### 示例1：文件工具类

```java
import java.io.*;
import java.nio.file.*;
import java.util.*;

public class FileUtils {
    
    // 读取文件为字符串
    public static String readFile(String path) throws IOException {
        return Files.readString(Path.of(path));
    }
    
    // 写入字符串到文件
    public static void writeFile(String path, String content) throws IOException {
        Files.writeString(Path.of(path), content);
    }
    
    // 按行读取文件
    public static List<String> readLines(String path) throws IOException {
        return Files.readAllLines(Path.of(path));
    }
    
    // 复制目录
    public static void copyDirectory(String sourceDir, String targetDir) 
            throws IOException {
        Path source = Path.of(sourceDir);
        Path target = Path.of(targetDir);
        
        Files.walk(source).forEach(path -> {
            try {
                Path relative = source.relativize(path);
                Path dest = target.resolve(relative);
                
                if (Files.isDirectory(path)) {
                    Files.createDirectories(dest);
                } else {
                    Files.copy(path, dest, StandardCopyOption.REPLACE_EXISTING);
                }
            } catch (IOException e) {
                throw new RuntimeException(e);
            }
        });
    }
    
    // 删除目录
    public static void deleteDirectory(String dir) throws IOException {
        Path path = Path.of(dir);
        Files.walk(path)
             .sorted(Comparator.reverseOrder())
             .forEach(p -> {
                 try {
                     Files.delete(p);
                 } catch (IOException e) {
                     throw new RuntimeException(e);
                 }
             });
    }
    
    // 查找文件
    public static List<Path> findFiles(String dir, String pattern) 
            throws IOException {
        List<Path> result = new ArrayList<>();
        PathMatcher matcher = FileSystems.getDefault()
            .getPathMatcher("glob:" + pattern);
        
        Files.walk(Path.of(dir)).forEach(path -> {
            if (matcher.matches(path.getFileName())) {
                result.add(path);
            }
        });
        
        return result;
    }
}
```

### 示例2：配置文件读写

```java
import java.io.*;
import java.nio.file.*;
import java.util.*;

public class ConfigManager {
    private Properties properties;
    private Path configPath;
    
    public ConfigManager(String configFile) {
        this.properties = new Properties();
        this.configPath = Path.of(configFile);
        load();
    }
    
    public void load() {
        if (Files.exists(configPath)) {
            try (Reader reader = Files.newBufferedReader(configPath)) {
                properties.load(reader);
            } catch (IOException e) {
                System.err.println("加载配置失败：" + e.getMessage());
            }
        }
    }
    
    public void save() {
        try (Writer writer = Files.newBufferedWriter(configPath)) {
            properties.store(writer, "Application Configuration");
        } catch (IOException e) {
            System.err.println("保存配置失败：" + e.getMessage());
        }
    }
    
    public String get(String key) {
        return properties.getProperty(key);
    }
    
    public String get(String key, String defaultValue) {
        return properties.getProperty(key, defaultValue);
    }
    
    public void set(String key, String value) {
        properties.setProperty(key, value);
    }
    
    public static void main(String[] args) {
        ConfigManager config = new ConfigManager("app.properties");
        
        config.set("app.name", "MyApplication");
        config.set("app.version", "1.0.0");
        config.set("database.url", "jdbc:mysql://localhost:3306/mydb");
        
        config.save();
        
        System.out.println("应用名称：" + config.get("app.name"));
        System.out.println("作者：" + config.get("author", "Unknown"));
    }
}
```

### 示例3：日志记录器

```java
import java.io.*;
import java.nio.file.*;
import java.time.*;
import java.time.format.*;

public class SimpleLogger {
    private Path logFile;
    private DateTimeFormatter formatter;
    
    public SimpleLogger(String logFile) {
        this.logFile = Path.of(logFile);
        this.formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    }
    
    public void log(String level, String message) {
        String timestamp = LocalDateTime.now().format(formatter);
        String logEntry = String.format("[%s] [%s] %s%n", 
                                       timestamp, level, message);
        
        try {
            Files.writeString(logFile, logEntry, 
                StandardOpenOption.CREATE, 
                StandardOpenOption.APPEND);
        } catch (IOException e) {
            System.err.println("写入日志失败：" + e.getMessage());
        }
    }
    
    public void info(String message) {
        log("INFO", message);
    }
    
    public void warn(String message) {
        log("WARN", message);
    }
    
    public void error(String message) {
        log("ERROR", message);
    }
    
    public static void main(String[] args) {
        SimpleLogger logger = new SimpleLogger("app.log");
        
        logger.info("应用程序启动");
        logger.warn("内存使用超过80%");
        logger.error("数据库连接失败");
        logger.info("应用程序关闭");
    }
}
```
