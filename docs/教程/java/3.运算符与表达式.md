# 第三章 运算符与表达式

## 3.1 运算符概述

运算符是用于执行特定操作的符号。Java提供了丰富的运算符，包括算术运算符、关系运算符、逻辑运算符、位运算符、赋值运算符等。理解运算符的优先级和结合性对于编写正确的表达式至关重要。

## 3.2 算术运算符

算术运算符用于执行基本的数学运算：

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| + | 加法 | 5 + 3 | 8 |
| - | 减法 | 5 - 3 | 2 |
| * | 乘法 | 5 * 3 | 15 |
| / | 除法 | 5 / 3 | 1（整数除法） |
| % | 取模（求余） | 5 % 3 | 2 |

```java
int a = 17, b = 5;
System.out.println("a + b = " + (a + b));   // 22
System.out.println("a - b = " + (a - b));   // 12
System.out.println("a * b = " + (a * b));   // 85
System.out.println("a / b = " + (a / b));   // 3
System.out.println("a % b = " + (a % b));   // 2
```

### 整数除法与浮点除法

```java
int x = 5, y = 2;
double result1 = x / y;             // 2.0，整数除法后转换为double
double result2 = (double) x / y;    // 2.5，浮点除法
```

### 自增自减运算符

```java
int a = 5;
int b = ++a;    // 前缀自增：a先变为6，然后b赋值为6
int c = a++;    // 后缀自增：c赋值为6，然后a变为7
```

前缀形式先修改变量值，再使用；后缀形式先使用变量值，再修改。

## 3.3 关系运算符

关系运算符用于比较两个值，结果为boolean类型：

| 运算符 | 含义 | 示例 | 结果（a=5, b=3） |
|--------|------|------|------------------|
| == | 等于 | a == b | false |
| != | 不等于 | a != b | true |
| > | 大于 | a > b | true |
| < | 小于 | a < b | false |
| >= | 大于等于 | a >= b | true |
| <= | 小于等于 | a <= b | false |

```java
int a = 5, b = 3;
System.out.println(a > b);      // true
System.out.println(a == b);     // false
System.out.println(a != b);     // true
```

注意区分赋值运算符`=`和等于运算符`==`：

```java
if (a = 5) {        // 编译错误：int不能转换为boolean
}

if (a == 5) {       // 正确：判断a是否等于5
}
```

## 3.4 逻辑运算符

逻辑运算符用于组合多个条件：

| 运算符 | 含义 | 示例 | 说明 |
|--------|------|------|------|
| && | 逻辑与 | a && b | 两者都为true时结果为true |
| || | 逻辑或 | a || b | 至少一个为true时结果为true |
| ! | 逻辑非 | !a | true变false，false变true |
| ^ | 逻辑异或 | a ^ b | 两者不同时结果为true |

```java
int age = 25;
int income = 50000;

if (age >= 18 && age <= 60) {
    System.out.println("年龄在18到60岁之间");
}

if (income > 100000 || age < 30) {
    System.out.println("符合条件");
}

if (!(age < 18)) {
    System.out.println("已成年");
}
```

### 短路求值

逻辑运算符采用短路求值策略：

```java
int a = 0, b = 5;

if (a != 0 && b / a > 2) {      // a != 0为false，不计算b / a，避免除零错误
}

if (a == 0 || b > 3) {          // a == 0为true，不计算b > 3
}
```

## 3.5 位运算符

位运算符直接对整数的二进制位进行操作：

| 运算符 | 含义 | 示例 | 说明 |
|--------|------|------|------|
| & | 按位与 | a & b | 对应位都为1时结果为1 |
| | | 按位或 | a | b | 对应位至少一个为1时结果为1 |
| ^ | 按位异或 | a ^ b | 对应位不同时结果为1 |
| ~ | 按位取反 | ~a | 0变1，1变0 |
| << | 左移 | a << 2 | 各位左移2位，右侧补0 |
| >> | 右移 | a >> 2 | 各位右移2位，左侧补符号位 |
| >>> | 无符号右移 | a >>> 2 | 各位右移2位，左侧补0 |

```java
int a = 5;      // 二进制：0000 0101
int b = 3;      // 二进制：0000 0011

System.out.println(a & b);      // 1，二进制：0000 0001
System.out.println(a | b);      // 7，二进制：0000 0111
System.out.println(a ^ b);      // 6，二进制：0000 0110
System.out.println(~a);         // -6，二进制：1111 1010
System.out.println(a << 1);     // 10，二进制：0000 1010
System.out.println(a >> 1);     // 2，二进制：0000 0010
```

### 位运算的应用

```java
// 设置第n位为1
flags |= (1 << n);

// 设置第n位为0
flags &= ~(1 << n);

// 切换第n位
flags ^= (1 << n);

// 检查第n位是否为1
if ((flags & (1 << n)) != 0) {
    // 第n位为1
}
```

## 3.6 赋值运算符

### 简单赋值

```java
int a = 10;
```

### 复合赋值

```java
int a = 10;
a += 5;             // 等价于 a = a + 5
a -= 3;             // 等价于 a = a - 3
a *= 2;             // 等价于 a = a * 2
a /= 4;             // 等价于 a = a / 4
a %= 3;             // 等价于 a = a % 3

// 位运算复合赋值
a &= 0xFF;
a |= 0x10;
a ^= 0x01;
a <<= 2;
a >>= 1;
```

### 多重赋值

```java
int a, b, c;
a = b = c = 0;      // 从右向左赋值，a、b、c都为0
```

## 3.7 条件运算符

条件运算符是Java中唯一的三目运算符：

```java
条件 ? 表达式1 : 表达式2
```

如果条件为true，则返回表达式1的值；否则返回表达式2的值。

```java
int a = 5, b = 3;
int max = (a > b) ? a : b;      // max的值为5

// 等价于
int max;
if (a > b) {
    max = a;
} else {
    max = b;
}
```

条件运算符可以嵌套使用，但过度嵌套会降低代码可读性：

```java
int score = 85;
char grade = (score >= 90) ? 'A' :
             (score >= 80) ? 'B' :
             (score >= 70) ? 'C' :
             (score >= 60) ? 'D' : 'F';
```

## 3.8 instanceof运算符

instanceof用于测试对象是否是指定类型或其子类型的实例：

```java
String str = "Hello";
if (str instanceof String) {
    System.out.println("str是String类型");
}

Object obj = "World";
if (obj instanceof String) {
    System.out.println("obj可以转换为String");
}
```

Java 16引入了模式匹配的instanceof：

```java
if (obj instanceof String s) {
    // s已经是String类型，无需强制转换
    System.out.println(s.length());
}
```

## 3.9 运算符优先级

运算符优先级决定了表达式中运算的执行顺序：

| 优先级 | 运算符 |
|--------|--------|
| 1（最高） | ()、[]、. |
| 2 | ++、--、+（正）、-（负）、~、! |
| 3 | *、/、% |
| 4 | +、- |
| 5 | <<、>>、>>> |
| 6 | <、<=、>、>=、instanceof |
| 7 | ==、!= |
| 8 | & |
| 9 | ^ |
| 10 | || |
| 11 | && |
| 12 | || |
| 13 | ?: |
| 14 | =、+=、-= 等 |
| 15（最低） | , |

```java
int a = 5, b = 3, c = 2;
int result = a + b * c;         // 先算b * c，再加a，结果为11

boolean x = a > b && b > c;     // 先算a > b和b > c，再算&&，结果为true

// 使用括号明确运算顺序
int y = (a + b) * c;            // 结果为16
```

## 3.10 类型转换运算符

```java
double d = 3.14;
int i = (int) d;                // 强制类型转换

Object obj = "Hello";
String str = (String) obj;      // 向下转型
```

## 3.11 综合示例

```java
public class OperatorDemo {
    public static void main(String[] args) {
        // 算术运算
        int a = 17, b = 5;
        System.out.println("算术运算：");
        System.out.println(a + " + " + b + " = " + (a + b));
        System.out.println(a + " - " + b + " = " + (a - b));
        System.out.println(a + " * " + b + " = " + (a * b));
        System.out.println(a + " / " + b + " = " + (a / b));
        System.out.println(a + " % " + b + " = " + (a % b));
        
        // 关系运算
        System.out.println("\n关系运算：");
        System.out.println(a + " > " + b + ": " + (a > b));
        System.out.println(a + " == " + b + ": " + (a == b));
        
        // 位运算
        System.out.println("\n位运算：");
        int x = 0x0F;
        int y = 0xF0;
        System.out.printf("0x%02X & 0x%02X = 0x%02X%n", x, y, x & y);
        System.out.printf("0x%02X | 0x%02X = 0x%02X%n", x, y, x | y);
        System.out.printf("0x%02X ^ 0x%02X = 0x%02X%n", x, y, x ^ y);
        System.out.printf("~0x%02X = 0x%02X%n", x, ~x);
        System.out.printf("0x%02X << 2 = 0x%02X%n", x, x << 2);
        
        // 条件运算
        int max = (a > b) ? a : b;
        System.out.println("\n条件运算：");
        System.out.println("max(" + a + ", " + b + ") = " + max);
        
        // 复合赋值
        int n = 10;
        System.out.println("\n复合赋值：");
        System.out.println("n = " + n);
        n += 5;
        System.out.println("n += 5: " + n);
        n *= 2;
        System.out.println("n *= 2: " + n);
    }
}
```
