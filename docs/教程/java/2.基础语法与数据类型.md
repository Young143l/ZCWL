# 第二章 基础语法与数据类型

## 2.1 标识符与关键字

### 标识符

标识符是程序中用于命名变量、方法、类、接口等的字符序列。Java标识符的命名规则如下：

- 由字母、数字、下划线（_）和美元符号（$）组成
- 不能以数字开头
- 区分大小写
- 不能是Java关键字
- 建议使用有意义的名称

有效的标识符示例：`name`、`age`、`_value`、`$amount`、`studentName`

无效的标识符示例：`2name`（以数字开头）、`class`（关键字）、`my-name`（包含连字符）

### 关键字

关键字是Java语言预定义的具有特殊含义的单词，不能用作标识符。Java关键字包括：

| 类别 | 关键字 |
|------|--------|
| 数据类型 | byte、short、int、long、float、double、char、boolean |
| 流程控制 | if、else、switch、case、default、while、do、for、break、continue、return |
| 访问修饰符 | public、private、protected |
| 类与对象 | class、interface、extends、implements、new、this、super |
| 其他修饰符 | static、final、abstract、synchronized、volatile、transient、native、strictfp |
| 包相关 | package、import |
| 异常处理 | try、catch、finally、throw、throws |
| 其他 | instanceof、void、null、true、false、enum、assert、goto（保留但未使用）、const（保留但未使用） |

## 2.2 变量

### 变量的声明

变量是程序中存储数据的容器，必须先声明后使用：

```java
// 声明单个变量
int age;
String name;

// 同时声明多个同类型变量
int a, b, c;

// 声明并初始化
int score = 90;
double price = 19.99;
String message = "Hello";
```

### 变量的作用域

变量的作用域决定了变量的可见范围：

```java
public class ScopeExample {
    // 成员变量（实例变量），在整个类中可见
    private int instanceVar = 10;
    
    // 静态变量，属于类，在所有实例中共享
    private static int staticVar = 20;
    
    public void method() {
        // 局部变量，只在方法内可见
        int localVar = 30;
        
        if (localVar > 0) {
            // 块变量，只在代码块内可见
            int blockVar = 40;
            System.out.println(blockVar);
        }
        // blockVar在此处不可见
    }
}
```

## 2.3 基本数据类型

Java的数据类型分为基本数据类型和引用数据类型两大类。

### 整数类型

| 类型 | 大小 | 取值范围 |
|------|------|----------|
| byte | 1字节 | -128 至 127 |
| short | 2字节 | -32768 至 32767 |
| int | 4字节 | -2147483648 至 2147483647 |
| long | 8字节 | -9223372036854775808 至 9223372036854775807 |

```java
byte b = 100;
short s = 10000;
int i = 100000;
long l = 10000000000L;      // long类型需要加L或l后缀
```

### 浮点类型

| 类型 | 大小 | 精度 | 取值范围 |
|------|------|------|----------|
| float | 4字节 | 6-7位有效数字 | 约 ±3.4E-38 至 ±3.4E+38 |
| double | 8字节 | 15-16位有效数字 | 约 ±1.7E-308 至 ±1.7E+308 |

```java
float f = 3.14f;            // float类型需要加F或f后缀
double d = 3.14159;         // 默认是double类型
double e = 3.14e10;         // 科学计数法
```

### 字符类型

char类型用于存储单个Unicode字符，占用2字节：

```java
char c1 = 'A';
char c2 = '中';             // 支持中文
char c3 = '\u0041';         // Unicode编码表示'A'
char c4 = '\n';             // 转义字符
```

常用转义字符：

| 转义字符 | 含义 |
|----------|------|
| \n | 换行 |
| \t | 水平制表符 |
| \r | 回车 |
| \\ | 反斜杠 |
| \' | 单引号 |
| \" | 双引号 |
| \b | 退格 |
| \f | 换页 |

### 布尔类型

boolean类型只有两个取值：true和false：

```java
boolean flag = true;
boolean isEmpty = false;
```

### 类类型


## 2.5 类型转换

### 自动类型转换

当目标类型的范围大于源类型时，自动进行类型转换：

```java
byte b = 10;
int i = b;                  // 自动转换：byte -> int
long l = i;                 // 自动转换：int -> long
double d = l;               // 自动转换：long -> double
```

转换方向：byte -> short -> int -> long -> float -> double

### 强制类型转换

当目标类型的范围小于源类型时，需要显式强制转换：

```java
double d = 3.14;
int i = (int) d;            // 强制转换，小数部分截断

long l = 100L;
int j = (int) l;            // 强制转换
```

强制转换可能导致数据精度损失或溢出，使用时需谨慎。

### 表达式中的类型提升

```java
byte a = 10;
byte b = 20;
int c = a + b;              // a和b先提升为int，再进行运算
```

## 2.6 常量

### 字面常量

```java
100                         // 整型常量
3.14                        // 浮点型常量
' A'                         // 字符常量
"Hello"                     // 字符串常量
true                        // 布尔常量
null                        // 空引用常量
```

### final常量

使用final关键字定义常量，常量只能赋值一次：

```java
final int MAX_SIZE = 100;
final double PI = 3.14159;
final String APP_NAME = "MyApplication";

// MAX_SIZE = 200;          // 错误：不能修改final变量
```

### 静态常量

通常将常量定义为静态的，使其属于类而非实例：

```java
public class Constants {
    public static final int MAX_USERS = 1000;
    public static final String VERSION = "1.0.0";
    public static final double PI = 3.14159265359;
}
```

## 2.7 字符串

String类用于表示不可变的字符序列：

```java
String str1 = "Hello";
String str2 = new String("World");

// 字符串连接
String greeting = str1 + ", " + str2 + "!";

// 字符串长度
int len = str1.length();

// 获取字符
char c = str1.charAt(0);    // 'H'

// 子串
String sub = str1.substring(1, 3);  // "el"

// 比较
boolean equal = str1.equals("Hello");   // true
boolean ignoreCase = str1.equalsIgnoreCase("hello"); // true

// 查找
int index = str1.indexOf('l');      // 2
boolean contains = str1.contains("ell"); // true

// 替换
String replaced = str1.replace('l', 'x');   // "Hexxo"

// 分割
String[] parts = "a,b,c".split(",");    // ["a", "b", "c"]
```

## 2.8 输入输出

### 标准输出

```java
System.out.println("Hello");        // 输出并换行
System.out.print("Hello");          // 输出不换行
System.out.printf("Name: %s, Age: %d%n", "Alice", 20);  // 格式化输出
```

格式化说明符：

| 说明符 | 含义 |
|--------|------|
| %s | 字符串 |
| %d | 十进制整数 |
| %f | 浮点数 |
| %c | 字符 |
| %b | 布尔值 |
| %n | 换行符 |
| %t | 日期时间 |

### 标准输入

```java
import java.util.Scanner;

Scanner scanner = new Scanner(System.in);

System.out.print("请输入姓名：");
String name = scanner.nextLine();

System.out.print("请输入年龄：");
int age = scanner.nextInt();

System.out.print("请输入成绩：");
double score = scanner.nextDouble();

scanner.close();
```

## 2.9 综合示例

```java
import java.util.Scanner;

public class StudentInfo {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        
        // 输入学生信息
        System.out.print("请输入学生姓名：");
        String name = scanner.nextLine();
        
        System.out.print("请输入年龄：");
        int age = scanner.nextInt();
        
        System.out.print("请输入语文成绩：");
        double chinese = scanner.nextDouble();
        
        System.out.print("请输入数学成绩：");
        double math = scanner.nextDouble();
        
        System.out.print("请输入英语成绩：");
        double english = scanner.nextDouble();
        
        // 计算平均分
        double average = (chinese + math + english) / 3;
        
        // 输出结果
        System.out.println("\n学生信息：");
        System.out.println("姓名：" + name);
        System.out.println("年龄：" + age);
        System.out.printf("平均分：%.2f%n", average);
        
        scanner.close();
    }
}
```
