# 第九章 常用类库

## 9.1 Object类

Object是所有Java类的根类，提供了一些通用的方法。

### toString方法

返回对象的字符串表示：

```java
public class Person {
    private String name;
    private int age;
    
    @Override
    public String toString() {
        return "Person{name='" + name + "', age=" + age + "}";
    }
}
```

### equals方法

比较两个对象是否相等：

```java
@Override
public boolean equals(Object obj) {
    if (this == obj) return true;
    if (obj == null || getClass() != obj.getClass()) return false;
    Person person = (Person) obj;
    return age == person.age && Objects.equals(name, person.name);
}
```

### hashCode方法

返回对象的哈希码：

```java
@Override
public int hashCode() {
    return Objects.hash(name, age);
}
```

### getClass方法

获取对象的运行时类：

```java
Person p = new Person();
Class<?> clazz = p.getClass();
System.out.println(clazz.getName());    // 输出类名
```

## 9.2 String类

String是不可变的字符序列。

### 创建字符串

```java
String str1 = "Hello";                      // 字符串常量
String str2 = new String("Hello");          // 使用构造方法
String str3 = new String(charArray);        // 从字符数组创建
```

### 常用方法

```java
String str = "Hello, World!";

// 获取长度
int len = str.length();                     // 13

// 获取字符
char c = str.charAt(0);                     // 'H'

// 子串
String sub1 = str.substring(7);             // "World!"
String sub2 = str.substring(0, 5);          // "Hello"

// 查找
int index1 = str.indexOf('o');              // 4
int index2 = str.indexOf("World");          // 7
int index3 = str.lastIndexOf('o');          // 8
boolean contains = str.contains("World");   // true

// 比较
boolean equal = str.equals("Hello, World!");                    // true
boolean ignoreCase = str.equalsIgnoreCase("hello, world!");     // true
int compare = str.compareTo("Hello");                           // 正数

// 替换
String replaced = str.replace('o', 'x');            // "Hellx, Wxrld!"
String replaced2 = str.replace("World", "Java");    // "Hello, Java!"

// 分割
String[] parts = "a,b,c".split(",");        // ["a", "b", "c"]

// 去除空白
String trimmed = "  hello  ".trim();        // "hello"

// 大小写转换
String upper = str.toUpperCase();           // "HELLO, WORLD!"
String lower = str.toLowerCase();           // "hello, world!"

// 判空
boolean empty = str.isEmpty();              // false
boolean blank = str.isBlank();              // false（Java 11+）
```

### StringBuilder和StringBuffer

可变字符串，用于频繁修改字符串的场景：

```java
// StringBuilder（非线程安全，更快）
StringBuilder sb = new StringBuilder();
sb.append("Hello");
sb.append(" ");
sb.append("World");
sb.insert(5, ",");
sb.delete(5, 6);
sb.reverse();
String result = sb.toString();

// StringBuffer（线程安全）
StringBuffer sbf = new StringBuffer();
sbf.append("Hello");
```

## 9.9 正则表达式

```java

    System.out.println(matcher.group());    // 123, 456
```

## 9.10 综合示例

### 示例1：字符串工具类

```java
public class StringUtils {
    
    // 判断字符串是否为空
    public static boolean isEmpty(String str) {
        return str == null || str.isEmpty();
    }
    
    // 判断字符串是否为空白
    public static boolean isBlank(String str) {
        return str == null || str.trim().isEmpty();
    }
    
    // 反转字符串
    public static String reverse(String str) {
        if (str == null) return null;
        return new StringBuilder(str).reverse().toString();
    }
    
    // 驼峰命名转下划线
    public static String camelToUnderscore(String str) {
        if (str == null) return null;
        return str.replaceAll("([a-z])([A-Z])", "$1_$2").toLowerCase();
    }
    
    // 下划线转驼峰命名
    public static String underscoreToCamel(String str) {
        if (str == null) return null;
        StringBuilder sb = new StringBuilder();
        String[] parts = str.split("_");
        sb.append(parts[0].toLowerCase());
        for (int i = 1; i < parts.length; i++) {
            sb.append(parts[i].substring(0, 1).toUpperCase());
            sb.append(parts[i].substring(1).toLowerCase());
        }
        return sb.toString();
    }
    
    public static void main(String[] args) {
        System.out.println(reverse("Hello"));
        System.out.println(camelToUnderscore("userName"));
        System.out.println(underscoreToCamel("user_name"));
    }
}
```

### 示例2：日期工具类

```java
import java.time.*;
import java.time.format.*;
import java.time.temporal.*;

public class DateUtils {
    
    private static final DateTimeFormatter DEFAULT_FORMATTER = 
        DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
    
    // 获取当前日期时间字符串
    public static String now() {
        return LocalDateTime.now().format(DEFAULT_FORMATTER);
    }
    
    // 格式化日期时间
    public static String format(LocalDateTime dateTime, String pattern) {
        return dateTime.format(DateTimeFormatter.ofPattern(pattern));
    }
    
    // 解析日期时间
    public static LocalDateTime parse(String text, String pattern) {
        return LocalDateTime.parse(text, DateTimeFormatter.ofPattern(pattern));
    }
    
    // 获取年龄
    public static int getAge(LocalDate birthDate) {
        return Period.between(birthDate, LocalDate.now()).getYears();
    }
    
    // 获取两个日期之间的天数
    public static long daysBetween(LocalDate start, LocalDate end) {
        return ChronoUnit.DAYS.between(start, end);
    }
    
    // 判断是否为闰年
    public static boolean isLeapYear(int year) {
        return Year.of(year).isLeap();
    }
    
    public static void main(String[] args) {
        System.out.println("当前时间：" + now());
        System.out.println("年龄：" + getAge(LocalDate.of(2000, 1, 1)));
        System.out.println("2024是否为闰年：" + isLeapYear(2024));
    }
}
```
