# 第二章 数据类型与变量

## 2.1 数据类型概述

C语言是一种强类型语言，每个变量都必须明确指定其数据类型。数据类型决定了变量在内存中占用的空间大小、可表示的数值范围以及可进行的操作。

C语言的数据类型可分为以下几类：

- **基本类型**：整型、浮点型、字符型
- **构造类型**：数组、结构体、联合体、枚举
- **指针类型**：指向内存地址的变量
- **空类型**：void类型，表示无类型

## 2.2 整型数据类型

整型用于表示整数，根据取值范围和内存占用大小，分为以下几种：

| 类型 | 典型大小 | 取值范围（32位系统） |
|------|----------|---------------------|
| short | 2字节 | -32768 至 32767 |
| int | 4字节 | -2147483648 至 2147483647 |
| long | 4或8字节 | 与平台相关 |
| long long | 8字节 | -9223372036854775808 至 9223372036854775807 |

整型还可以使用`signed`（有符号，默认）和`unsigned`（无符号）修饰符：

```c
signed int a;      /* 有符号整数，可表示正负数 */
unsigned int b;    /* 无符号整数，只能表示非负数，正数范围扩大一倍 */
```

### 整型常量

整型常量可以用十进制、八进制或十六进制表示：

```c
int dec = 100;      /* 十进制 */
int oct = 0144;     /* 八进制，以0开头 */
int hex = 0x64;     /* 十六进制，以0x或0X开头 */
```

整型常量还可以添加后缀指定类型：

```c
long a = 100L;           /* L或l表示long类型 */
unsigned long b = 100UL; /* U或u表示unsigned类型 */
long long c = 100LL;     /* LL或ll表示long long类型 */
```

## 2.3 浮点型数据类型

浮点型用于表示实数，即带有小数部分的数值：

| 类型 | 典型大小 | 精度 | 取值范围（约） |
|------|----------|------|----------------|
| float | 4字节 | 6-7位有效数字 | 3.4E-38 至 3.4E+38 |
| double | 8字节 | 15-16位有效数字 | 1.7E-308 至 1.7E+308 |
| long double | 8或16字节 | 与平台相关 | 与平台相关 |

### 浮点型常量

浮点型常量可以用小数形式或指数形式表示：

```c
double a = 3.14159;     /* 小数形式 */
double b = 3.14159e0;   /* 指数形式，e或E表示乘以10的幂 */
double c = 314.159e-2;  /* 等价于3.14159 */

float d = 3.14f;        /* f或F后缀表示float类型 */
long double e = 3.14L;  /* L或l后缀表示long double类型 */
```

## 2.4 字符型数据类型

字符型用于存储单个字符，在内存中占用1字节：

```c
char ch = 'A';          /* 字符常量用单引号括起来 */
```

字符在内存中以其ASCII码值存储，因此字符型本质上是一种特殊的整型：

```c
char ch = 'A';
int code = ch;          /* code的值为65，即'A'的ASCII码 */
char next = ch + 1;     /* next的值为'B' */
```

### 转义字符

C语言提供了一些特殊的转义字符，用于表示不可打印字符：

| 转义字符 | 含义 |
|----------|------|
| \n | 换行 |
| \t | 水平制表符 |
| \r | 回车 |
| \\ | 反斜杠 |
| \' | 单引号 |
| \" | 双引号 |
| \0 | 空字符（字符串结束标志） |
| \xhh | 十六进制表示的字符 |

```c
char newline = '\n';
char tab = '\t';
char quote = '\'';
char hex_char = '\x41';  /* 等价于'A' */
```

## 2.5 变量声明与定义

### 变量声明

变量声明告诉编译器变量的名称和类型，但不分配内存：

```c
extern int global_var;  /* 声明一个在其他文件中定义的全局变量 */
```

### 变量定义

变量定义不仅声明了变量的名称和类型，还为其分配了内存空间：

```c
int count;              /* 定义一个int类型变量 */
double price = 19.99;   /* 定义并初始化 */
```

### 变量初始化

变量在定义时可以同时赋初值：

```c
int a = 10;
int b = 20, c = 30;     /* 同时定义多个变量 */
int d, e = 5;           /* d未初始化，e初始化为5 */
```

未初始化的局部变量包含不确定的值，使用前应确保赋值：

```c
int x;
printf("%d\n", x);      /* 危险：x的值不确定 */
```

## 2.6 常量

### 字面常量

字面常量是直接出现在代码中的固定值：

```c
100         /* 整型常量 */
3.14        /* 浮点型常量 */
'A'         /* 字符常量 */
"Hello"     /* 字符串常量 */
```

### 符号常量

使用`#define`预处理指令或`const`关键字定义符号常量：

```c
#define PI 3.14159          /* 宏定义常量 */
#define MAX_SIZE 100

const double PI = 3.14159;  /* const常量 */
const int MAX_SIZE = 100;
```

`#define`定义的常量在预处理阶段进行文本替换，不占用内存；`const`定义的常量是只读变量，占用内存空间。

### 枚举常量

枚举类型用于定义一组命名的整数常量：

```c
enum Color {
    RED,        /* 默认值为0 */
    GREEN,      /* 值为1 */
    BLUE        /* 值为2 */
};

enum Color c = RED;         /* 使用枚举常量 */

enum Status {
    OK = 200,
    NOT_FOUND = 404,
    ERROR = 500
};
```

## 2.7 类型转换

### 隐式类型转换

当不同类型的数据进行运算时，编译器会自动进行类型转换：

```c
int a = 5;
double b = 2.5;
double result = a + b;      /* a自动转换为double类型 */
```

转换规则遵循从低精度到高精度的方向：

```
char -> short -> int -> long -> long long
                    |
                    v
                  float -> double -> long double
```

### 显式类型转换（强制类型转换）

使用强制类型转换运算符可以明确指定类型转换：

```c
int a = 5, b = 2;
double result = (double)a / b;  /* 将a转换为double，进行浮点除法 */

int x = (int)3.14;              /* 将double转换为int，小数部分截断 */
```

强制类型转换可能导致数据精度损失，使用时需谨慎。

## 2.8 sizeof运算符

`sizeof`运算符用于获取数据类型或变量在内存中占用的字节数：

```c
printf("sizeof(char) = %zu\n", sizeof(char));           /* 1 */
printf("sizeof(int) = %zu\n", sizeof(int));             /* 4 */
printf("sizeof(double) = %zu\n", sizeof(double));       /* 8 */

int arr[10];
printf("sizeof(arr) = %zu\n", sizeof(arr));             /* 40（假设int为4字节） */
```

`sizeof`的返回值类型是`size_t`，在打印时应使用`%zu`格式说明符。

## 2.9 typedef关键字

`typedef`用于为已有的数据类型创建别名：

```c
typedef unsigned int uint;      /* 为unsigned int创建别名uint */
typedef long long int64;        /* 为long long创建别名int64 */

uint a = 100;                   /* 使用别名定义变量 */
int64 b = 10000000000LL;
```

`typedef`常用于简化复杂类型的声明：

```c
typedef struct {
    int x;
    int y;
} Point;                        /* 为结构体创建别名 */

Point p1;                       /* 直接使用别名定义结构体变量 */
```

## 2.10 综合示例

```c
#include <stdio.h>
#include <limits.h>
#include <float.h>

int main(void)
{
    /* 整型变量示例 */
    short s = 100;
    int i = 100000;
    long l = 1000000000L;
    long long ll = 9000000000000LL;
    
    /* 浮点型变量示例 */
    float f = 3.14159f;
    double d = 2.718281828459045;
    long double ld = 1.4142135623730950488L;
    
    /* 字符型变量示例 */
    char ch = 'A';
    unsigned char uc = 255;
    
    /* 输出各类型的大小 */
    printf("数据类型大小（字节）：\n");
    printf("short: %zu\n", sizeof(short));
    printf("int: %zu\n", sizeof(int));
    printf("long: %zu\n", sizeof(long));
    printf("long long: %zu\n", sizeof(long long));
    printf("float: %zu\n", sizeof(float));
    printf("double: %zu\n", sizeof(double));
    printf("long double: %zu\n", sizeof(long double));
    printf("char: %zu\n", sizeof(char));
    
    /* 输出取值范围 */
    printf("\n整型取值范围：\n");
    printf("INT_MIN = %d, INT_MAX = %d\n", INT_MIN, INT_MAX);
    printf("LONG_MIN = %ld, LONG_MAX = %ld\n", LONG_MIN, LONG_MAX);
    
    printf("\n浮点型取值范围：\n");
    printf("FLT_MIN = %e, FLT_MAX = %e\n", FLT_MIN, FLT_MAX);
    printf("DBL_MIN = %e, DBL_MAX = %e\n", DBL_MIN, DBL_MAX);
    
    /* 类型转换示例 */
    int a = 7, b = 2;
    printf("\n类型转换示例：\n");
    printf("整数除法：7 / 2 = %d\n", a / b);
    printf("浮点除法：7 / 2 = %.2f\n", (double)a / b);
    
    return 0;
}
```
