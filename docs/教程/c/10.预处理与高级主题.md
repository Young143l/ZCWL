# 第十章 预处理与高级主题

## 10.1 预处理器概述

预处理器是C编译器的一部分，在编译之前对源代码进行处理。预处理器指令以井号`#`开头，主要包括宏定义、文件包含和条件编译等。合理使用预处理功能可以提高代码的可移植性、可读性和可维护性。

## 10.2 宏定义

### 简单宏定义

```c
#define PI 3.14159
#define MAX_SIZE 100
#define GREETING "Hello, World!"
```

宏定义在预处理阶段进行文本替换，不占用内存空间。

### 带参数的宏

```c
#define SQUARE(x) ((x) * (x))
#define MAX(a, b) ((a) > (b) ? (a) : (b))
#define MIN(a, b) ((a) < (b) ? (a) : (b))
```

注意：参数和整个表达式都应使用括号，避免运算符优先级问题。

```c
int result = SQUARE(5);         /* 展开为 ((5) * (5)) = 25 */
int max = MAX(3, 7);            /* 展开为 ((3) > (7) ? (3) : (7)) = 7 */
```

### 多行宏

```c
#define PRINT_DEBUG(msg) do { \
    printf("[DEBUG] %s:%d: ", __FILE__, __LINE__); \
    printf(msg); \
    printf("\n"); \
} while(0)
```

使用`do-while(0)`包裹多行宏，确保宏在任何上下文中都能正确使用。

### 预定义宏

C语言提供了一些预定义的宏：

| 宏 | 含义 |
|----|------|
| `__FILE__` | 当前源文件名 |
| `__LINE__` | 当前行号 |
| `__DATE__` | 编译日期 |
| `__TIME__` | 编译时间 |
| `__func__` | 当前函数名（C99） |

```c
printf("文件：%s\n", __FILE__);
printf("行号：%d\n", __LINE__);
printf("编译日期：%s\n", __DATE__);
printf("编译时间：%s\n", __TIME__);
```

### 宏的取消定义

```c
#undef PI
```

## 10.3 文件包含

### 标准头文件包含

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
```

### 用户头文件包含

```c
#include "myheader.h"
#include "utils/math.h"
```

尖括号`<>`用于包含系统头文件，编译器在系统目录中查找；双引号`""`用于包含用户头文件，编译器先在当前目录查找，再到系统目录查找。

### 头文件保护

防止头文件被重复包含：

```c
#ifndef MYHEADER_H
#define MYHEADER_H

/* 头文件内容 */

#endif /* MYHEADER_H */
```

或使用`#pragma once`（非标准但被广泛支持）：

```c
#pragma once

/* 头文件内容 */
```

## 10.4 条件编译

### #ifdef和#ifndef

```c
#define DEBUG

#ifdef DEBUG
    printf("调试信息\n");
#endif

#ifndef PI
    #define PI 3.14159
#endif
```

### #if、#elif、#else

```c
#define VERSION 2

#if VERSION == 1
    /* 版本1的代码 */
#elif VERSION == 2
    /* 版本2的代码 */
#else
    /* 其他版本的代码 */
#endif
```

### defined运算符

```c
#if defined(DEBUG) && !defined(RELEASE)
    printf("调试模式\n");
#endif
```

### 平台相关代码

```c
#ifdef _WIN32
    /* Windows平台代码 */
    #include <windows.h>
#elif defined(__linux__)
    /* Linux平台代码 */
    #include <unistd.h>
#elif defined(__APPLE__)
    /* macOS平台代码 */
#endif
```

## 10.5 其他预处理指令

### #error

产生编译错误：

```c
#ifndef __STDC__
    #error "需要标准C编译器"
#endif
```

### #warning

产生编译警告（GCC扩展）：

```c
#warning "此功能已弃用"
```

### #line

修改行号和文件名：

```c
#line 100 "newfile.c"
/* 从此处开始，行号从100计数，文件名为newfile.c */
```

## 10.6 高级数据类型

### 复数类型（C99）

```c
#include <complex.h>

double complex z1 = 1.0 + 2.0*I;
double complex z2 = 3.0 - 4.0*I;

double complex sum = z1 + z2;
double complex product = z1 * z2;

double real = creal(sum);
double imag = cimag(sum);
double magnitude = cabs(sum);
```

### 布尔类型（C99）

```c
#include <stdbool.h>

bool flag = true;           /* 或 false */
if (flag) {
    /* ... */
}
```

### 定长整数类型（C99）

```c
#include <stdint.h>

int8_t i8;                  /* 8位有符号整数 */
uint8_t u8;                 /* 8位无符号整数 */
int16_t i16;                /* 16位有符号整数 */
uint32_t u32;               /* 32位无符号整数 */
int64_t i64;                /* 64位有符号整数 */

uintptr_t ptr_int;          /* 可以存储指针的整数类型 */
```

## 10.7 变长数组（C99）

变长数组的大小在运行时确定：

```c
void process(int n)
{
    int arr[n];             /* 变长数组 */
    for (int i = 0; i < n; i++) {
        arr[i] = i;
    }
}
```

注意：变长数组不能初始化，其生命周期在离开作用域时结束。

## 10.8 内联函数与restrict

### 内联函数

```c
inline int max(int a, int b)
{
    return (a > b) ? a : b;
}
```

### restrict关键字

`restrict`用于优化指针访问，承诺指针是访问其所指内存的唯一方式：

```c
void add(int *restrict a, int *restrict b, int *restrict c, int n)
{
    for (int i = 0; i < n; i++) {
        c[i] = a[i] + b[i];
    }
}
```

## 10.9 原子操作（C11）

C11引入了原子类型和操作，用于多线程编程：

```c
#include <stdatomic.h>

atomic_int counter = 0;

void increment(void)
{
    atomic_fetch_add(&counter, 1);
}

int load(void)
{
    return atomic_load(&counter);
}
```

## 10.10 线程支持（C11）

C11提供了标准线程库：

```c
#include <threads.h>

int thread_func(void *arg)
{
    printf("线程ID: %lu\n", thrd_current());
    return 0;
}

int main(void)
{
    thrd_t thread;
    thrd_create(&thread, thread_func, NULL);
    thrd_join(thread, NULL);
    return 0;
}
```

## 10.11 泛型选择（C11）

`_Generic`实现类型泛化的表达式：

```c
#define abs(x) _Generic((x), \
    int: abs, \
    long: labs, \
    long long: llabs, \
    double: fabs, \
    float: fabsf \
)(x)

int i = abs(-5);            /* 调用abs */
double d = abs(-3.14);      /* 调用fabs */
```

## 10.12 静态断言（C11）

编译时断言，用于检查编译期条件：

```c
_Static_assert(sizeof(int) == 4, "int必须是4字节");
_Static_assert(CHAR_BIT == 8, "char必须是8位");
```

## 10.13 对齐支持（C11）

```c
#include <stdalign.h>

alignas(16) char buffer[1024];  /* 16字节对齐 */

size_t alignment = alignof(int);    /* 获取int的对齐要求 */
```

## 10.14 综合示例

### 示例1：调试宏

```c
#ifndef DEBUG_H
#define DEBUG_H

#include <stdio.h>

#ifdef DEBUG
    #define DEBUG_PRINT(fmt, ...) \
        fprintf(stderr, "[DEBUG] %s:%d:%s(): " fmt "\n", \
                __FILE__, __LINE__, __func__, ##__VA_ARGS__)
    #define DEBUG_ENTER() \
        fprintf(stderr, "[ENTER] %s:%d:%s()\n", \
                __FILE__, __LINE__, __func__)
    #define DEBUG_EXIT() \
        fprintf(stderr, "[EXIT] %s:%d:%s()\n", \
                __FILE__, __LINE__, __func__)
#else
    #define DEBUG_PRINT(fmt, ...) ((void)0)
    #define DEBUG_ENTER() ((void)0)
    #define DEBUG_EXIT() ((void)0)
#endif

#endif /* DEBUG_H */
```

### 示例2：跨平台代码

```c
#include <stdio.h>

/* 检测操作系统 */
#if defined(_WIN32) || defined(_WIN64)
    #define OS_WINDOWS
    #include <windows.h>
#elif defined(__linux__)
    #define OS_LINUX
    #include <unistd.h>
#elif defined(__APPLE__) && defined(__MACH__)
    #define OS_MACOS
    #include <unistd.h>
#else
    #define OS_UNKNOWN
#endif

/* 检测编译器 */
#if defined(__GNUC__)
    #define COMPILER_GCC
#elif defined(_MSC_VER)
    #define COMPILER_MSVC
#elif defined(__clang__)
    #define COMPILER_CLANG
#endif

/* 平台相关的睡眠函数 */
void sleep_ms(int ms)
{
    #ifdef OS_WINDOWS
        Sleep(ms);
    #elif defined(OS_LINUX) || defined(OS_MACOS)
        usleep(ms * 1000);
    #endif
}

int main(void)
{
    #ifdef OS_WINDOWS
        printf("Windows平台\n");
    #elif defined(OS_LINUX)
        printf("Linux平台\n");
    #elif defined(OS_MACOS)
        printf("macOS平台\n");
    #else
        printf("未知平台\n");
    #endif
    
    #ifdef COMPILER_GCC
        printf("GCC编译器\n");
    #elif defined(COMPILER_MSVC)
        printf("MSVC编译器\n");
    #elif defined(COMPILER_CLANG)
        printf("Clang编译器\n");
    #endif
    
    return 0;
}
```

### 示例3：泛型数学函数

```c
#include <stdio.h>
#include <math.h>

#define generic_sqrt(x) _Generic((x), \
    float: sqrtf, \
    double: sqrt, \
    long double: sqrtl \
)(x)

#define generic_abs(x) _Generic((x), \
    int: abs, \
    long: labs, \
    long long: llabs, \
    float: fabsf, \
    double: fabs, \
    long double: fabsl \
)(x)

int main(void)
{
    int i = -5;
    double d = -3.14;
    float f = -2.5f;
    
    printf("abs(%d) = %d\n", i, generic_abs(i));
    printf("abs(%f) = %f\n", d, generic_abs(d));
    printf("abs(%f) = %f\n", f, generic_abs(f));
    
    double x = 16.0;
    printf("sqrt(%f) = %f\n", x, generic_sqrt(x));
    
    return 0;
}
```

## 10.15 本章小结

本章详细介绍了C语言的预处理功能，包括宏定义、文件包含和条件编译。讲解了C99和C11标准引入的新特性，如复数类型、布尔类型、定长整数类型、变长数组、原子操作、线程支持和泛型选择。通过调试宏、跨平台代码和泛型函数等示例展示了这些高级特性的实际应用。掌握这些知识对于编写高质量、可移植的C程序具有重要意义。

## 10.16 学习建议

学习C语言需要理论与实践相结合：

1. **扎实基础**：深入理解数据类型、控制结构、函数和指针等核心概念
2. **大量练习**：通过编写程序巩固所学知识
3. **阅读源码**：学习优秀的开源项目代码
4. **理解底层**：了解编译过程和内存模型
5. **注重规范**：养成良好的编程习惯和代码风格
6. **持续学习**：关注C语言标准的发展和新特性

C语言作为一门底层语言，掌握它需要时间和耐心，但其带来的对计算机系统的深刻理解将使程序员终身受益。
