# 第三章 运算符与表达式

## 3.1 运算符概述

运算符是用于执行特定操作的符号。Python提供了丰富的运算符，包括算术运算符、比较运算符、赋值运算符、逻辑运算符、位运算符、成员运算符和身份运算符。理解运算符的优先级和结合性对于编写正确的表达式至关重要。

## 3.2 算术运算符

算术运算符用于执行基本的数学运算。

| 运算符 | 名称 | 描述 | 示例 | 结果 |
|--------|------|------|------|------|
| + | 加法 | 两个数相加 | 5 + 3 | 8 |
| - | 减法 | 两个数相减 | 5 - 3 | 2 |
| * | 乘法 | 两个数相乘 | 5 * 3 | 15 |
| / | 除法 | 两个数相除（浮点结果） | 5 / 2 | 2.5 |
| // | 整除 | 两个数相除取整数部分 | 5 // 2 | 2 |
| % | 取模 | 返回除法的余数 | 5 % 2 | 1 |
| ** | 幂运算 | 返回x的y次幂 | 2 ** 3 | 8 |
| +x | 正号 | x的正值 | +5 | 5 |
| -x | 负号 | x的负值 | -5 | -5 |

```python
a = 17
b = 5

print(f"a + b = {a + b}")       # 22
print(f"a - b = {a - b}")       # 12
print(f"a * b = {a * b}")       # 85
print(f"a / b = {a / b}")       # 3.4
print(f"a // b = {a // b}")     # 3
print(f"a % b = {a % b}")       # 2
print(f"a ** b = {a ** b}")     # 1419857
print(f"divmod(a, b) = {divmod(a, b)}")  # (3, 2)
```

### 整数除法与浮点除法

```python
# Python 3中，/总是返回浮点数
print(5 / 2)        # 2.5
print(4 / 2)        # 2.0

# //返回整数部分（向下取整）
print(5 // 2)       # 2
print(-5 // 2)      # -3（向下取整）

# 混合运算
print(5 // 2.0)     # 2.0
```

## 3.3 比较运算符

比较运算符用于比较两个值，返回布尔值True或False。

| 运算符 | 名称 | 描述 | 示例 | 结果 |
|--------|------|------|------|------|
| == | 等于 | 两个对象是否相等 | 5 == 5 | True |
| != | 不等于 | 两个对象是否不相等 | 5 != 3 | True |
| > | 大于 | 左边是否大于右边 | 5 > 3 | True |
| < | 小于 | 左边是否小于右边 | 5 < 3 | False |
| >= | 大于等于 | 左边是否大于或等于右边 | 5 >= 5 | True |
| <= | 小于等于 | 左边是否小于或等于右边 | 5 <= 3 | False |

```python
a = 5
b = 3

print(a == b)       # False
print(a != b)       # True
print(a > b)        # True
print(a < b)        # False
print(a >= b)       # True
print(a <= b)       # False
```

### 链式比较

Python支持链式比较：

```python
x = 5

# 检查x是否在1到10之间
print(1 <= x <= 10)     # True

# 等价于
print(1 <= x and x <= 10)   # True

# 更复杂的链式比较
print(1 < 2 < 3 < 4 < 5)    # True
```

## 3.4 赋值运算符

### 简单赋值

```python
x = 10
```

### 复合赋值

```python
a = 10
a += 5      # a = a + 5，结果为15
a -= 3      # a = a - 3，结果为12
a *= 2      # a = a * 2，结果为24
a /= 4      # a = a / 4，结果为6.0
a //= 2     # a = a // 2，结果为3.0
a %= 2      # a = a % 2，结果为1.0
a **= 3     # a = a ** 3，结果为1.0
```

### 海象运算符（Python 3.8+）

`:=`运算符允许在表达式内部进行赋值：

```python
# 传统写法
n = len(data)
if n > 10:
    print(f"Length is {n}")

# 使用海象运算符
if (n := len(data)) > 10:
    print(f"Length is {n}")

# 在while循环中使用
while (line := input()) != "quit":
    print(f"You entered: {line}")
```

### 多重赋值

```python
# 同时赋值
a = b = c = 0

# 解包赋值
a, b, c = 1, 2, 3

# 交换变量
a, b = b, a

# 扩展解包
first, *rest = [1, 2, 3, 4, 5]      # first=1, rest=[2, 3, 4, 5]
*beginning, last = [1, 2, 3, 4, 5]  # beginning=[1, 2, 3, 4], last=5
first, *middle, last = [1, 2, 3, 4, 5]  # first=1, middle=[2, 3, 4], last=5
```

## 3.5 逻辑运算符

逻辑运算符用于组合多个条件。

| 运算符 | 描述 | 示例 | 结果 |
|--------|------|------|------|
| and | 逻辑与 | True and False | False |
| or | 逻辑或 | True or False | True |
| not | 逻辑非 | not True | False |

```python
age = 25
income = 50000

# 逻辑与
if age >= 18 and age <= 60:
    print("年龄在18到60岁之间")

# 逻辑或
if income > 100000 or age < 30:
    print("符合条件")

# 逻辑非
if not (age < 18):
    print("已成年")
```

### 短路求值

逻辑运算符采用短路求值策略：

```python
# and：如果第一个操作数为False，不计算第二个操作数
result = False and expensive_function()   # expensive_function不会被执行

# or：如果第一个操作数为True，不计算第二个操作数
result = True or expensive_function()      # expensive_function不会被执行

# 实际应用
def greet(name):
    # 如果name为空字符串或None，使用默认值
    name = name or "Guest"
    print(f"Hello, {name}!")

greet("")           # Hello, Guest!
greet(None)         # Hello, Guest!
greet("Alice")      # Hello, Alice!
```

## 3.6 位运算符

位运算符直接对整数的二进制位进行操作。

| 运算符 | 名称 | 描述 | 示例 |
|--------|------|------|------|
| & | 按位与 | 对应位都为1时结果为1 | 5 & 3 = 1 |
| | | 按位或 | 对应位至少一个为1时结果为1 | 5 | 3 = 7 |
| ^ | 按位异或 | 对应位不同时结果为1 | 5 ^ 3 = 6 |
| ~ | 按位取反 | 0变1，1变0 | ~5 = -6 |
| << | 左移 | 各位左移，右侧补0 | 5 << 1 = 10 |
| >> | 右移 | 各位右移，左侧补符号位 | 5 >> 1 = 2 |

```python
a = 5       # 二进制：101
b = 3       # 二进制：011

print(f"a & b = {a & b}")       # 1 (001)
print(f"a | b = {a | b}")       # 7 (111)
print(f"a ^ b = {a ^ b}")       # 6 (110)
print(f"~a = {~a}")             # -6
print(f"a << 1 = {a << 1}")     # 10 (1010)
print(f"a >> 1 = {a >> 1}")     # 2 (10)
```

### 位运算的应用

```python
# 设置第n位为1
flags |= (1 << n)

# 设置第n位为0
flags &= ~(1 << n)

# 切换第n位
flags ^= (1 << n)

# 检查第n位是否为1
if flags & (1 << n):
    print(f"第{n}位为1")

# 清除最低位的1
x = x & (x - 1)

# 获取最低位的1
lowbit = x & (-x)
```

## 3.7 成员运算符

成员运算符用于测试序列中是否包含某个值。

| 运算符 | 描述 | 示例 | 结果 |
|--------|------|------|------|
| in | 如果在序列中找到值返回True | 3 in [1, 2, 3] | True |
| not in | 如果在序列中没有找到值返回True | 4 not in [1, 2, 3] | True |

```python
# 列表
numbers = [1, 2, 3, 4, 5]
print(3 in numbers)         # True
print(6 in numbers)         # False
print(6 not in numbers)     # True

# 字符串
text = "Hello, World!"
print("Hello" in text)      # True
print("Python" in text)     # False

# 字典（检查键）
person = {"name": "Alice", "age": 20}
print("name" in person)     # True
print("Alice" in person)    # False（检查的是键，不是值）
print("Alice" in person.values())   # True
```

## 3.8 身份运算符

身份运算符用于比较两个对象的内存地址。

| 运算符 | 描述 | 示例 | 结果 |
|--------|------|------|------|
| is | 如果两个变量引用同一对象返回True | x is y | 取决于具体情况 |
| is not | 如果两个变量不引用同一对象返回True | x is not y | 取决于具体情况 |

```python
a = [1, 2, 3]
b = a
c = [1, 2, 3]

print(a is b)           # True（同一对象）
print(a is c)           # False（不同对象，值相同）
print(a is not c)       # True
print(a == c)           # True（值相等）

# 小整数缓存
x = 256
y = 256
print(x is y)           # True（小整数被缓存）

x = 257
y = 257
print(x is y)           # False（大整数不被缓存）

# None检查
result = None
print(result is None)   # True
print(result is not None)   # False
```

## 3.9 运算符优先级

运算符优先级决定了表达式中运算的执行顺序。

| 优先级 | 运算符 | 描述 |
|--------|--------|------|
| 1（最高） | () | 括号 |
| 2 | ** | 幂运算 |
| 3 | +x, -x, ~x | 正号、负号、按位取反 |
| 4 | *, @, /, //, % | 乘法、矩阵乘法、除法、整除、取模 |
| 5 | +, - | 加法、减法 |
| 6 | <<, >> | 位移 |
| 7 | & | 按位与 |
| 8 | ^ | 按位异或 |
| 9 | | | 按位或 |
| 10 | in, not in, is, is not, <, <=, >, >=, !=, == | 比较运算符 |
| 11 | not x | 逻辑非 |
| 12 | and | 逻辑与 |
| 13 | or | 逻辑或 |
| 14 | if-else | 条件表达式 |
| 15 | lambda | Lambda表达式 |
| 16（最低） | := | 海象运算符 |

```python
# 优先级示例
result = 2 + 3 * 4          # 14（先乘后加）
result = (2 + 3) * 4        # 20（括号优先）
result = 2 ** 3 ** 2        # 512（从右向左计算：2**(3**2)）
result = 5 > 3 and 2 < 4    # True（比较优先于逻辑运算）
```

## 3.10 条件表达式

条件表达式（三元运算符）提供简洁的条件判断：

```python
# 语法：value_if_true if condition else value_if_false

age = 20
status = "成年" if age >= 18 else "未成年"
print(status)           # 成年

# 等价于
if age >= 18:
    status = "成年"
else:
    status = "未成年"

# 嵌套条件表达式（不推荐，可读性差）
score = 85
grade = "A" if score >= 90 else "B" if score >= 80 else "C" if score >= 70 else "D"
```

## 3.11 综合示例

```python
# 计算器程序
def calculator():
    print("简单计算器")
    print("支持的运算：+, -, *, /, //, %, **")
    
    num1 = float(input("请输入第一个数："))
    operator = input("请输入运算符：")
    num2 = float(input("请输入第二个数："))
    
    if operator == "+":
        result = num1 + num2
    elif operator == "-":
        result = num1 - num2
    elif operator == "*":
        result = num1 * num2
    elif operator == "/":
        if num2 == 0:
            print("错误：除数不能为零")
            return
        result = num1 / num2
    elif operator == "//":
        result = num1 // num2
    elif operator == "%":
        result = num1 % num2
    elif operator == "**":
        result = num1 ** num2
    else:
        print("错误：不支持的运算符")
        return
    
    print(f"结果：{result}")

calculator()
```
