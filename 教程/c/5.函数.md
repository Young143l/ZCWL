# 第五章 函数

## 5.1 函数概述

函数是C程序的基本组成单元，是实现模块化编程的重要手段。通过将程序分解为多个函数，可以提高代码的可读性、可维护性和复用性。

C程序的执行从main函数开始，main函数可以调用其他函数，其他函数之间也可以相互调用。

## 5.2 函数的定义

函数定义包括返回类型、函数名、参数列表和函数体：

```c
返回类型 函数名(参数列表)
{
    /* 函数体 */
    return 返回值;  /* 如果返回类型不是void */
}
```

```c
/* 计算两个整数之和的函数 */
int add(int a, int b)
{
    return a + b;
}

/* 无参数、无返回值的函数 */
void print_hello(void)
{
    printf("Hello, World!\n");
}
```

## 5.3 函数的声明

函数声明（函数原型）告诉编译器函数的名称、返回类型和参数类型，使编译器能够在函数定义之前调用该函数：

```c
/* 函数声明 */
int add(int a, int b);
void print_hello(void);

int main(void)
{
    int result = add(3, 5);     /* 在定义前调用 */
    print_hello();
    return 0;
}

/* 函数定义 */
int add(int a, int b)
{
    return a + b;
}
```

函数声明中的参数名可以省略：

```c
int add(int, int);              /* 等价于 int add(int a, int b); */
```

## 5.4 函数的调用

函数调用通过函数名和实参列表实现：

```c
int result = add(3, 5);         /* 调用add函数，传入3和5 */
print_hello();                  /* 调用无参数函数 */
```

### 参数传递

C语言采用值传递方式，函数接收的是实参的副本：

```c
void swap(int a, int b)
{
    int temp = a;
    a = b;
    b = temp;
    /* 这里的交换不影响main函数中的x和y */
}

int main(void)
{
    int x = 3, y = 5;
    swap(x, y);
    printf("x = %d, y = %d\n", x, y);    /* 输出：x = 3, y = 5 */
    return 0;
}
```

## 5.5 函数的返回值

函数通过return语句返回结果：

```c
/* 返回单个值 */
int max(int a, int b)
{
    return (a > b) ? a : b;
}

/* 返回计算结果和状态码（通过指针参数） */
int divide(int a, int b, double *result)
{
    if (b == 0) {
        return -1;                  /* 错误：除数为零 */
    }
    *result = (double)a / b;
    return 0;                       /* 成功 */
}
```

void类型的函数不需要return语句，或使用不带值的return：

```c
void print_error(const char *msg)
{
    if (msg == NULL) {
        return;                     /* 提前退出 */
    }
    printf("Error: %s\n", msg);
}
```

## 5.6 递归函数

递归函数是在其定义中调用自身的函数。递归需要基本情况（终止条件）和递归情况：

```c
/* 计算阶乘 */
long long factorial(int n)
{
    if (n < 0) {
        return -1;                  /* 错误 */
    }
    if (n == 0 || n == 1) {
        return 1;                   /* 基本情况 */
    }
    return n * factorial(n - 1);    /* 递归情况 */
}

/* 斐波那契数列 */
long long fibonacci(int n)
{
    if (n <= 0) {
        return 0;
    }
    if (n == 1) {
        return 1;
    }
    return fibonacci(n - 1) + fibonacci(n - 2);
}
```

### 尾递归优化

尾递归是递归调用出现在函数最后的情况，某些编译器可以优化：

```c
/* 尾递归形式的阶乘 */
long long factorial_tail(int n, long long acc)
{
    if (n <= 1) {
        return acc;
    }
    return factorial_tail(n - 1, n * acc);
}

long long factorial(int n)
{
    if (n < 0) {
        return -1;
    }
    return factorial_tail(n, 1);
}
```

## 5.7 函数指针

函数指针是指向函数的指针，可以用于回调函数、实现多态等：

```c
/* 声明函数指针类型 */
typedef int (*CompareFunc)(int, int);

/* 比较函数 */
int ascending(int a, int b)
{
    return a - b;
}

int descending(int a, int b)
{
    return b - a;
}

/* 使用函数指针 */
void sort(int arr[], int n, CompareFunc cmp)
{
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (cmp(arr[j], arr[j + 1]) > 0) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

## 5.8 内联函数

C99标准引入了内联函数，建议编译器将函数调用替换为函数体，减少调用开销：

```c
inline int max(int a, int b)
{
    return (a > b) ? a : b;
}
```

注意：
- inline只是建议，编译器可能不采纳
- 内联函数适合短小、频繁调用的函数
- 内联函数的定义通常放在头文件中

## 5.9 变参函数

C语言支持可变参数函数，如printf：

```c
#include <stdarg.h>

/* 计算平均值 */
double average(int count, ...)
{
    va_list args;
    va_start(args, count);
    
    double sum = 0;
    for (int i = 0; i < count; i++) {
        sum += va_arg(args, double);
    }
    
    va_end(args);
    return sum / count;
}

/* 使用 */
double avg = average(3, 1.0, 2.0, 3.0);     /* 结果为2.0 */
```

## 5.10 作用域与存储类别

### 作用域

**局部变量**：在函数或代码块内定义，只在定义范围内可见：

```c
void func(void)
{
    int local = 10;             /* 局部变量 */
    {
        int inner = 20;         /* 代码块局部变量 */
        printf("%d\n", local);  /* 可以访问外层变量 */
    }
    /* inner在此处不可见 */
}
```

**全局变量**：在所有函数外定义，整个程序可见：

```c
int global = 100;               /* 全局变量 */

void func1(void)
{
    printf("%d\n", global);     /* 可以访问全局变量 */
}

void func2(void)
{
    global = 200;               /* 修改全局变量 */
}
```

### 存储类别

**auto**：自动变量（默认），进入作用域时创建，离开时销毁：

```c
void func(void)
{
    auto int x = 10;            /* auto通常省略 */
}
```

**static**：静态变量，生命周期贯穿整个程序运行期：

```c
void counter(void)
{
    static int count = 0;       /* 只初始化一次 */
    count++;
    printf("调用次数：%d\n", count);
}

static int internal = 0;        /* 静态全局变量，只在当前文件可见 */
```

**extern**：声明在其他地方定义的变量：

```c
/* file1.c */
int shared = 100;               /* 定义全局变量 */

/* file2.c */
extern int shared;              /* 声明外部变量 */
```

**register**：建议编译器将变量存储在寄存器中：

```c
void func(void)
{
    register int i;             /* 建议优化 */
    for (i = 0; i < 1000000; i++) {
        /* ... */
    }
}
```

## 5.11 综合示例

### 示例1：字符串处理函数

```c
#include <stdio.h>

/* 计算字符串长度 */
size_t my_strlen(const char *str)
{
    size_t len = 0;
    while (str[len] != '\0') {
        len++;
    }
    return len;
}

/* 复制字符串 */
char *my_strcpy(char *dest, const char *src)
{
    char *ptr = dest;
    while ((*ptr++ = *src++) != '\0');
    return dest;
}

/* 比较字符串 */
int my_strcmp(const char *s1, const char *s2)
{
    while (*s1 && *s1 == *s2) {
        s1++;
        s2++;
    }
    return *(unsigned char *)s1 - *(unsigned char *)s2;
}

int main(void)
{
    char str1[] = "Hello";
    char str2[20];
    
    printf("长度：%zu\n", my_strlen(str1));
    my_strcpy(str2, str1);
    printf("复制后：%s\n", str2);
    printf("比较结果：%d\n", my_strcmp(str1, str2));
    
    return 0;
}
```

### 示例2：二分查找

```c
#include <stdio.h>

/* 二分查找，返回索引，未找到返回-1 */
int binary_search(int arr[], int n, int target)
{
    int left = 0;
    int right = n - 1;
    
    while (left <= right) {
        int mid = left + (right - left) / 2;
        
        if (arr[mid] == target) {
            return mid;
        } else if (arr[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    
    return -1;
}

int main(void)
{
    int arr[] = {1, 3, 5, 7, 9, 11, 13, 15};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    int target = 7;
    int result = binary_search(arr, n, target);
    
    if (result != -1) {
        printf("找到%d，索引为%d\n", target, result);
    } else {
        printf("未找到%d\n", target);
    }
    
    return 0;
}
```

### 示例3：函数指针应用

```c
#include <stdio.h>

/* 数学运算函数 */
int add(int a, int b) { return a + b; }
int subtract(int a, int b) { return a - b; }
int multiply(int a, int b) { return a * b; }
int divide(int a, int b) { return b != 0 ? a / b : 0; }

int main(void)
{
    /* 函数指针数组 */
    int (*operations[])(int, int) = {add, subtract, multiply, divide};
    const char *op_names[] = {"+", "-", "*", "/"};
    
    int a = 10, b = 5;
    
    for (int i = 0; i < 4; i++) {
        int result = operations[i](a, b);
        printf("%d %s %d = %d\n", a, op_names[i], b, result);
    }
    
    return 0;
}
```
