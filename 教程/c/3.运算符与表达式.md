# 第三章 运算符与表达式

## 3.1 运算符概述

运算符是用于执行特定操作的符号。C语言提供了丰富的运算符，包括算术运算符、关系运算符、逻辑运算符、位运算符、赋值运算符等。理解运算符的优先级和结合性对于编写正确的表达式至关重要。

## 3.2 算术运算符

算术运算符用于执行基本的数学运算：

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| + | 加法 | 5 + 3 | 8 |
| - | 减法 | 5 - 3 | 2 |
| * | 乘法 | 5 * 3 | 15 |
| / | 除法 | 5 / 3 | 1（整数除法） |
| % | 取模（求余） | 5 % 3 | 2 |

### 整数除法与浮点除法

```c
int a = 5, b = 2;
double result1 = a / b;         /* 结果为2.0，整数除法后转换为double */
double result2 = (double)a / b; /* 结果为2.5，浮点除法 */
```

### 取模运算符

取模运算符`%`要求两个操作数都必须是整数类型：

```c
int remainder = 17 % 5;         /* 结果为2 */
int negative = -17 % 5;         /* 结果为-2，符号与被除数相同 */
```

### 自增自减运算符

```c
int a = 5;
int b = ++a;    /* 前缀自增：a先变为6，然后b赋值为6 */
int c = a++;    /* 后缀自增：c赋值为6，然后a变为7 */
```

前缀形式先修改变量值，再使用；后缀形式先使用变量值，再修改。

## 3.3 关系运算符

关系运算符用于比较两个值，结果为0（假）或1（真）：

| 运算符 | 含义 | 示例 | 结果（a=5, b=3） |
|--------|------|------|------------------|
| == | 等于 | a == b | 0 |
| != | 不等于 | a != b | 1 |
| > | 大于 | a > b | 1 |
| < | 小于 | a < b | 0 |
| >= | 大于等于 | a >= b | 1 |
| <= | 小于等于 | a <= b | 0 |

```c
int a = 5, b = 3;
if (a > b) {
    printf("a大于b\n");
}
```

注意区分赋值运算符`=`和等于运算符`==`：

```c
if (a = 5) {    /* 危险：将5赋值给a，然后判断a是否为非零 */
    /* 此代码块总是执行 */
}

if (a == 5) {   /* 正确：判断a是否等于5 */
    /* 条件满足时执行 */
}
```

## 3.4 逻辑运算符

逻辑运算符用于组合多个条件：

| 运算符 | 含义 | 示例 | 说明 |
|--------|------|------|------|
| && | 逻辑与 | a && b | 两者都为真时结果为真 |
| || | 逻辑或 | a || b | 至少一个为真时结果为真 |
| ! | 逻辑非 | !a | 真变假，假变真 |

```c
int age = 25;
int income = 50000;

if (age >= 18 && age <= 60) {
    printf("年龄在18到60岁之间\n");
}

if (income > 100000 || age < 30) {
    printf("符合条件\n");
}

if (!(age < 18)) {
    printf("已成年\n");
}
```

### 短路求值

逻辑运算符采用短路求值策略：

```c
int a = 0, b = 5;

if (a != 0 && b / a > 2) {      /* a != 0为假，不计算b / a，避免除零错误 */
    /* 不会执行 */
}

if (a == 0 || b > 3) {          /* a == 0为真，不计算b > 3 */
    /* 会执行 */
}
```

## 3.5 位运算符

位运算符直接对整数的二进制位进行操作：

| 运算符 | 含义 | 示例 | 说明 |
|--------|------|------|------|
| & | 按位与 | a & b | 对应位都为1时结果为1 |
| | | 按位或 | a | b | 对应位至少一个为1时结果为1 |
| ^ | 按位异或 | a ^ b | 对应位不同时结果为1 |
| ~ | 按位取反 | ~a | 0变1，1变0 |
| << | 左移 | a << 2 | 各位左移2位，右侧补0 |
| >> | 右移 | a >> 2 | 各位右移2位，左侧补符号位或0 |

```c
unsigned int a = 5;     /* 二进制：0000 0101 */
unsigned int b = 3;     /* 二进制：0000 0011 */

unsigned int c = a & b; /* 结果：0000 0001 = 1 */
unsigned int d = a | b; /* 结果：0000 0111 = 7 */
unsigned int e = a ^ b; /* 结果：0000 0110 = 6 */
unsigned int f = ~a;    /* 结果：1111 1010（取决于整数位数） */
unsigned int g = a << 1; /* 结果：0000 1010 = 10 */
unsigned int h = a >> 1; /* 结果：0000 0010 = 2 */
```

### 位运算的应用

```c
/* 设置第n位为1 */
flags |= (1 << n);

/* 设置第n位为0 */
flags &= ~(1 << n);

/* 切换第n位 */
flags ^= (1 << n);

/* 检查第n位是否为1 */
if (flags & (1 << n)) {
    /* 第n位为1 */
}
```

## 3.6 赋值运算符

### 简单赋值

```c
int a = 10;         /* 将10赋值给变量a */
```

### 复合赋值

```c
int a = 10;
a += 5;             /* 等价于 a = a + 5 */
a -= 3;             /* 等价于 a = a - 3 */
a *= 2;             /* 等价于 a = a * 2 */
a /= 4;             /* 等价于 a = a / 4 */
a %= 3;             /* 等价于 a = a % 3 */

/* 位运算复合赋值 */
a &= 0xFF;
a |= 0x10;
a ^= 0x01;
a <<= 2;
a >>= 1;
```

### 多重赋值

```c
int a, b, c;
a = b = c = 0;      /* 从右向左赋值，a、b、c都为0 */
```

## 3.7 条件运算符

条件运算符是C语言中唯一的三目运算符：

```c
条件 ? 表达式1 : 表达式2
```

如果条件为真（非零），则返回表达式1的值；否则返回表达式2的值。

```c
int a = 5, b = 3;
int max = (a > b) ? a : b;      /* max的值为5 */

/* 等价于 */
int max;
if (a > b) {
    max = a;
} else {
    max = b;
}
```

条件运算符可以嵌套使用，但过度嵌套会降低代码可读性：

```c
int score = 85;
char grade = (score >= 90) ? 'A' :
             (score >= 80) ? 'B' :
             (score >= 70) ? 'C' :
             (score >= 60) ? 'D' : 'F';
```

## 3.8 其他运算符

### 逗号运算符

逗号运算符从左到右依次计算各表达式，返回最右边表达式的值：

```c
int a = (1, 2, 3);          /* a的值为3 */

for (int i = 0, j = 10; i < j; i++, j--) {
    /* 同时修改i和j */
}
```

### 取地址运算符与解引用运算符

```c
int a = 10;
int *p = &a;                /* &取变量a的地址 */
int b = *p;                 /* *解引用指针p，获取指向的值 */
```

### sizeof运算符

```c
int a;
size_t size = sizeof(a);    /* 获取变量a的大小 */
size_t int_size = sizeof(int); /* 获取int类型的大小 */
```

## 3.9 运算符优先级与结合性

运算符优先级决定了表达式中运算的执行顺序。优先级高的运算符先执行。

| 优先级 | 运算符 | 结合性 |
|--------|--------|--------|
| 1（最高） | () [] -> . | 从左到右 |
| 2 | ++ --（后缀） | 从左到右 |
| 3 | ++ --（前缀） + - ! ~ * & sizeof | 从右到左 |
| 4 | * / % | 从左到右 |
| 5 | + - | 从左到右 |
| 6 | << >> | 从左到右 |
| 7 | < <= > >= | 从左到右 |
| 8 | == != | 从左到右 |
| 9 | & | 从左到右 |
| 10 | ^ | 从左到右 |
| 11 | | | 从左到右 |
| 12 | && | 从左到右 |
| 13 | || | 从左到右 |
| 14 | ?: | 从右到左 |
| 15 | = += -= 等 | 从右到左 |
| 16（最低） | , | 从左到右 |

```c
int a = 5, b = 3, c = 2;
int result = a + b * c;         /* 先算b * c，再加a，结果为11 */

int x = a > b && b > c;         /* 先算a > b和b > c，再算&&，结果为1 */

/* 使用括号明确运算顺序 */
int y = (a + b) * c;            /* 结果为16 */
```

## 3.10 表达式求值

### 整型提升

在表达式求值过程中，小于int类型的整型会被提升为int类型：

```c
char a = 100;
char b = 50;
int c = a + b;                  /* a和b先提升为int，再相加 */
```

### 算术转换

当不同类型的数据进行运算时，会按照规则转换为相同类型：

```c
int a = 5;
double b = 2.5;
double c = a + b;               /* a转换为double，再与b相加 */
```

## 3.11 综合示例

```c
#include <stdio.h>

int main(void)
{
    /* 算术运算符示例 */
    int a = 17, b = 5;
    printf("算术运算：\n");
    printf("%d + %d = %d\n", a, b, a + b);
    printf("%d - %d = %d\n", a, b, a - b);
    printf("%d * %d = %d\n", a, b, a * b);
    printf("%d / %d = %d\n", a, b, a / b);
    printf("%d %% %d = %d\n", a, b, a % b);
    
    /* 关系与逻辑运算符示例 */
    printf("\n关系与逻辑运算：\n");
    printf("%d > %d: %d\n", a, b, a > b);
    printf("%d == %d: %d\n", a, b, a == b);
    printf("(%d > %d) && (%d < 10): %d\n", a, b, a, (a > b) && (a < 10));
    
    /* 位运算符示例 */
    unsigned int x = 0x0F;      /* 0000 1111 */
    unsigned int y = 0xF0;      /* 1111 0000 */
    printf("\n位运算：\n");
    printf("0x%02X & 0x%02X = 0x%02X\n", x, y, x & y);
    printf("0x%02X | 0x%02X = 0x%02X\n", x, y, x | y);
    printf("0x%02X ^ 0x%02X = 0x%02X\n", x, y, x ^ y);
    printf("~0x%02X = 0x%02X\n", x, ~x);
    printf("0x%02X << 2 = 0x%02X\n", x, x << 2);
    printf("0x%02X >> 2 = 0x%02X\n", x, x >> 2);
    
    /* 条件运算符示例 */
    int max = (a > b) ? a : b;
    printf("\n条件运算：\n");
    printf("max(%d, %d) = %d\n", a, b, max);
    
    /* 复合赋值示例 */
    int n = 10;
    printf("\n复合赋值：\n");
    printf("n = %d\n", n);
    n += 5;
    printf("n += 5: %d\n", n);
    n *= 2;
    printf("n *= 2: %d\n", n);
    
    return 0;
}
```
