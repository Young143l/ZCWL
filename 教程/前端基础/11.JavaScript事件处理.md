# 第十一章 JavaScript事件处理

## 11.1 事件概述

### 11.1.1 什么是事件

事件是用户或浏览器触发的特定动作或发生的事情。JavaScript通过事件处理机制来响应这些动作，实现网页的交互功能。常见的事件包括用户点击按钮、输入文本、滚动页面、键盘按键等。

### 11.1.2 事件类型分类

**鼠标事件**

- `click`：单击
- `dblclick`：双击
- `mousedown`：鼠标按下
- `mouseup`：鼠标释放
- `mousemove`：鼠标移动
- `mouseenter`：鼠标进入元素
- `mouseleave`：鼠标离开元素
- `mouseover`：鼠标移到元素或其子元素上
- `mouseout`：鼠标离开元素或其子元素
- `contextmenu`：右键菜单

**键盘事件**

- `keydown`：键盘按下
- `keyup`：键盘释放
- `keypress`：按键按下（已废弃，不推荐使用）

**表单事件**

- `submit`：表单提交
- `reset`：表单重置
- `change`：值改变
- `input`：输入
- `focus`：获得焦点
- `blur`：失去焦点
- `select`：文本被选中

**窗口/文档事件**

- `load`：页面或资源加载完成
- `unload`：页面卸载
- `resize`：窗口大小改变
- `scroll`：滚动
- `DOMContentLoaded`：DOM加载完成

**触摸事件（移动端）**

- `touchstart`：触摸开始
- `touchmove`：触摸移动
- `touchend`：触摸结束
- `touchcancel`：触摸取消

## 11.2 事件绑定方式

### 11.2.1 HTML事件属性

直接在HTML元素上使用事件属性（不推荐）：

```html
<button onclick="alert('Hello')">点击我</button>
<button onclick="handleClick()">点击我</button>
```

```javascript
function handleClick() {
    console.log('按钮被点击');
}
```

缺点：

- HTML与JavaScript耦合
- 无法绑定多个处理函数
- 维护困难

### 11.2.2 DOM事件属性

通过JavaScript设置元素的事件属性：

```javascript
let button = document.getElementById('myButton');

button.onclick = function() {
    console.log('按钮被点击');
};

// 箭头函数
button.onclick = () => {
    console.log('按钮被点击');
};
```

缺点：

- 只能绑定一个处理函数
- 后绑定的会覆盖先绑定的

### 11.2.3 addEventListener（推荐）

使用`addEventListener`方法绑定事件：

```javascript
let button = document.getElementById('myButton');

// 基本用法
button.addEventListener('click', function() {
    console.log('按钮被点击');
});

// 使用命名函数
function handleClick() {
    console.log('按钮被点击');
}
button.addEventListener('click', handleClick);

// 绑定多个处理函数
button.addEventListener('click', function() {
    console.log('第一个处理函数');
});
button.addEventListener('click', function() {
    console.log('第二个处理函数');
});

// 使用选项
button.addEventListener('click', handleClick, {
    capture: false,  // 使用冒泡阶段
    once: true,      // 只执行一次
    passive: true    // 不阻止默认行为
});
```

### 11.2.4 移除事件监听

```javascript
function handleClick() {
    console.log('按钮被点击');
}

// 添加监听
button.addEventListener('click', handleClick);

// 移除监听（必须使用相同的函数引用）
button.removeEventListener('click', handleClick);

// 匿名函数无法移除
button.addEventListener('click', function() {});
// 无法移除上面的监听
```

## 11.3 事件对象

### 11.3.1 事件对象概述

当事件触发时，浏览器会自动创建一个事件对象，并作为参数传递给事件处理函数。事件对象包含有关事件的详细信息。

```javascript
element.addEventListener('click', function(event) {
    console.log(event);  // 事件对象
});

// 简写
element.addEventListener('click', (e) => {
    console.log(e);
});
```

### 11.3.2 事件对象常用属性

**通用属性**

```javascript
element.addEventListener('click', function(event) {
    console.log(event.type);      // 事件类型："click"
    console.log(event.target);    // 触发事件的元素
    console.log(event.currentTarget); // 绑定事件的元素
    console.log(event.timeStamp); // 事件发生的时间戳
    console.log(event.bubbles);   // 是否冒泡
    console.log(event.cancelable); // 是否可以取消默认行为
});
```

**鼠标事件属性**

```javascript
element.addEventListener('click', function(event) {
    console.log(event.clientX);   // 鼠标相对于视口的X坐标
    console.log(event.clientY);   // 鼠标相对于视口的Y坐标
    console.log(event.pageX);     // 鼠标相对于文档的X坐标
    console.log(event.pageY);     // 鼠标相对于文档的Y坐标
    console.log(event.screenX);   // 鼠标相对于屏幕的X坐标
    console.log(event.screenY);   // 鼠标相对于屏幕的Y坐标
    console.log(event.button);    // 按下的鼠标按钮（0:左键, 1:中键, 2:右键）
    console.log(event.ctrlKey);   // Ctrl键是否按下
    console.log(event.shiftKey);  // Shift键是否按下
    console.log(event.altKey);    // Alt键是否按下
    console.log(event.metaKey);   // Meta键是否按下（Mac上的Command键）
});
```

**键盘事件属性**

```javascript
document.addEventListener('keydown', function(event) {
    console.log(event.key);       // 按键的值（如"Enter", "a", "1"）
    console.log(event.code);      // 按键的物理代码（如"KeyA", "Enter"）
    console.log(event.keyCode);   // 按键的数字代码（已废弃）
    console.log(event.ctrlKey);   // Ctrl键是否按下
    console.log(event.shiftKey);  // Shift键是否按下
    console.log(event.altKey);    // Alt键是否按下
    console.log(event.repeat);    // 按键是否持续按下
});
```

### 11.3.3 事件对象常用方法

```javascript
element.addEventListener('click', function(event) {
    // 阻止默认行为
    event.preventDefault();
    
    // 阻止事件冒泡
    event.stopPropagation();
    
    // 阻止事件冒泡并阻止同一元素上的其他事件处理
    event.stopImmediatePropagation();
});
```

## 11.4 事件传播

### 11.4.1 事件传播的三个阶段

事件传播分为三个阶段：

1. **捕获阶段（Capture Phase）**：事件从文档根节点向下传播到目标元素
2. **目标阶段（Target Phase）**：事件到达目标元素
3. **冒泡阶段（Bubble Phase）**：事件从目标元素向上冒泡到文档根节点

```
Document
    └── html
        └── body
            └── div#parent
                └── button#child (目标)
```

### 11.4.2 事件冒泡

默认情况下，事件处理在冒泡阶段执行：

```html
<div id="parent">
    <button id="child">点击我</button>
</div>
```

```javascript
document.getElementById('parent').addEventListener('click', function() {
    console.log('父元素被点击');
});

document.getElementById('child').addEventListener('click', function() {
    console.log('子元素被点击');
});

// 点击按钮时输出：
// 子元素被点击
// 父元素被点击
```

### 11.4.3 事件捕获

使用`addEventListener`的第三个参数启用捕获阶段：

```javascript
document.getElementById('parent').addEventListener('click', function() {
    console.log('父元素被点击（捕获）');
}, true);

document.getElementById('child').addEventListener('click', function() {
    console.log('子元素被点击');
});

// 点击按钮时输出：
// 父元素被点击（捕获）
// 子元素被点击
```

### 11.4.4 阻止事件传播

```javascript
document.getElementById('child').addEventListener('click', function(event) {
    console.log('子元素被点击');
    event.stopPropagation();  // 阻止事件继续传播
});

// 点击按钮时只输出：
// 子元素被点击
```

## 11.5 事件委托

### 11.5.1 什么是事件委托

事件委托是一种利用事件冒泡机制的技术。通过在父元素上绑定事件处理函数，来管理子元素的事件，而不是为每个子元素单独绑定。

### 11.5.2 事件委托的优势

- 减少事件处理函数的数量，提高性能
- 自动处理动态添加的元素
- 代码更简洁，易于维护

### 11.5.3 事件委托实现

```html
<ul id="todoList">
    <li>任务1</li>
    <li>任务2</li>
    <li>任务3</li>
</ul>
```

```javascript
// 不推荐：为每个li绑定事件
document.querySelectorAll('#todoList li').forEach(li => {
    li.addEventListener('click', function() {
        console.log(this.textContent);
    });
});

// 推荐：使用事件委托
document.getElementById('todoList').addEventListener('click', function(event) {
    // 检查点击的是否是li元素
    if (event.target.tagName === 'LI') {
        console.log(event.target.textContent);
    }
});

// 动态添加的元素也能响应
let newLi = document.createElement('li');
newLi.textContent = '任务4';
document.getElementById('todoList').appendChild(newLi);
// 点击"任务4"也能触发事件处理
```

### 11.5.4 使用closest方法

```javascript
document.getElementById('todoList').addEventListener('click', function(event) {
    // 查找最近的li祖先元素
    let li = event.target.closest('li');
    
    if (li && this.contains(li)) {
        console.log(li.textContent);
    }
});
```

## 11.6 常用事件示例

### 11.6.1 表单验证

```javascript
let form = document.getElementById('myForm');
let emailInput = document.getElementById('email');

// 实时验证
emailInput.addEventListener('input', function() {
    let email = this.value;
    let isValid = /^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(email);
    
    if (isValid) {
        this.style.borderColor = 'green';
    } else {
        this.style.borderColor = 'red';
    }
});

// 提交验证
form.addEventListener('submit', function(event) {
    let email = emailInput.value;
    
    if (!email) {
        event.preventDefault();
        alert('请输入邮箱地址');
        emailInput.focus();
    }
});
```

### 11.6.2 防抖和节流

**防抖（Debounce）**

防抖确保函数在指定时间内只执行一次，如果在此期间再次触发，则重新计时。

```javascript
function debounce(func, wait) {
    let timeout;
    
    return function(...args) {
        clearTimeout(timeout);
        timeout = setTimeout(() => func.apply(this, args), wait);
    };
}

// 使用
let searchInput = document.getElementById('search');

searchInput.addEventListener('input', debounce(function() {
    console.log('搜索：', this.value);
    // 执行搜索请求
}, 500));
```

**节流（Throttle）**

节流确保函数在指定时间间隔内最多执行一次。

```javascript
function throttle(func, limit) {
    let inThrottle;
    
    return function(...args) {
        if (!inThrottle) {
            func.apply(this, args);
            inThrottle = true;
            setTimeout(() => inThrottle = false, limit);
        }
    };
}

// 使用
window.addEventListener('scroll', throttle(function() {
    console.log('滚动位置：', window.scrollY);
}, 200));
```

### 11.6.3 拖拽实现

```javascript
let draggable = document.getElementById('draggable');
let isDragging = false;
let currentX, currentY, initialX, initialY;

draggable.addEventListener('mousedown', dragStart);
document.addEventListener('mousemove', drag);
document.addEventListener('mouseup', dragEnd);

function dragStart(event) {
    initialX = event.clientX - draggable.offsetLeft;
    initialY = event.clientY - draggable.offsetTop;
    
    if (event.target === draggable) {
        isDragging = true;
    }
}

function drag(event) {
    if (isDragging) {
        event.preventDefault();
        
        currentX = event.clientX - initialX;
        currentY = event.clientY - initialY;
        
        draggable.style.left = currentX + 'px';
        draggable.style.top = currentY + 'px';
    }
}

function dragEnd() {
    initialX = currentX;
    initialY = currentY;
    isDragging = false;
}
```

## 11.7 自定义事件

### 11.7.1 创建和触发自定义事件

```javascript
// 创建自定义事件
let customEvent = new Event('myEvent');

// 创建带数据的自定义事件
let customEventWithData = new CustomEvent('userLogin', {
    detail: {
        username: 'john',
        timestamp: Date.now()
    },
    bubbles: true,
    cancelable: true
});

// 监听自定义事件
document.addEventListener('userLogin', function(event) {
    console.log('用户登录：', event.detail.username);
    console.log('登录时间：', new Date(event.detail.timestamp));
});

// 触发自定义事件
document.dispatchEvent(customEventWithData);
```

### 11.7.2 自定义事件应用

```javascript
// 组件通信
class TaskManager {
    constructor() {
        this.tasks = [];
    }
    
    addTask(task) {
        this.tasks.push(task);
        
        // 触发任务添加事件
        document.dispatchEvent(new CustomEvent('taskAdded', {
            detail: { task: task }
        }));
    }
    
    completeTask(taskId) {
        let task = this.tasks.find(t => t.id === taskId);
        if (task) {
            task.completed = true;
            
            // 触发任务完成事件
            document.dispatchEvent(new CustomEvent('taskCompleted', {
                detail: { task: task }
            }));
        }
    }
}

// 监听事件
document.addEventListener('taskAdded', function(event) {
    console.log('新任务添加：', event.detail.task);
    updateTaskList();
});

document.addEventListener('taskCompleted', function(event) {
    console.log('任务完成：', event.detail.task);
    updateStats();
});
```
