# 第四章 CSS基础与选择器

## 4.1 CSS概述

### 4.1.1 什么是CSS

CSS（Cascading Style Sheets，层叠样式表）是用于描述HTML文档外观和格式的样式表语言。CSS定义了元素的显示方式，包括颜色、字体、布局、动画等视觉效果。

CSS将内容（HTML）与表现（样式）分离，使得网页更易于维护和更新。

### 4.1.2 CSS的发展历程

- CSS1：1996年发布，包含基本的字体、颜色、间距等属性
- CSS2：1998年发布，增加了定位、z-index、媒体类型等
- CSS2.1：2011年发布，修正了CSS2的问题
- CSS3：模块化发布，包含众多新特性如动画、变换、网格布局等
- CSS4：正在开发中，各模块独立推进

### 4.1.3 CSS的工作原理

浏览器解析HTML文档时，会同时解析关联的CSS样式，然后根据CSS规则计算每个元素的最终样式，并将元素渲染到页面上。

CSS的层叠机制决定了当多个规则应用于同一元素时，哪个规则生效。层叠顺序考虑以下因素：

1. 来源（浏览器默认样式、用户样式、作者样式）
2. 特异性（选择器的权重）
3. 重要性（`!important`声明）
4. 源代码顺序（后定义的规则优先级更高）

## 4.2 CSS引入方式

### 4.2.1 外部样式表

将CSS代码保存在独立的`.css`文件中，通过`<link>`元素引入HTML文档。这是推荐的方式，可以实现样式复用和内容与表现的完全分离。

```html
<!-- 在HTML的head部分引入 -->
<head>
    <link rel="stylesheet" href="styles.css">
</head>
```

`styles.css`文件内容：

```css
body {
    font-family: Arial, sans-serif;
    line-height: 1.6;
}

h1 {
    color: #333;
}
```

### 4.2.2 内部样式表

将CSS代码放在HTML文档的`<style>`元素内，适用于单页面特有的样式。

```html
<head>
    <style>
        body {
            background-color: #f5f5f5;
        }
        
        h1 {
            color: #333;
            text-align: center;
        }
    </style>
</head>
```

### 4.2.3 内联样式

直接在HTML元素的`style`属性中定义样式。这种方式优先级最高，但应避免使用，因为它破坏了内容与表现的分离。

```html
<p style="color: red; font-size: 16px;">这是一段红色文字。</p>
```

### 4.2.4 引入方式的优先级

当同一元素的样式在多种方式中定义时，优先级从高到低为：

1. 内联样式（`style`属性）
2. 内部样式表（`<style>`元素）
3. 外部样式表（`<link>`引入）
4. 浏览器默认样式

注意：具体优先级还受选择器特异性和`!important`的影响。

## 4.3 CSS语法基础

### 4.3.1 基本语法结构

CSS规则由选择器和声明块组成：

```css
选择器 {
    属性: 值;
    属性: 值;
}
```

示例：

```css
h1 {
    color: blue;
    font-size: 24px;
}
```

### 4.3.2 选择器

选择器指定了样式规则应用的HTML元素。

### 4.3.3 声明

声明由属性和值组成，以冒号分隔，以分号结束。

```css
property: value;
```

### 4.3.4 注释

CSS注释使用`/* */`包裹，可以跨越多行：

```css
/* 这是单行注释 */

/*
    这是
    多行注释
*/

h1 {
    color: blue; /* 设置文字颜色 */
}
```

### 4.3.5 多个选择器组合

可以使用逗号分隔多个选择器，为它们应用相同的样式：

```css
h1, h2, h3 {
    font-family: Georgia, serif;
    color: #333;
}
```

## 4.4 CSS选择器

### 4.4.1 基本选择器

**元素选择器（类型选择器）**

选择指定类型的所有HTML元素：

```css
p {
    line-height: 1.6;
}

h1 {
    font-size: 32px;
}
```

**类选择器**

选择具有指定类名的所有元素，以点号（`.`）开头：

```css
.highlight {
    background-color: yellow;
}

.button {
    padding: 10px 20px;
    border: 1px solid #ccc;
}
```

HTML中使用：

```html
<p class="highlight">这段文字高亮显示。</p>
<button class="button">按钮</button>
```

一个元素可以有多个类：

```html
<button class="button primary">主要按钮</button>
```

```css
.button.primary {
    background-color: blue;
    color: white;
}
```

**ID选择器**

选择具有指定ID的元素，以井号（`#`）开头：

```css
#header {
    background-color: #333;
    color: white;
}

#main-content {
    max-width: 1200px;
    margin: 0 auto;
}
```

HTML中使用：

```html
<header id="header">...</header>
<main id="main-content">...</main>
```

注意：ID在文档中应该是唯一的，不应将ID选择器用于多个元素。

**通用选择器**

选择所有元素，以星号（`*`）表示：

```css
* {
    margin: 0;
    padding: 0;
    box-sizing: border-box;
}
```

### 4.4.2 组合选择器

**后代选择器**

选择某个元素内部的所有指定后代元素，使用空格分隔：

```css
/* 选择nav元素内的所有a元素 */
nav a {
    text-decoration: none;
    color: #333;
}

/* 选择article元素内的所有p元素 */
article p {
    margin-bottom: 1em;
}
```

**子元素选择器**

选择某个元素的直接子元素，使用大于号（`>`）分隔：

```css
/* 选择ul的直接子li元素 */
ul > li {
    list-style-type: disc;
}

/* 选择nav的直接子a元素 */
nav > a {
    font-weight: bold;
}
```

**相邻兄弟选择器**

选择紧接在另一个元素之后的元素，使用加号（`+`）分隔：

```css
/* 选择紧跟在h2后面的p元素 */
h2 + p {
    font-size: 1.1em;
}

/* 选择紧跟在input后面的label元素 */
input + label {
    margin-left: 5px;
}
```

**通用兄弟选择器**

选择在另一个元素之后的所有同级元素，使用波浪号（`~`）分隔：

```css
/* 选择h2后面的所有p元素 */
h2 ~ p {
    color: #666;
}
```

### 4.4.3 属性选择器

**存在属性选择器**

选择具有指定属性的元素：

```css
/* 选择所有具有title属性的元素 */
[title] {
    cursor: help;
}

/* 选择所有具有href属性的a元素 */
a[href] {
    color: blue;
}
```

**精确属性值选择器**

选择具有指定属性值的元素：

```css
/* 选择type属性值为text的input元素 */
input[type="text"] {
    border: 1px solid #ccc;
}

/* 选择target属性值为_blank的a元素 */
a[target="_blank"] {
    padding-right: 15px;
}
```

**包含属性值选择器**

选择属性值包含指定单词的元素（单词之间用空格分隔）：

```css
/* 选择class属性包含button的类名的元素 */
[class~="button"] {
    border-radius: 4px;
}
```

**开头属性值选择器**

选择属性值以指定字符串开头的元素：

```css
/* 选择href属性以https开头的a元素 */
a[href^="https"] {
    color: green;
}

/* 选择class属性以col-开头的元素 */
[class^="col-"] {
    float: left;
}
```

**结尾属性值选择器**

选择属性值以指定字符串结尾的元素：

```css
/* 选择href属性以.pdf结尾的a元素 */
a[href$=".pdf"] {
    background: url(pdf-icon.png) no-repeat right center;
}

/* 选择src属性以.jpg结尾的img元素 */
img[src$=".jpg"] {
    border: 2px solid #ccc;
}
```

**子串属性值选择器**

选择属性值包含指定子串的元素：

```css
/* 选择href属性包含example的a元素 */
a[href*="example"] {
    color: orange;
}
```

### 4.4.4 伪类选择器

伪类用于选择元素的特定状态或位置。

**链接伪类**

```css
/* 未访问的链接 */
a:link {
    color: blue;
}

/* 已访问的链接 */
a:visited {
    color: purple;
}

/* 鼠标悬停 */
a:hover {
    text-decoration: underline;
}

/* 激活状态（点击时） */
a:active {
    color: red;
}
```

注意：链接伪类的顺序应为`:link`、`:visited`、`:hover`、`:active`（记忆口诀：LoVe HAte）。

**表单状态伪类**

```css
/* 获得焦点的输入框 */
input:focus {
    outline: 2px solid blue;
}

/* 必填字段 */
input:required {
    border-left: 3px solid red;
}

/* 有效的输入 */
input:valid {
    border-color: green;
}

/* 无效的输入 */
input:invalid {
    border-color: red;
}

/* 禁用的元素 */
input:disabled {
    background-color: #eee;
}

/* 启用的元素 */
input:enabled {
    background-color: white;
}

/* 选中的单选框或复选框 */
input:checked {
    accent-color: blue;
}
```

**结构性伪类**

```css
/* 第一个子元素 */
li:first-child {
    font-weight: bold;
}

/* 最后一个子元素 */
li:last-child {
    border-bottom: none;
}

/* 第n个子元素 */
li:nth-child(3) {
    color: red;
}

/* 奇数个子元素 */
li:nth-child(odd) {
    background-color: #f5f5f5;
}

/* 偶数个子元素 */
li:nth-child(even) {
    background-color: white;
}

/* 每3个元素中的第1个 */
li:nth-child(3n+1) {
    margin-left: 0;
}

/* 唯一子元素 */
p:only-child {
    font-size: 1.2em;
}

/* 没有子元素的元素 */
div:empty {
    display: none;
}
```

**否定伪类**

```css
/* 选择不是.active类的所有div元素 */
div:not(.active) {
    opacity: 0.5;
}

/* 选择不是第一个子元素的所有li元素 */
li:not(:first-child) {
    margin-top: 10px;
}
```

### 4.4.5 伪元素选择器

伪元素用于选择元素的特定部分或生成内容。

**首字母和首行伪元素**

```css
/* 段落的第一个字母 */
p::first-letter {
    font-size: 2em;
    float: left;
}

/* 段落的第一行 */
p::first-line {
    font-weight: bold;
}
```

**前后内容伪元素**

```css
/* 在元素前插入内容 */
.quote::before {
    content: '"';
    font-size: 2em;
}

/* 在元素后插入内容 */
.quote::after {
    content: '"';
    font-size: 2em;
}

/* 清除浮动 */
.clearfix::after {
    content: '';
    display: table;
    clear: both;
}
```

**选中文本伪元素**

```css
/* 选中的文本 */
::selection {
    background-color: yellow;
    color: black;
}
```

**占位符伪元素**

```css
/* 输入框的占位符文本 */
input::placeholder {
    color: #999;
    font-style: italic;
}
```

## 4.5 选择器特异性

### 4.5.1 特异性计算规则

当多个选择器应用于同一元素时，浏览器根据特异性决定哪个规则生效。特异性按以下方式计算：

- 内联样式：1000分
- ID选择器：100分
- 类选择器、属性选择器、伪类：10分
- 元素选择器、伪元素：1分
- 通用选择器：0分

### 4.5.2 特异性示例

```css
/* 特异性：0,0,1,1 = 11分 */
nav a { }

/* 特异性：0,0,2,0 = 20分 */
.nav .item { }

/* 特异性：0,1,0,1 = 101分 */
#header a { }

/* 特异性：0,1,1,0 = 110分 */
#header .nav { }

/* 特异性：1,0,0,0 = 1000分 */
style="color: red;"
```

### 4.5.3 重要性声明

使用`!important`可以覆盖任何特异性计算，但应谨慎使用：

```css
.button {
    background-color: blue !important;
}
```

`!important`的使用原则：

- 尽量避免使用
- 仅在覆盖第三方样式或调试时使用
- 不要在自己的CSS中过度依赖

## 4.6 CSS变量

CSS自定义属性（变量）允许定义可复用的值：

```css
/* 定义变量（通常在:root中定义全局变量） */
:root {
    --primary-color: #007bff;
    --secondary-color: #6c757d;
    --font-size-base: 16px;
    --spacing-unit: 8px;
}

/* 使用变量 */
.button {
    background-color: var(--primary-color);
    font-size: var(--font-size-base);
    padding: calc(var(--spacing-unit) * 2);
}

/* 提供默认值 */
.alert {
    color: var(--alert-color, red);
}
```

变量的作用域：

```css
/* 全局变量 */
:root {
    --global-color: blue;
}

/* 局部变量 */
.card {
    --card-padding: 20px;
    padding: var(--card-padding);
}

/* 子元素可以访问父元素的变量 */
.card .title {
    padding: var(--card-padding);
}
```
