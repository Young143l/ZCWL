# 第八章 CSS响应式设计

## 8.1 响应式设计概述

### 8.1.1 什么是响应式设计

响应式Web设计（Responsive Web Design）是一种使网页能够根据用户设备的屏幕尺寸、分辨率和方向自动调整布局和内容显示方式的设计方法。响应式设计的目标是提供最佳的浏览体验，无论是在桌面电脑、平板还是手机上访问。

### 8.1.2 响应式设计的核心原则

响应式设计基于三个核心技术：

- **流式网格布局**：使用相对单位（如百分比）而非固定像素
- **弹性图像和媒体**：图像和媒体能够自适应容器大小
- **CSS媒体查询**：根据设备特性应用不同的样式规则

### 8.1.3 视口设置

在HTML中设置视口是响应式设计的第一步：

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```

属性说明：

- `width=device-width`：设置视口宽度等于设备宽度
- `initial-scale=1.0`：设置初始缩放比例为1
- `maximum-scale=1.0`：最大缩放比例（可选）
- `user-scalable=no`：禁止用户缩放（不推荐）

## 8.2 媒体查询

### 8.2.1 媒体查询基本语法

媒体查询允许根据设备的特性应用不同的CSS样式：

```css
/* 基本语法 */
@media 媒体类型 and (媒体特性) {
    /* CSS规则 */
}

/* 示例：屏幕宽度小于768px时应用 */
@media screen and (max-width: 768px) {
    body {
        font-size: 14px;
    }
}
```

### 8.2.2 媒体类型

```css
/* 所有设备 */
@media all { }

/* 屏幕设备 */
@media screen { }

/* 打印设备 */
@media print { }

/* 语音合成器 */
@media speech { }
```

### 8.2.3 常用媒体特性

**宽度相关**

```css
/* 最大宽度 */
@media (max-width: 768px) { }

/* 最小宽度 */
@media (min-width: 769px) { }

/* 宽度范围 */
@media (min-width: 768px) and (max-width: 1024px) { }
```

**高度相关**

```css
@media (max-height: 600px) { }
@media (min-height: 800px) { }
```

**方向**

```css
/* 横向 */
@media (orientation: landscape) { }

/* 纵向 */
@media (orientation: portrait) { }
```

**分辨率**

```css
/* 高分辨率屏幕 */
@media (min-resolution: 192dpi) { }
@media (-webkit-min-device-pixel-ratio: 2) { }
```

**其他特性**

```css
/* 悬停支持 */
@media (hover: hover) { }

/* 指针类型 */
@media (pointer: fine) { }   /* 鼠标 */
@media (pointer: coarse) { } /* 触摸 */

/* 暗色模式 */
@media (prefers-color-scheme: dark) { }

/* 减少动画 */
@media (prefers-reduced-motion: reduce) { }
```

### 8.2.4 媒体查询逻辑

```css
/* AND - 同时满足 */
@media screen and (min-width: 768px) and (max-width: 1024px) { }

/* OR - 逗号分隔 */
@media screen and (max-width: 768px), print { }

/* NOT - 否定 */
@media not screen and (max-width: 768px) { }

/* ONLY - 仅适用于特定媒体类型 */
@media only screen and (max-width: 768px) { }
```

### 8.2.5 断点选择

常见的响应式断点：

```css
/* 手机 */
@media (max-width: 576px) { }

/* 平板 */
@media (min-width: 577px) and (max-width: 768px) { }

/* 小型桌面 */
@media (min-width: 769px) and (max-width: 992px) { }

/* 中型桌面 */
@media (min-width: 993px) and (max-width: 1200px) { }

/* 大型桌面 */
@media (min-width: 1201px) { }
```

移动优先的断点设计：

```css
/* 基础样式（手机） */
.container {
    padding: 10px;
}

/* 平板 */
@media (min-width: 768px) {
    .container {
        padding: 20px;
    }
}

/* 桌面 */
@media (min-width: 1024px) {
    .container {
        padding: 40px;
        max-width: 1200px;
        margin: 0 auto;
    }
}
```

## 8.3 流式布局

### 8.3.1 相对单位

**百分比**

```css
.container {
    width: 100%;
    max-width: 1200px;
}

.column {
    width: 50%; /* 父容器宽度的50% */
}
```

**视口单位**

```css
.full-screen {
    width: 100vw;  /* 视口宽度的100% */
    height: 100vh; /* 视口高度的100% */
}

.half-width {
    width: 50vw;
}
```

**em和rem**

```css
/* em：相对于父元素的字体大小 */
.parent {
    font-size: 16px;
}
.child {
    font-size: 1.5em; /* 24px */
    padding: 2em;     /* 32px */
}

/* rem：相对于根元素的字体大小 */
html {
    font-size: 16px;
}
.element {
    font-size: 1.5rem; /* 24px */
    margin: 2rem;      /* 32px */
}
```

### 8.3.2 流式网格

```css
.row {
    display: flex;
    flex-wrap: wrap;
    margin: 0 -15px;
}

.col {
    flex: 1;
    padding: 0 15px;
}

.col-6 {
    flex: 0 0 50%;
    max-width: 50%;
    padding: 0 15px;
}

.col-4 {
    flex: 0 0 33.333%;
    max-width: 33.333%;
    padding: 0 15px;
}

/* 响应式 */
@media (max-width: 768px) {
    .col-6,
    .col-4 {
        flex: 0 0 100%;
        max-width: 100%;
    }
}
```

## 8.4 弹性图像和媒体

### 8.4.1 响应式图像

```css
/* 基础响应式图像 */
img {
    max-width: 100%;
    height: auto;
    display: block;
}

/* 容器内的图像 */
.image-container img {
    width: 100%;
    height: auto;
}

/* 保持比例的背景图像 */
.bg-image {
    background-image: url('image.jpg');
    background-size: cover;
    background-position: center;
    padding-top: 56.25%; /* 16:9比例 */
}
```

### 8.4.2 响应式视频

```css
.video-container {
    position: relative;
    padding-bottom: 56.25%; /* 16:9比例 */
    height: 0;
    overflow: hidden;
}

.video-container iframe,
.video-container video {
    position: absolute;
    top: 0;
    left: 0;
    width: 100%;
    height: 100%;
}
```

### 8.4.3 picture元素

使用`<picture>`元素提供不同尺寸的图像：

```html
<picture>
    <source media="(min-width: 1200px)" srcset="large.jpg">
    <source media="(min-width: 768px)" srcset="medium.jpg">
    <img src="small.jpg" alt="描述">
</picture>
```

### 8.4.4 srcset属性

```html
<img srcset="small.jpg 480w,
             medium.jpg 768w,
             large.jpg 1200w"
     sizes="(max-width: 480px) 100vw,
            (max-width: 768px) 50vw,
            33vw"
     src="fallback.jpg"
     alt="描述">
```

## 8.5 响应式排版

### 8.5.1 流式字体大小

```css
/* 使用clamp实现流式字体 */
h1 {
    font-size: clamp(1.5rem, 4vw + 1rem, 3rem);
}

/* 使用媒体查询 */
h1 {
    font-size: 1.5rem;
}

@media (min-width: 768px) {
    h1 {
        font-size: 2rem;
    }
}

@media (min-width: 1200px) {
    h1 {
        font-size: 2.5rem;
    }
}
```

### 8.5.2 响应式行高

```css
body {
    line-height: 1.5;
}

@media (min-width: 768px) {
    body {
        line-height: 1.6;
    }
}
```

## 8.7 容器查询

### 8.7.1 容器查询概述

容器查询（Container Queries）是CSS的新特性，允许根据容器的大小而非视口大小应用样式。

### 8.7.2 使用容器查询

```css
/* 定义容器 */
.card-container {
    container-type: inline-size;
    container-name: card;
}

/* 容器查询 */
@container card (min-width: 400px) {
    .card {
        display: flex;
    }
    
    .card-image {
        width: 40%;
    }
    
    .card-content {
        width: 60%;
    }
}

@container card (min-width: 600px) {
    .card-title {
        font-size: 1.5rem;
    }
}
```

---

响应式设计是现代Web开发的核心技能。通过媒体查询、流式布局、弹性图像和响应式排版等技术，可以创建适配各种设备的网页。采用移动优先的设计策略，从基础样式开始，逐步添加更复杂的布局，是响应式设计的最佳实践。
