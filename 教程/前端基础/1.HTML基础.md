# 第一章 HTML基础

## 1.1 HTML概述

### 1.1.1 什么是HTML

HTML（HyperText Markup Language，超文本标记语言）是构建Web页面的标准标记语言。HTML使用标记标签（markup tags）来描述网页的结构和内容。HTML文档由HTML元素组成，这些元素通过标签进行标识。

HTML并非编程语言，而是一种标记语言。标记语言是一套标记标签（markup tag），HTML使用标记标签来描述网页。

### 1.1.2 HTML的发展历程

HTML由蒂姆·伯纳斯-李（Tim Berners-Lee）于1991年创立。W3C（World Wide Web Consortium，万维网联盟）自1997年起成为HTML标准的维护组织。

- HTML 4.01：1999年发布，是广泛使用的一个版本
- XHTML 1.0：2000年发布，基于XML的HTML
- HTML5：2014年正式发布，是目前最新的标准

HTML5引入了大量新特性，包括语义化元素、多媒体支持、Canvas绘图、本地存储等。

### 1.1.3 HTML文档的基本结构

一个标准的HTML5文档包含以下基本结构：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>页面标题</title>
</head>
<body>
    <!-- 页面内容 -->
</body>
</html>
```

各部分的说明：

- `<!DOCTYPE html>`：文档类型声明，告知浏览器使用HTML5标准解析文档
- `<html>`：HTML文档的根元素，`lang`属性指定文档语言
- `<head>`：包含文档的元数据（metadata），如字符编码、视口设置、标题等
- `<meta charset="UTF-8">`：指定文档使用UTF-8字符编码
- `<meta name="viewport">`：配置视口，用于响应式设计
- `<title>`：定义浏览器标签页上显示的标题
- `<body>`：包含文档的所有可见内容

## 1.2 HTML元素与标签

### 1.2.1 元素的基本语法

HTML元素通常由开始标签、内容和结束标签组成：

```html
<标签名>内容</标签名>
```

例如：

```html
<p>这是一个段落。</p>
```

某些元素为空元素（void elements），不包含内容和结束标签：

```html
<br>
<img src="image.jpg" alt="描述文本">
<input type="text">
```

### 1.2.2 元素的属性

HTML元素可以拥有属性，属性提供元素的附加信息。属性以名称/值对的形式出现，写在开始标签中：

```html
<标签名 属性名="属性值">内容</标签名>
```

属性值应始终使用引号包裹（单引号或双引号均可）：

```html
<a href="https://example.com" target="_blank">链接文本</a>
<img src="photo.jpg" alt="照片描述" width="300" height="200">
```

常用全局属性：

- `id`：为元素指定唯一的标识符
- `class`：为元素指定一个或多个类名
- `style`：为元素指定内联样式
- `title`：为元素提供额外信息（通常以工具提示形式显示）
- `data-*`：自定义数据属性

### 1.2.3 嵌套元素

HTML元素可以嵌套在其他元素内部。嵌套时应确保正确闭合标签，遵循先进后出的原则：

```html
<p>这是一个<strong>重要的</strong>段落。</p>
```

错误的嵌套示例：

```html
<!-- 错误：标签交叉嵌套 -->
<p>这是一个<strong>重要的</p></strong>
```

## 1.3 常用HTML标签

### 1.3.1 标题标签

HTML提供六级标题标签，从`<h1>`到`<h6>`，`<h1>`表示最高级别标题，`<h6>`表示最低级别：

```html
<h1>一级标题</h1>
<h2>二级标题</h2>
<h3>三级标题</h3>
<h4>四级标题</h4>
<h5>五级标题</h5>
<h6>六级标题</h6>
```

使用规范：

- 每个页面应只有一个`<h1>`标签
- 标题级别应按层次使用，不要跳级
- 标题用于文档结构，而非文本大小控制

### 1.3.2 段落与文本标签

**段落标签**：

```html
<p>这是一个段落。段落是文本的基本单位，浏览器会自动在段落前后添加空白。</p>
```

**换行标签**：

```html
<p>这是第一行<br>这是第二行</p>
```

**水平分割线**：

```html
<hr>
```

**文本格式化标签**：

```html
<strong>重要文本（加粗）</strong>
<em>强调文本（斜体）</em>
<mark>标记文本（高亮）</mark>
<small>小号文本</small>
<del>删除文本</del>
<ins>插入文本</ins>
<sub>下标</sub>
<sup>上标</sup>
<code>代码片段</code>
<pre>预格式化文本</pre>
```

### 1.3.3 链接标签

`<a>`标签用于创建超链接：

```html
<!-- 外部链接 -->
<a href="https://www.example.com">访问示例网站</a>

<!-- 在新窗口打开 -->
<a href="https://www.example.com" target="_blank">在新窗口打开</a>

<!-- 内部链接（锚点） -->
<a href="#section1">跳转到第一节</a>

<!-- 页面内锚点 -->
<h2 id="section1">第一节</h2>

<!-- 邮件链接 -->
<a href="mailto:email@example.com">发送邮件</a>

<!-- 电话链接 -->
<a href="tel:+8612345678900">拨打电话</a>
```

`target`属性的取值：

- `_self`：在当前窗口打开（默认）
- `_blank`：在新窗口或新标签页打开
- `_parent`：在父框架中打开
- `_top`：在整个窗口中打开

### 1.3.4 图像标签

`<img>`标签用于在页面中嵌入图像：

```html
<img src="image.jpg" alt="图像描述" width="500" height="300">
```

属性说明：

- `src`：图像文件的路径（必需）
- `alt`：图像的替代文本，用于图像无法显示时或辅助技术（必需）
- `width`：图像宽度（像素）
- `height`：图像高度（像素）
- `loading`：加载策略（`lazy`表示延迟加载）

### 1.3.5 列表标签

**无序列表**：

```html
<ul>
    <li>苹果</li>
    <li>香蕉</li>
    <li>橙子</li>
</ul>
```

**有序列表**：

```html
<ol>
    <li>第一步</li>
    <li>第二步</li>
    <li>第三步</li>
</ol>
```

有序列表的`type`属性：

```html
<ol type="A">  <!-- 大写字母：A, B, C -->
<ol type="a">  <!-- 小写字母：a, b, c -->
<ol type="I">  <!-- 大写罗马数字：I, II, III -->
<ol type="i">  <!-- 小写罗马数字：i, ii, iii -->
<ol type="1">  <!-- 阿拉伯数字：1, 2, 3（默认） -->
```

**定义列表**：

```html
<dl>
    <dt>HTML</dt>
    <dd>超文本标记语言</dd>
    <dt>CSS</dt>
    <dd>层叠样式表</dd>
</dl>
```

**嵌套列表**：

```html
<ul>
    <li>水果
        <ul>
            <li>苹果</li>
            <li>香蕉</li>
        </ul>
    </li>
    <li>蔬菜</li>
</ul>
```

### 1.3.6 表格标签

```html
<table>
    <caption>表格标题</caption>
    <thead>
        <tr>
            <th>姓名</th>
            <th>年龄</th>
            <th>城市</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>张三</td>
            <td>25</td>
            <td>北京</td>
        </tr>
        <tr>
            <td>李四</td>
            <td>30</td>
            <td>上海</td>
        </tr>
    </tbody>
    <tfoot>
        <tr>
            <td colspan="3">总计：2人</td>
        </tr>
    </tfoot>
</table>
```

表格相关标签：

- `<table>`：定义表格
- `<caption>`：表格标题
- `<thead>`：表头区域
- `<tbody>`：表体区域
- `<tfoot>`：表尾区域
- `<tr>`：表格行
- `<th>`：表头单元格（默认加粗居中）
- `<td>`：数据单元格

表格属性：

- `colspan`：单元格跨列数
- `rowspan`：单元格跨行数

### 1.3.7 区块与内联元素

**块级元素**

块级元素独占一行，可以设置宽高。常用块级元素包括：

- `<div>`：通用容器
- `<p>`：段落
- `<h1>`至`<h6>`：标题
- `<ul>`、`<ol>`、`<li>`：列表
- `<table>`：表格
- `<header>`、`<footer>`、`<section>`、`<article>`：语义化元素

```html
<div>
    <p>这是一个段落。</p>
    <p>这是另一个段落。</p>
</div>
```

**内联元素**

内联元素不独占一行，宽度和高度由内容决定。常用内联元素包括：

- `<span>`：通用内联容器
- `<a>`：链接
- `<strong>`、`<em>`：文本强调
- `<img>`：图像
- `<code>`：代码
- `<br>`：换行

```html
<p>这是一段文字，其中<span style="color: red;">这部分</span>是红色的。</p>
```

## 1.4 HTML注释

HTML注释用于在代码中添加说明，浏览器不会渲染注释内容：

```html
<!-- 这是单行注释 -->

<!--
    这是
    多行注释
-->

<div>
    <!-- TODO: 完善此部分功能 -->
    <p>段落内容</p>
</div>
```

注释的使用场景：

- 解释代码的功能
- 临时禁用代码进行调试
- 标记待办事项
- 组织代码结构

## 1.5 特殊字符与实体

HTML中某些字符具有特殊含义，如需显示这些字符本身，应使用字符实体：

| 字符 | 实体名称 | 实体编号 | 说明 |
|------|----------|----------|------|
| `<` | `&lt;` | `&#60;` | 小于号 |
| `>` | `&gt;` | `&#62;` | 大于号 |
| `&` | `&amp;` | `&#38;` | 和号 |
| `"` | `&quot;` | `&#34;` | 双引号 |
| `'` | `&apos;` | `&#39;` | 单引号 |
| 空格 | `&nbsp;` | `&#160;` | 不间断空格 |
| 人民币 | `&yen;` | `&#165;` | 元符号 |
| 版权 | `&copy;` | `&#169;` | 版权符号 |
| 注册商标 | `&reg;` | `&#174;` | 注册商标符号 |

示例：

```html
<p>5 &lt; 10 且 10 &gt; 5</p>
<p>版权所有 &copy; 2024 公司名称</p>
<p>价格：&yen;100</p>
```

## 1.6 完整的HTML页面示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>我的第一个网页</title>
</head>
<body>
    <h1>欢迎来到我的网站</h1>
    
    <p>这是一个使用HTML5标准构建的简单网页。</p>
    
    <h2>关于我</h2>
    <p>我是一名前端开发学习者，正在学习HTML、CSS和JavaScript。</p>
    
    <h2>我的兴趣</h2>
    <ul>
        <li>编程</li>
        <li>阅读</li>
        <li>旅行</li>
    </ul>
    
    <h2>联系方式</h2>
    <p>邮箱：<a href="mailto:example@email.com">example@email.com</a></p>
    
    <hr>
    
    <p><small>版权所有 &copy; 2024</small></p>
</body>
</html>
```
