# 第十章 JavaScript DOM操作

## 10.1 DOM概述

### 10.1.1 什么是DOM

DOM（Document Object Model，文档对象模型）是W3C标准，它定义了访问和操作HTML文档的标准方法。DOM将HTML文档表示为一个树形结构，其中每个节点都是文档的一部分（如元素、属性、文本等）。

通过DOM，JavaScript可以：

- 动态修改HTML元素和内容
- 动态修改CSS样式
- 响应用户交互
- 创建和删除HTML元素
- 获取和设置元素属性

### 10.1.2 DOM树结构

HTML文档被解析为一个树形结构：

```
Document
  └── html
      ├── head
      │   ├── title
      │   └── meta
      └── body
          ├── header
          │   └── h1
          ├── main
          │   ├── p
          │   └── img
          └── footer
              └── p
```

节点类型：

- **元素节点**：HTML元素（如`<div>`、`<p>`）
- **文本节点**：元素内的文本内容
- **属性节点**：元素的属性
- **注释节点**：HTML注释
- **文档节点**：整个文档（`document`对象）

## 10.2 获取DOM元素

### 10.2.1 getElementById

通过元素的`id`属性获取单个元素：

```javascript
let element = document.getElementById('myId');
```

```html
<div id="container">内容</div>
<script>
    let container = document.getElementById('container');
    console.log(container);  // <div id="container">内容</div>
</script>
```

### 10.2.2 getElementsByClassName

通过元素的`class`属性获取元素集合（HTMLCollection）：

```javascript
let elements = document.getElementsByClassName('myClass');
```

```html
<div class="item">项目1</div>
<div class="item">项目2</div>
<div class="item">项目3</div>
<script>
    let items = document.getElementsByClassName('item');
    console.log(items.length);  // 3
    console.log(items[0]);      // 第一个.item元素
</script>
```

### 10.2.3 getElementsByTagName

通过标签名获取元素集合：

```javascript
let elements = document.getElementsByTagName('p');
```

```html
<p>段落1</p>
<p>段落2</p>
<script>
    let paragraphs = document.getElementsByTagName('p');
    console.log(paragraphs.length);  // 2
</script>
```

### 10.2.4 querySelector

使用CSS选择器获取第一个匹配的元素：

```javascript
let element = document.querySelector('.myClass');
let element = document.querySelector('#myId');
let element = document.querySelector('div.container > p:first-child');
```

```html
<div class="container">
    <p class="text">第一段</p>
    <p class="text">第二段</p>
</div>
<script>
    let firstText = document.querySelector('.container .text');
    console.log(firstText.textContent);  // "第一段"
</script>
```

### 10.2.5 querySelectorAll

使用CSS选择器获取所有匹配的元素（NodeList）：

```javascript
let elements = document.querySelectorAll('.myClass');
let elements = document.querySelectorAll('p, div');
let elements = document.querySelectorAll('[data-type="item"]');
```

```html
<ul>
    <li class="item">项目1</li>
    <li class="item">项目2</li>
    <li class="item">项目3</li>
</ul>
<script>
    let items = document.querySelectorAll('.item');
    items.forEach(item => {
        console.log(item.textContent);
    });
</script>
```

### 10.2.6 获取方法对比

| 方法 | 返回类型 | 是否实时 | 支持CSS选择器 |
|------|----------|----------|---------------|
| getElementById | Element/null | - | 否 |
| getElementsByClassName | HTMLCollection | 是 | 否 |
| getElementsByTagName | HTMLCollection | 是 | 否 |
| querySelector | Element/null | - | 是 |
| querySelectorAll | NodeList | 否 | 是 |

## 10.3 遍历DOM

### 10.3.1 父子关系

```javascript
let element = document.getElementById('myElement');

// 获取父元素
let parent = element.parentNode;
let parentElement = element.parentElement;

// 获取子元素
let children = element.childNodes;        // 包含文本节点
let elementChildren = element.children;   // 仅元素节点
let firstChild = element.firstChild;
let lastChild = element.lastChild;
let firstElementChild = element.firstElementChild;
let lastElementChild = element.lastElementChild;

// 获取子元素数量
let childCount = element.childElementCount;
```

### 10.3.2 兄弟关系

```javascript
let element = document.getElementById('myElement');

// 获取兄弟节点
let nextSibling = element.nextSibling;
let previousSibling = element.previousSibling;

// 获取兄弟元素
let nextElement = element.nextElementSibling;
let previousElement = element.previousElementSibling;
```

### 10.3.3 遍历示例

```javascript
// 遍历所有子元素
function traverseChildren(element) {
    for (let child of element.children) {
        console.log(child.tagName);
        traverseChildren(child);  // 递归遍历
    }
}

// 查找最近的祖先元素
function findAncestor(element, selector) {
    while (element) {
        if (element.matches && element.matches(selector)) {
            return element;
        }
        element = element.parentElement;
    }
    return null;
}
```

## 10.4 修改元素内容

### 10.4.1 innerHTML

`innerHTML`获取或设置元素的HTML内容：

```javascript
let element = document.getElementById('container');

// 获取HTML内容
let html = element.innerHTML;

// 设置HTML内容
element.innerHTML = '<p>新的段落</p>';

// 追加内容
element.innerHTML += '<p>追加的段落</p>';
```

注意：使用`innerHTML`插入用户输入的内容存在XSS安全风险。

### 10.4.2 textContent

`textContent`获取或设置元素的纯文本内容：

```javascript
let element = document.getElementById('container');

// 获取文本内容（不包含HTML标签）
let text = element.textContent;

// 设置文本内容（HTML标签会被转义）
element.textContent = '<p>这是纯文本</p>';
```

### 10.4.3 innerText

`innerText`与`textContent`类似，但会考虑CSS样式：

```javascript
let element = document.getElementById('container');

// 获取可见文本（考虑CSS隐藏）
let text = element.innerText;

// 设置文本内容
element.innerText = '新的文本';
```

`innerText`与`textContent`的区别：

- `innerText`会触发重排，性能较低
- `innerText`只返回可见文本
- `textContent`返回所有文本，包括隐藏元素
- `textContent`性能更好，推荐使用

## 10.5 修改元素属性

### 10.5.1 标准属性

```javascript
let link = document.getElementById('myLink');

// 获取属性
let href = link.href;
let target = link.getAttribute('target');

// 设置属性
link.href = 'https://example.com';
link.setAttribute('target', '_blank');

// 检查属性是否存在
let hasTarget = link.hasAttribute('target');

// 删除属性
link.removeAttribute('target');
```

### 10.5.2 自定义数据属性

HTML5引入了`data-*`属性用于存储自定义数据：

```html
<div id="user" data-id="123" data-role="admin" data-status="active">
    用户信息
</div>
```

```javascript
let user = document.getElementById('user');

// 获取data属性
dataset方式（推荐）
let userId = user.dataset.id;        // "123"
let userRole = user.dataset.role;    // "admin"
let userStatus = user.dataset.status; // "active"

// 设置data属性
user.dataset.level = 'premium';

// 删除data属性
delete user.dataset.status;

// getAttribute方式
let id = user.getAttribute('data-id');
user.setAttribute('data-level', 'premium');
```

### 10.5.3 类名操作

```javascript
let element = document.getElementById('myElement');

// className：获取或设置完整的class字符串
console.log(element.className);  // "class1 class2"
element.className = 'newClass';

// classList：更方便的类名操作（推荐）
element.classList.add('active');           // 添加类名
element.classList.remove('active');        // 移除类名
element.classList.toggle('active');        // 切换类名
element.classList.contains('active');      // 检查是否包含类名
element.classList.replace('old', 'new');   // 替换类名
```

### 10.5.4 样式操作

```javascript
let element = document.getElementById('myElement');

// 内联样式（style属性）
element.style.color = 'red';
element.style.backgroundColor = '#f0f0f0';
element.style.fontSize = '16px';
element.style.marginTop = '10px';

// 设置多个样式
element.style.cssText = 'color: red; background: blue; padding: 10px;';

// 获取计算样式
let computedStyle = window.getComputedStyle(element);
let color = computedStyle.color;
let fontSize = computedStyle.fontSize;
```

注意：`style`属性只能获取或设置内联样式，无法获取外部样式表中的样式。

## 10.6 创建和删除元素

### 10.6.1 创建元素

```javascript
// 创建新元素
let newDiv = document.createElement('div');

// 设置属性
newDiv.id = 'newDiv';
newDiv.className = 'container';
newDiv.textContent = '新创建的div';

// 设置样式
newDiv.style.backgroundColor = '#f0f0f0';
newDiv.style.padding = '20px';
```

### 10.6.2 插入元素

```javascript
let parent = document.getElementById('parent');
let newElement = document.createElement('div');
let referenceElement = document.getElementById('reference');

// 在末尾追加
parent.appendChild(newElement);

// 在开头插入
parent.insertBefore(newElement, parent.firstChild);

// 在参考元素之前插入
parent.insertBefore(newElement, referenceElement);

// 在参考元素之后插入（ES6新增）
referenceElement.after(newElement);

// 在参考元素之前插入（ES6新增）
referenceElement.before(newElement);

// 追加多个节点或字符串（ES6新增）
parent.append(newElement, '文本内容');

// 在开头插入多个节点或字符串（ES6新增）
parent.prepend(newElement, '文本内容');
```

### 10.6.3 替换元素

```javascript
let oldElement = document.getElementById('old');
let newElement = document.createElement('div');

// 替换子元素
parent.replaceChild(newElement, oldElement);

// ES6方式
oldElement.replaceWith(newElement);
```

### 10.6.4 删除元素

```javascript
let element = document.getElementById('toRemove');

// 通过父元素删除
element.parentNode.removeChild(element);

// 直接删除（ES6新增）
element.remove();

// 清空元素内容
element.innerHTML = '';

// 移除所有子元素
while (element.firstChild) {
    element.removeChild(element.firstChild);
}
```

### 10.6.5 克隆元素

```javascript
let original = document.getElementById('original');

// 浅克隆（只克隆元素本身，不包含子元素）
let shallowClone = original.cloneNode(false);

// 深克隆（克隆元素及其所有子元素）
let deepClone = original.cloneNode(true);

// 添加到文档
parent.appendChild(deepClone);
```

## 10.7 DOM操作最佳实践

### 10.7.1 批量操作使用文档片段

```javascript
// 不推荐：多次操作DOM
for (let i = 0; i < 100; i++) {
    let div = document.createElement('div');
    document.body.appendChild(div);  // 100次重排
}

// 推荐：使用文档片段
let fragment = document.createDocumentFragment();
for (let i = 0; i < 100; i++) {
    let div = document.createElement('div');
    fragment.appendChild(div);
}
document.body.appendChild(fragment);  // 1次重排
```

### 10.7.2 离线操作

```javascript
let element = document.getElementById('myElement');

// 从DOM中移除
let parent = element.parentNode;
parent.removeChild(element);

// 进行多次修改
for (let i = 0; i < 100; i++) {
    let child = document.createElement('div');
    element.appendChild(child);
}

// 重新插入DOM
parent.appendChild(element);
```

### 10.7.3 使用模板

```javascript
// 创建模板
let template = document.createElement('template');
template.innerHTML = `
    <div class="card">
        <h3 class="title"></h3>
        <p class="description"></p>
    </div>
`;

// 克隆使用
function createCard(title, description) {
    let clone = template.content.cloneNode(true);
    clone.querySelector('.title').textContent = title;
    clone.querySelector('.description').textContent = description;
    return clone;
}

// 添加到文档
document.body.appendChild(createCard('标题', '描述'));
```

## 10.8 完整示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
    <meta charset="UTF-8">
    <title>DOM操作示例</title>
    <style>
        .container {
            max-width: 600px;
            margin: 20px auto;
            padding: 20px;
        }
        
        .item {
            padding: 10px;
            margin: 10px 0;
            background-color: #f0f0f0;
            border-radius: 4px;
            display: flex;
            justify-content: space-between;
            align-items: center;
        }
        
        .item.completed {
            text-decoration: line-through;
            opacity: 0.6;
        }
        
        .btn {
            padding: 5px 10px;
            margin-left: 5px;
            cursor: pointer;
        }
        
        .input-group {
            display: flex;
            gap: 10px;
            margin-bottom: 20px;
        }
        
        #newItemInput {
            flex: 1;
            padding: 10px;
        }
    </style>
</head>
<body>
    <div class="container">
        <h1>待办事项列表</h1>
        
        <div class="input-group">
            <input type="text" id="newItemInput" placeholder="输入新事项">
            <button class="btn" onclick="addItem()">添加</button>
        </div>
        
        <div id="todoList"></div>
        
        <div>
            <p>总计: <span id="totalCount">0</span></p>
            <p>已完成: <span id="completedCount">0</span></p>
        </div>
    </div>

    <script>
        let todos = [];
        let nextId = 1;
        
        // 添加事项
        function addItem() {
            let input = document.getElementById('newItemInput');
            let text = input.value.trim();
            
            if (text === '') {
                alert('请输入内容');
                return;
            }
            
            let todo = {
                id: nextId++,
                text: text,
                completed: false
            };
            
            todos.push(todo);
            input.value = '';
            render();
        }
        
        // 切换完成状态
        function toggleTodo(id) {
            let todo = todos.find(t => t.id === id);
            if (todo) {
                todo.completed = !todo.completed;
                render();
            }
        }
        
        // 删除事项
        function deleteTodo(id) {
            todos = todos.filter(t => t.id !== id);
            render();
        }
        
        // 渲染列表
        function render() {
            let listContainer = document.getElementById('todoList');
            
            // 清空列表
            listContainer.innerHTML = '';
            
            // 创建文档片段
            let fragment = document.createDocumentFragment();
            
            todos.forEach(todo => {
                let itemDiv = document.createElement('div');
                itemDiv.className = 'item' + (todo.completed ? ' completed' : '');
                
                let textSpan = document.createElement('span');
                textSpan.textContent = todo.text;
                
                let buttonGroup = document.createElement('div');
                
                let toggleBtn = document.createElement('button');
                toggleBtn.className = 'btn';
                toggleBtn.textContent = todo.completed ? '未完成' : '完成';
                toggleBtn.onclick = () => toggleTodo(todo.id);
                
                let deleteBtn = document.createElement('button');
                deleteBtn.className = 'btn';
                deleteBtn.textContent = '删除';
                deleteBtn.onclick = () => deleteTodo(todo.id);
                
                buttonGroup.appendChild(toggleBtn);
                buttonGroup.appendChild(deleteBtn);
                
                itemDiv.appendChild(textSpan);
                itemDiv.appendChild(buttonGroup);
                
                fragment.appendChild(itemDiv);
            });
            
            listContainer.appendChild(fragment);
            
            // 更新统计
            document.getElementById('totalCount').textContent = todos.length;
            document.getElementById('completedCount').textContent = 
                todos.filter(t => t.completed).length;
        }
        
        // 回车键添加
        document.getElementById('newItemInput').addEventListener('keypress', function(e) {
            if (e.key === 'Enter') {
                addItem();
            }
        });
    </script>
</body>
</html>
```

---

本章详细介绍了JavaScript DOM操作的各种方法，包括获取元素、遍历DOM、修改内容和属性、创建和删除元素等。掌握这些技术是开发动态交互网页的基础。在实际开发中，应注意性能优化，避免频繁的DOM操作导致的重排和重绘问题。
