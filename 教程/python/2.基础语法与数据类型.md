# 第二章 基础语法与数据类型

## 2.1 标识符与关键字

### 标识符

标识符是程序中用于命名变量、函数、类、模块等的名称。Python标识符的命名规则如下：

- 由字母（a-z, A-Z）、数字（0-9）和下划线（_）组成
- 不能以数字开头
- 区分大小写
- 不能是Python关键字
- 以下划线开头的标识符有特殊含义

有效的标识符示例：`name`、`age`、`_value`、`__init__`、`student_name`

无效的标识符示例：`2name`（以数字开头）、`my-name`（包含连字符）、`my name`（包含空格）

### 关键字

关键字是Python预定义的具有特殊含义的单词，不能用作标识符。

| 关键字 | 说明 |
|--------|------|
| False、None、True | 布尔值和空值 |
| and、or、not | 逻辑运算符 |
| as | 用于import和with语句的别名 |
| assert | 断言，用于调试 |
| break、continue | 循环控制 |
| class | 定义类 |
| def | 定义函数 |
| del | 删除对象 |
| elif、else、if | 条件语句 |
| except、finally、raise、try | 异常处理 |
| for、while | 循环语句 |
| from、import | 导入模块 |
| global、nonlocal | 声明全局变量和非局部变量 |
| in、is | 成员运算符和身份运算符 |
| lambda | 创建匿名函数 |
| pass | 空语句，占位符 |
| return | 从函数返回值 |
| yield | 定义生成器 |
| with | 上下文管理器 |

## 2.2 变量

### 变量的定义

Python是动态类型语言，变量类型在运行时自动确定，无需显式声明。

```python
# 变量赋值
name = "Alice"
age = 20
height = 1.75
is_student = True

# 多个变量同时赋值
a = b = c = 0
x, y, z = 1, 2, 3

# 交换变量值
a, b = b, a
```

### 变量的作用域

变量的作用域决定了变量的可见范围：

```python
# 全局变量
global_var = 10

def my_function():
    # 局部变量
    local_var = 20
    print(global_var)   # 可以访问全局变量
    print(local_var)    # 可以访问局部变量

my_function()
print(global_var)       # 可以访问全局变量
# print(local_var)      # 错误：局部变量在函数外部不可见

# 修改全局变量
def modify_global():
    global global_var
    global_var = 30

modify_global()
print(global_var)       # 输出：30
```

### 变量的删除

使用`del`语句删除变量：

```python
x = 10
print(x)        # 输出：10
del x
# print(x)      # 错误：NameError: name 'x' is not defined
```

## 2.3 基本数据类型

Python的基本数据类型包括：数字、字符串、布尔值和空值。

### 数字类型

#### 整数（int）

Python 3中只有int类型，没有long类型，整数可以表示任意大的数值。

```python
# 十进制
a = 100
b = -50

# 二进制（前缀0b或0B）
binary = 0b1010       # 10

# 八进制（前缀0o或0O）
octal = 0o17          # 15

# 十六进制（前缀0x或0X）
hexadecimal = 0xFF    # 255

# 大整数
big_number = 123456789012345678901234567890
```

#### 浮点数（float）

浮点数使用IEEE 754双精度标准，精度约为15-17位有效数字。

```python
# 普通表示
a = 3.14
b = -0.5

# 科学计数法
c = 1.5e10      # 1.5 * 10^10
d = 2.5e-3      # 2.5 * 10^-3

# 特殊值
inf = float('inf')      # 正无穷
neg_inf = float('-inf') # 负无穷
nan = float('nan')      # 非数字
```

#### 复数（complex）

复数由实部和虚部组成，虚部使用后缀`j`或`J`表示。

```python
# 创建复数
a = 3 + 4j
b = complex(3, 4)

# 访问实部和虚部
print(a.real)       # 3.0
print(a.imag)       # 4.0

# 共轭复数
print(a.conjugate())    # (3-4j)

# 模
print(abs(a))       # 5.0
```

### 字符串（str）

字符串是Unicode字符的序列，使用单引号、双引号或三引号表示。

```python
# 单引号字符串
s1 = 'Hello'

# 双引号字符串
s2 = "World"

# 三引号字符串（多行）
s3 = '''This is
a multi-line
string'''

s4 = """This is also
a multi-line
string"""

# 原始字符串（不转义）
path = r'C:\Users\name'

# 字符串操作
s = "Hello, World!"
print(len(s))               # 字符串长度
print(s[0])                 # 索引访问：H
print(s[-1])                # 负索引：!
print(s[0:5])               # 切片：Hello
print(s[7:])                # 切片：World!
print(s.upper())            # 转大写
print(s.lower())            # 转小写
print(s.strip())            # 去除空白
print(s.split(','))         # 分割：['Hello', ' World!']
print(s.replace('World', 'Python'))     # 替换
print('Hello' in s)         # 成员检查：True
```

字符串格式化：

```python
name = "Alice"
age = 20

# %格式化（旧式）
s1 = "Name: %s, Age: %d" % (name, age)

# str.format()方法
s2 = "Name: {}, Age: {}".format(name, age)
s3 = "Name: {0}, Age: {1}".format(name, age)
s4 = "Name: {n}, Age: {a}".format(n=name, a=age)

# f-string（推荐，Python 3.6+）
s5 = f"Name: {name}, Age: {age}"
s6 = f"Next year: {age + 1}"
```

### 布尔值（bool）

布尔值只有两个取值：`True`和`False`。

```python
a = True
b = False

# 布尔运算
print(a and b)      # False
print(a or b)       # True
print(not a)        # False

# 比较运算
print(5 > 3)        # True
print(5 == 3)       # False
print(5 != 3)       # True
```

以下值被视为False：
- `None`
- `False`
- 数值零：`0`、`0.0`、`0j`
- 空序列：`''`、`[]`、`()`、`{}`
- 空集合：`set()`

### 空值（None）

`None`表示空值或缺失值，是`NoneType`类型的唯一值。

```python
result = None

# 检查是否为None
if result is None:
    print("Result is None")

# 检查是否不为None
if result is not None:
    print("Result is not None")
```

## 2.4 类型转换

Python提供了内置函数进行类型转换：

```python
# 转换为整数
int(3.14)           # 3（截断小数）
int("100")          # 100
int("1010", 2)      # 10（二进制转十进制）
int("FF", 16)       # 255（十六进制转十进制）

# 转换为浮点数
float(3)            # 3.0
float("3.14")       # 3.14

# 转换为字符串
str(100)            # "100"
str(3.14)           # "3.14"
str(True)           # "True"

# 转换为布尔值
bool(1)             # True
bool(0)             # False
bool("Hello")       # True
bool("")            # False

# 转换为复数
complex(3, 4)       # (3+4j)
```

## 2.5 类型检查

```python
# 获取类型
type(100)           # <class 'int'>
type("Hello")       # <class 'str'>
type([1, 2, 3])     # <class 'list'>

# 类型检查
isinstance(100, int)            # True
isinstance("Hello", str)        # True
isinstance([1, 2, 3], list)     # True
isinstance(100, (int, float))   # True（检查多个类型）
```

## 2.7 运算符

### 算术运算符

```python
a = 17
b = 5

print(a + b)        # 加法：22
print(a - b)        # 减法：12
print(a * b)        # 乘法：85
print(a / b)        # 除法：3.4（总是返回浮点数）
print(a // b)       # 整除：3
print(a % b)        # 取模：2
print(a ** b)       # 幂运算：1419857
print(divmod(a, b)) # 返回(商, 余数)：(3, 2)
```

### 比较运算符

```python
a = 5
b = 3

print(a == b)       # 等于：False
print(a != b)       # 不等于：True
print(a > b)        # 大于：True
print(a < b)        # 小于：False
print(a >= b)       # 大于等于：True
print(a <= b)       # 小于等于：False
```

### 赋值运算符

```python
a = 10
a += 5              # 等价于 a = a + 5
a -= 3              # 等价于 a = a - 3
a *= 2              # 等价于 a = a * 2
a /= 4              # 等价于 a = a / 4
a //= 2             # 等价于 a = a // 2
a %= 3              # 等价于 a = a % 3
a **= 2             # 等价于 a = a ** 2
```

### 位运算符

```python
a = 5       # 二进制：101
b = 3       # 二进制：011

print(a & b)        # 按位与：1
print(a | b)        # 按位或：7
print(a ^ b)        # 按位异或：6
print(~a)           # 按位取反：-6
print(a << 1)       # 左移：10
print(a >> 1)       # 右移：2
```

### 成员运算符

```python
lst = [1, 2, 3, 4, 5]

print(3 in lst)         # True
print(6 in lst)         # False
print(6 not in lst)     # True

s = "Hello, World!"
print("Hello" in s)     # True
```

### 身份运算符

```python
a = [1, 2, 3]
b = a
c = [1, 2, 3]

print(a is b)           # True（同一对象）
print(a is c)           # False（不同对象）
print(a is not c)       # True
print(a == c)           # True（值相等）
```

## 2.8 综合示例

```python
# 温度转换器
print("温度转换器")
print("1. 摄氏度转华氏度")
print("2. 华氏度转摄氏度")

choice = input("请选择（1或2）：")

def celsius_to_fahrenheit(c):
    return c * 9/5 + 32

def fahrenheit_to_celsius(f):
    return (f - 32) * 5/9

if choice == "1":
    c = float(input("请输入摄氏度："))
    f = celsius_to_fahrenheit(c)
    print(f"{c}°C = {f:.2f}°F")
elif choice == "2":
    f = float(input("请输入华氏度："))
    c = fahrenheit_to_celsius(f)
    print(f"{f}°F = {c:.2f}°C")
else:
    print("无效选择")
```
