# 第一章 Python概述与环境搭建

## 1.1 Python语言的历史与发展

Python由Guido van Rossum于1989年底开始编写，第一个公开发行版本于1991年发布。Python的设计哲学强调代码的可读性和简洁的语法，尤其是使用空格缩进来表示代码块，而非使用大括号或关键字。

Python的名称来源于英国喜剧团体Monty Python，而非蟒蛇。Guido van Rossum在开发Python时，希望创建一种介于C和Shell脚本之间的语言，既具有系统编程的能力，又易于学习和使用。

Python经历了三个主要版本的演进：

- **Python 1.x**：1994年发布，奠定了Python的基础语法和核心特性
- **Python 2.x**：2000年发布，引入了列表推导式、垃圾回收等重要特性，于2020年1月1日停止维护
- **Python 3.x**：2008年发布，不完全兼容Python 2，修复了语言设计中的许多缺陷，是目前的主流版本

Python 3的主要改进包括：
- print从语句变为函数
- 整数除法返回浮点数
- 字符串默认使用Unicode编码
- 统一了整数类型，取消了long类型

## 1.2 Python语言的特点

Python具有以下显著特点：

**简洁优雅**：Python语法简洁清晰，代码可读性高，使用缩进表示代码块，强制统一的代码风格。

**解释型语言**：Python代码不需要编译，直接由解释器逐行执行，便于快速开发和调试。

**动态类型**：变量类型在运行时确定，无需显式声明，提高了开发效率。

**面向对象**：Python支持面向对象编程，一切皆对象，包括函数、模块、数字、字符串等。

**丰富的标准库**：Python拥有庞大的标准库，涵盖文件处理、网络编程、数据库接口、图形系统等众多领域。

**跨平台**：Python可以在Windows、macOS、Linux等多种操作系统上运行。

**可扩展性**：Python可以调用C/C++编写的扩展模块，提高执行效率。

## 1.3 Python的应用领域

Python在以下领域有着广泛的应用：

**Web开发**：Django、Flask、FastAPI等框架使Python成为Web开发的热门选择。

**数据科学与人工智能**：NumPy、Pandas、Matplotlib、Scikit-learn、TensorFlow、PyTorch等库使Python成为数据科学和机器学习的首选语言。

**自动化运维**：Ansible、SaltStack等工具使用Python编写，用于服务器配置管理和自动化部署。

**网络爬虫**：Requests、Scrapy等库使Python成为编写网络爬虫的理想语言。

**科学计算**：SciPy、SymPy等库提供了强大的科学计算功能。

**桌面应用开发**：PyQt、Tkinter等库可用于开发跨平台的桌面应用程序。

**游戏开发**：Pygame等库可用于开发2D游戏。

## 1.4 Python解释器

Python是解释型语言，需要解释器来执行代码。主流的Python解释器包括：

**CPython**：官方的、使用最广泛的Python解释器，使用C语言实现。

**PyPy**：使用Python实现的Python解释器，采用JIT编译技术，执行速度比CPython快。

**Jython**：在Java虚拟机上运行的Python解释器，可以与Java代码互操作。

**IronPython**：在.NET框架上运行的Python解释器。

## 1.5 开发环境搭建

### 1.5.1 Python的安装

**Windows平台**：

1. 从Python官网（https://www.python.org）下载安装程序
2. 运行安装程序，勾选"Add Python to PATH"选项
3. 点击"Install Now"完成安装

**Linux平台**：

大多数Linux发行版预装了Python。如需安装或升级：

```bash
# Ubuntu/Debian
sudo apt-get update
sudo apt-get install python3

# CentOS/RHEL
sudo yum install python3
```

**macOS平台**：

macOS预装了Python 2.7，建议安装Python 3：

```bash
# 使用Homebrew
brew install python3
```

### 1.5.2 验证安装

打开命令行，执行以下命令验证安装：

```bash
python3 --version
```

正常输出应显示Python版本信息，如`Python 3.9.0`。

### 1.5.3 虚拟环境

虚拟环境用于隔离不同项目的Python依赖：

```bash
# 创建虚拟环境
python3 -m venv myenv

# 激活虚拟环境
# Windows
myenv\Scripts\activate

# Linux/macOS
source myenv/bin/activate

# 退出虚拟环境
deactivate
```

### 1.5.4 包管理工具pip

pip是Python的包管理工具，用于安装和管理第三方库：

```bash
# 安装包
pip install package_name

# 指定版本安装
pip install package_name==1.0.0

# 升级包
pip install --upgrade package_name

# 卸载包
pip uninstall package_name

# 列出已安装包
pip list

# 导出依赖
pip freeze > requirements.txt

# 安装依赖
pip install -r requirements.txt
```

### 1.5.5 集成开发环境

常用的Python集成开发环境包括：

**Visual Studio Code**：微软开发的轻量级编辑器，配合Python扩展插件可进行Python开发。

## 1.6 第一个Python程序

下面是一个经典的入门程序：

```python
print("Hello, World!")
```

### 代码解析

**print()**：Python的内置函数，用于向控制台输出内容。在Python 3中，print是函数，需要使用括号；在Python 2中，print是语句，不需要括号。

**"Hello, World!"**：字符串字面量，使用双引号括起来。Python也支持单引号字符串。

### 运行程序

保存上述代码到文件`hello.py`，然后执行：

```bash
python3 hello.py
```

运行后输出：

```
Hello, World!
```

### 交互式解释器

Python提供了交互式解释器，可以逐行执行代码：


## 1.7 Python程序的基本结构

一个完整的Python程序通常包含以下组成部分：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
模块文档字符串（docstring）
说明模块的功能和用法
"""

# 导入语句
import os
import sys
from datetime import datetime

# 全局常量
MAX_SIZE = 100
DEFAULT_NAME = "unknown"

# 函数定义
def greet(name):
    """函数文档字符串"""
    return f"Hello, {name}!"

# 类定义
class Person:
    """类文档字符串"""
    
    def __init__(self, name):
        self.name = name
    
    def say_hello(self):
        print(f"Hello, I'm {self.name}")

# 主程序入口
if __name__ == "__main__":
    # 程序入口点
    person = Person("Alice")
    person.say_hello()
    print(greet("World"))
```

### 代码解析

**Shebang行**：`#!/usr/bin/env python3`指定使用哪个解释器执行脚本，在Unix/Linux系统中有效。

**编码声明**：`# -*- coding: utf-8 -*-`指定源文件的编码，Python 3默认使用UTF-8编码，此行可省略。

**文档字符串**：使用三引号括起来的字符串，用于说明模块、函数、类的功能，可通过`__doc__`属性访问。

**导入语句**：使用`import`导入模块，使用`from ... import ...`从模块中导入特定对象。

**主程序入口**：`if __name__ == "__main__":`用于判断当前模块是否作为主程序运行，避免被导入时执行不必要的代码。

## 1.8 编程规范与PEP 8

PEP 8是Python的官方编码风格指南，主要规范包括：

**缩进**：使用4个空格进行缩进，不要使用Tab字符。

**行长度**：每行不超过79个字符，文档字符串或注释不超过72个字符。

**空行**：顶级定义之间空两行，方法定义之间空一行。

**导入**：导入语句应分行书写，按标准库、第三方库、本地库的顺序分组。

**命名规范**：
- 模块名：小写，可用下划线，如`my_module`
- 包名：小写，不建议使用下划线，如`mypackage`
- 类名：大驼峰命名法，如`MyClass`
- 函数名：小写，用下划线分隔，如`my_function`
- 常量名：全大写，用下划线分隔，如`MAX_SIZE`
- 变量名：小写，用下划线分隔，如`my_variable`
- 私有成员：以单下划线开头，如`_private_var`
- 强私有成员：以双下划线开头，如`__very_private`

**注释**：使用完整的句子，首字母大写，句末使用句号。行内注释与代码之间至少间隔两个空格。
