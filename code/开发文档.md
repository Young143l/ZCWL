# 第一章 需求分析

## 1.1 项目背景

### 1.1.1 行业现状分析

随着人工智能技术的飞速发展，编程教育正在经历深刻变革。传统的编程学习模式存在以下问题：

1. **学习资源碎片化**：学习者需要在多个平台之间切换，难以形成系统的知识体系
2. **实践场景缺失**：现有的学习平台主要提供代码片段练习，缺乏完整的项目实战环境
3. **个性化指导不足**：学习者的问题难以得到及时、精准的解答
4. **学习效果难以评估**：缺乏完整的学习轨迹追踪和效果评估机制

### 1.1.2 项目目标

本项目旨在构建一个**智码启行（CFWW）编程学习平台**，实现以下核心目标：

1. **智能化学习辅助**：通过RAG技术和AI问答，为学习者提供精准的文档问答服务
2. **真实项目驱动**：引入GitHub/Gitee真实项目，让学习者在工业级代码中学习
3. **完整代码生成**：AI不仅能生成代码片段，更能生成完整的、可运行的项目
4. **全链路学习追踪**：记录学习轨迹，生成学习报告，帮助学习者了解自己的学习状况

## 1.3 非功能需求

### 1.3.1 性能需求

1. **响应时间**：API接口响应时间不超过200ms
2. **并发支持**：支持至少100个并发用户
3. **AI响应**：流式输出首字响应时间不超过3秒

### 1.3.2 安全需求

1. **密码安全**：使用BCrypt加密存储
2. **认证授权**：JWT Token无状态认证
3. **输入验证**：所有输入参数进行校验
4. **账户保护**：连续5次登录失败锁定账户15分钟

### 1.3.3 可用性需求

1. **系统可用性**：保证7x24小时可用
2. **数据备份**：定期备份数据库
3. **错误处理**：完善的异常处理机制

## 1.5 用户操作流程图

### 1.5.1 用户注册登录流程

用户注册登录是用户进入系统的第一道关口，设计时需要兼顾安全性和便捷性。

**登录流程详解**：

1. **页面加载**：用户访问系统登录页面，系统展示登录和注册两个操作选项。

2. **登录操作**：用户输入邮箱和密码后，前端调用登录API发送请求。后端验证用户凭证，若密码错误，记录失败次数；若失败次数达到5次，锁定账户15分钟。验证通过后，生成JWT Token返回给前端，前端保存Token并跳转到首页。

3. **注册操作**：用户填写用户名、邮箱、密码后，前端调用注册API。后端验证数据有效性，创建新用户记录，自动登录并跳转到首页。

**安全机制说明**：

系统在登录环节实现了多层安全保护。首先，密码采用BCrypt算法加密存储，即使数据库泄露也无法直接获取用户密码。其次，系统实现了登录失败锁定机制，连续5次登录失败后账户将被锁定15分钟，有效防止暴力破解攻击。此外，JWT Token采用签名验证，确保令牌不可伪造。

### 1.5.2 文档学习流程

文档学习是本系统的核心功能之一，为用户提供系统的编程学习资源。

**文档学习流程详解**：

1. **文档浏览**：用户进入文档列表页面，可以按分类或标签筛选感兴趣的文档，点击文档卡片进入文档详情页。

2. **内容阅读**：左侧显示文档章节目录，右侧显示章节内容，用户可以选择任意章节进行阅读。

3. **学习计时**：进入章节时自动开启计时器，实时记录学习时长，离开页面时自动结束计时。

4. **AI问答**：用户可以在当前文档内容基础上提问，系统通过RAG技术检索相关文档片段，结合上下文调用AI生成回答，支持流式输出逐字展示。

5. **互动评论**：用户可以对章节内容发表评论，评论会通知文档作者，其他用户可以看到评论进行互动。

**RAG技术应用说明**：

当用户提问时，系统首先将问题转换为向量表示，然后在文档向量库中进行相似度检索，找到最相关的文本片段作为上下文。AI模型结合上下文和用户问题生成回答，这种检索增强的方式确保了回答的准确性和相关性，避免了AI幻觉问题。

### 1.5.3 GitHub项目导入流程

项目导入功能让用户可以导入真实的GitHub项目进行学习和分析。

**项目导入流程详解**：

1. **URL输入**：用户点击"导入项目"按钮，在弹出的对话框中输入GitHub仓库URL。

2. **URL验证**：系统首先验证URL格式是否有效，无效则提示用户重新输入。

3. **仓库克隆**：系统调用Git克隆工具获取仓库代码。

4. **云端存储**：克隆成功的代码被上传到七牛云对象存储，生成访问URL。

5. **数据库记录**：在PostgreSQL中创建项目记录，保存仓库信息和存储路径。

6. **异步分析**：系统启动异步任务分析项目，遍历项目文件生成文件树结构，识别项目技术栈，生成项目摘要和关键文件说明。

7. **结果展示**：用户跳转到项目详情页，查看分析结果。

**技术实现说明**：

项目导入采用异步处理模式，避免长时间阻塞用户界面。克隆过程在服务器端完成，代码文件通过七牛云SDK上传到对象存储服务。项目分析使用静态代码分析技术，通过文件扩展名和配置文件内容识别技术栈。

### 1.5.4 代码生成与运行流程

代码生成功能是本系统的特色之一，用户可以描述需求，AI生成完整可运行的项目代码。

**代码生成流程详解**：

1. **类型选择**：用户选择要生成的代码类型——前端项目或控制台项目。

2. **框架选择**：前端项目需选择前端框架（如React、Vue）和UI框架；控制台项目需选择编程语言（如Python、Java、C）。

3. **需求描述**：用户用自然语言描述想要的代码功能和效果。

4. **AI生成**：构建包含技术栈和需求的提示词，调用DeepSeek API生成代码。前端项目返回分离的HTML/CSS/JS代码，控制台项目返回单一代码文件。

5. **编辑完善**：代码保存到数据库后，用户在Monaco编辑器中查看和修改代码。可以继续向AI描述修改需求，AI基于上下文进行修改。

6. **运行测试**：前端项目在右侧实时预览HTML效果；控制台项目建立WebSocket连接执行代码。

**WebSocket执行说明**：

控制台代码通过WebSocket实现交互式执行。用户点击"运行"按钮后，前端与后端建立WebSocket连接，代码在服务器端隔离环境中执行，输出通过WebSocket实时推送给前端。用户可以输入数据，程序接收输入并继续执行。这种方式支持需要交互输入的程序。

### 1.5.5 学习追踪流程

学习追踪帮助用户了解自己的学习情况，记录学习时长和进度。

**学习追踪流程详解**：

1. **开始学习**：用户进入文档章节后，前端调用开始学习API，后端创建学习记录并保存开始时间。

2. **计时更新**：前端启动计时器每秒更新显示，记录用户的翻页、滚动、提问等行为。

3. **结束学习**：用户离开页面或点击"结束学习"时，前端调用结束学习API，后端计算实际学习时长。

4. **统计更新**：更新用户的学习统计表，增加累计学习时长，更新阅读章节数。

5. **进度保存**：若文档未读完，保存当前进度，下次进入时可从上次位置继续。

6. **报告生成**：根据学习数据生成学习报告卡片，展示累计学习时长、阅读文档数等统计信息。

### 1.5.6 通知消息流程

通知系统实现用户之间的互动提醒，保持信息同步。

**通知消息流程详解**：

1. **触发通知**：用户发表评论时触发通知，后端查询文档作者和相关用户，创建通知记录。

2. **实时推送**：若用户在线，通过WebSocket推送通知，前端显示未读徽标。

3. **通知查看**：用户点击通知图标获取通知列表（按时间倒序），显示通知内容摘要。

4. **详情与已读**：用户点击通知进入详情，后端标记通知为已读，更新用户未读计数。

**通知类型说明**：

系统支持多种通知类型，包括评论通知（新评论时通知作者）、回复通知（被回复时通知）

### 1.7.1 AI与教育的深度融合

# 第二章 概要设计

## 2.1 系统架构设计

### 2.1.1 整体架构图

![系统架构图](https://img.young143.top/2026/04/%E6%9E%B6%E6%9E%84%E5%9B%BE.png)

**架构说明**：

本系统采用前后端分离的现代化技术架构，通过清晰的层级划分实现了高内聚低耦合的设计目标。

**前端层**基于React 19构建，采用TypeScript进行类型安全开发，通过Vite构建工具实现快速开发和热模块替换。React 19引入了新的编译器架构和并发特性，能够自动优化组件渲染性能。TypeScript的静态类型检查可以在开发阶段发现潜在bug，提高代码质量。Vite采用ESM（ES Modules）开发时原生地支持即时热更新（HMR），大幅提升开发体验。

**网关层**使用Nginx作为反向代理服务器，主要实现三大功能：负载均衡将请求分发到多个后端服务实例；静态资源缓存减少重复请求对后端的压力；SSL终结处理HTTPS加密解密，减轻后端负担。

**业务服务层**采用Spring Boot微服务架构，包含用户服务、文档服务、项目服务、代码服务、学习服务、通知服务等核心模块。Spring Boot 4.0.1版本引入了对Java 23虚拟线程的支持，能够显著提高并发性能。每个服务专注处理特定业务领域，通过HTTP/RESTful接口进行通信。

**AI服务层**包含MCP服务和RAG服务两个核心组件。MCP服务负责项目代码分析和AI对话，采用FastAPI框架和LangChain Agent架构，通过MCP协议与七牛云服务通信。RAG服务负责文档向量化检索，调用阿里云百炼API进行文本嵌入。

**数据存储层**采用PostgreSQL作为主数据库，利用pgvector扩展支持向量存储和相似度检索，实现了文档问答的语义搜索能力。Redis提供缓存服务，存储热点数据和会话信息。对象存储使用七牛云Kodo服务，保存用户上传的项目文件。

**外部集成**方面，七牛云提供对象存储服务，DeepSeek和通义千问提供大语言模型能力，阿里云百炼提供文本嵌入服务。这些外部服务通过标准化API与系统集成。

## 2.2 数据库设计

### 2.2.1 设计原则

1. **规范化**：遵循数据库第三范式（3NF），消除数据冗余
2. **一致性**：使用外键约束确保引用完整性
3. **可扩展性**：预留适当的字段长度和扩展空间
4. **向量化支持**：利用PostgreSQL的pgvector扩展，在数据库层面原生支持向量存储和相似度检索

**核心实体分析**：

**用户（USERS）**是系统的核心实体，与多个实体存在一对多关联。每个用户可以创建多个项目（PROJECTS）、多个前端项目（SIMPLE_FRONTEND_PROJECTS）和多个控制台项目（CONSOLE_PROJECTS），进行多次对话（DIALOG），发表多条评论（DOC_COMMENT），接收多个通知（NOTIFICATIONS），拥有多条学习记录（LEARNING_RECORDS）和学习统计（USER_LEARNING_STATS）。

**文档（DOC）**与文档章节（DOC_CONTENTS）为一对多关系，每个文档可以有多个章节。章节支持评论和RAG向量化，通过DOC_RAG表实现语义检索能力。文档与标签（TAGS）通过DOC_TAGS中间表建立多对多关系，支持灵活的文档分类。

**问答（DIALOG）和问答详情（QUE_ANS）**实现了AI对话功能的历史记录。每个对话包含多次问答，通过d_id和times联合主键确保唯一性。CHAT_HISTORY表记录对话的完整聊天历史。

**项目（PROJECTS）、前端项目（SIMPLE_FRONTEND_PROJECTS）、控制台项目（CONSOLE_PROJECTS）**实现了代码生成功能的管理。前端项目分离存储HTML/CSS/JS代码，控制台项目存储单一代码文件。

**学习记录（LEARNING_RECORDS）和学习统计（USER_LEARNING_STATS）**实现了学习追踪功能。学习记录详细保存每次学习的时间信息，学习统计汇总用户的累计学习数据。

**标签（TAGS）**通过中间表与文档和用户偏好建立多对多关系，支持个性化推荐和内容筛选。

## 3.1 前端架构设计

本项目的前端采用React 19框架构建，使用TypeScript进行类型安全的开发。前端架构遵循组件化、模块化的设计原则，通过Zustand进行状态管理，实现了良好的代码组织和可维护性。

### 3.1.1 技术栈详解

**React 19 + TypeScript**：React 19是Facebook推出的最新前端框架，引入了新的编译器架构和并发特性，能够自动优化组件渲染性能。TypeScript的静态类型检查可以在开发阶段发现潜在bug，提高代码质量。两者结合提供了高效且安全的开发体验。

**Vite 7**：作为新一代构建工具，Vite采用ESM（ES Modules）开发时原生地支持即时热更新（HMR），大幅提升开发体验。生产构建时使用Rollup进行代码打包和tree-shaking优化，生成的bundle体积更小。

**Ant Design 6**：Ant Design是蚂蚁金服开源的企业级UI组件库，提供了丰富的React组件，涵盖表单、表格、弹窗、导航等常用场景。组件设计遵循一致性原则，开箱即用且易于定制主题。本项目使用青色（Teal）作为主题色。

**Zustand 5**：Zustand是轻量级的状态管理库，相比Redux更加简洁，无需编写大量的reducer和action。Zustand使用hooks API，支持状态持久化和中间件扩展，学习成本低，API直观。

**Tailwind CSS 4**：Tailwind CSS是原子化CSS框架，通过组合原子类名实现样式开发。优点是样式代码零冗余，开发效率高；缺点是HTML文件可能较长。配合VS Code的Tailwind插件可以提供智能补全。

**Monaco Editor**：Monaco Editor是VS Code的代码编辑器内核，支持语法高亮、代码补全、代码格式化等高级功能。本项目使用Monaco Editor实现在线代码编辑功能，为用户提供专业的代码编辑体验。

**前端路由配置说明**：

**主布局路由（MainLayout）**包含以下页面：

- **首页（/）**：展示系统概览和热门内容入口

- **用户中心（/user）**：用户个人信息和学习统计

**无布局路由（BlankLayout）**包含登录和注册页面，这些页面使用独立的空白布局，不显示导航栏和侧边栏。

## 3.5 关键算法设计

### 3.5.1 向量相似度计算

使用余弦相似度算法计算向量距离：

$$
\text{CosineSimilarity}(A, B) = \frac{\sum_{i=1}^n A_i \cdot B_i}{\sqrt{\sum_{i=1}^n A_i^2} \cdot \sqrt{\sum_{i=1}^n B_i^2}}
$$

PostgreSQL中使用`<=>`操作符计算余弦距离：

```sql
SELECT id, chunk, d_id, c_id, vector <=> CAST(:vector AS vector) AS distance
FROM doc_rag
ORDER BY vector <=> CAST(:vector AS vector)
LIMIT :limit
```

- 已连接（CONNECTED）：WebSocket通道建立成功，等待用户输入
- 运行中（RUNNING）：程序正在执行，实时推送输出
- 等待输入（WAITING_INPUT）：程序等待用户输入才能继续
- 已关闭（CLOSED）：连接已关闭，资源已释放

**代码执行器内部流程说明**：

代码执行器是系统安全运行用户代码的核心组件，设计时需要考虑隔离性、安全性和资源控制。

**流程详解**：

1. **环境创建**：接收到代码和语言类型后，在隔离的运行环境（如Docker容器）中创建执行环境。不同语言的代码在不同的运行时中执行，避免相互影响。

2. **超时设置**：为防止恶意代码（如死循环）占用资源，每个代码执行任务都设置了超时限制。默认超时时间为30秒，超时后强制终止进程。

3. **编译与执行**：对于需要编译的语言（如Java、C），先进行编译，编译失败则返回编译错误。对于解释型语言（如Python、JavaScript），直接进入执行阶段。

4. **管道通信**：创建三个管道分别处理标准输出、标准错误和用户输入。子进程的标准输出和错误输出通过管道传递给父进程，用户输入通过管道传递给子进程。

5. **输出处理**：根据输出类型进行不同处理。标准输出和错误输出实时发送到WebSocket，程序结束时收集退出码。

6. **资源清理**：执行完成后，清理进程和管道资源，关闭容器，确保不占用系统资源。

**安全措施**：

- 进程隔离：每个代码执行任务在独立进程中运行
- 资源限制：CPU时间、内存、文件句柄等都有严格限制
- 超时控制：防止无限循环占用系统资源
- 输入过滤：对用户输入进行安全检查，防止命令注入

## 5.3 Nginx配置

生产环境建议使用Nginx作为反向代理服务器，实现负载均衡、静态资源缓存和HTTPS终结。

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/ZCWL_front_end/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端API代理
    location /api {
        proxy_pass http://localhost:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    # WebSocket代理（支持代码实时执行）
    location /ws {
        proxy_pass http://localhost:8080;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }

    # MCP服务代理
    location /mcp {
        proxy_pass http://localhost:8001;
        proxy_set_header Host $host;
    }
}
```

**Nginx配置说明**：

此配置实现了四个主要功能：静态文件服务、API代理、WebSocket代理和MCP服务代理。WebSocket代理需要特殊配置Upgrade头，以支持HTTP协议升级。

本项目对社会的贡献体现在多个方面：

- **降低学习门槛**：通过AI辅助，让零基础用户也能入门编程。智能问答系统可以即时解答疑问，无需等待人工回复。

- **推动教育公平**：让优质学习资源触手可及，缩小城乡教育差距。欠发达地区的学习者也能获得高质量的编程教育资源。

- **助力人才培养**：为社会培养更多具备编程能力的数字人才，缓解数字经济时代的人才短缺问题。
