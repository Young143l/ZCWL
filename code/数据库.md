## 用户表

**用户表（users）：**用户 ID（u_id），用户名（name），邮箱（email），密码（password），头像（avatar），失败尝试次数（failed_attempts），锁定时间（lock_time），是否锁定（locked），角色（role）

**主键：**用户 ID（u_id）

```sql
CREATE TABLE users (
  u_id VARCHAR(20) PRIMARY KEY,
  name VARCHAR(20) NOT NULL,
  email VARCHAR(20) NOT NULL,
  password VARCHAR(255) NOT NULL,
  avatar TEXT,
  failed_attempts INTEGER DEFAULT 0 NOT NULL,
  lock_time TIMESTAMP(6),
  locked BOOLEAN DEFAULT FALSE NOT NULL,
  role VARCHAR(20) DEFAULT 'USER' NOT NULL
);
```



## 标签表

**标签表（tags）：**标签 ID（t_id），标签名称（name）

**主键：**标签 ID（t_id）

**唯一约束：**标签名称（name）

```sql
CREATE TABLE tags (
  t_id SERIAL PRIMARY KEY,
  name VARCHAR(20) NOT NULL UNIQUE
);
```



## 文档表

**文档目录表（doc）：**文档 ID（doc_id），文档名称（doc_name），简介（summary），图标（icon）

**主键：**文档 ID（doc_id）

**唯一约束：**文档名称（doc_name）

```sql
CREATE TABLE doc (
  doc_id SERIAL PRIMARY KEY,
  doc_name VARCHAR(255) NOT NULL UNIQUE,
  summary VARCHAR(255),
  icon VARCHAR(255)
);
```



## 文档章节表

**文档内容表（doc_contents）：**文档 ID（doc_id），章节 ID（chapter_id），章节名（name），内容（content）

**主键：**（文档 ID, 章节 ID）

**外键：**文档 ID（doc_id）依赖于 文档表（doc）的文档 ID（doc_id）

```sql
CREATE TABLE doc_contents (
  doc_id INTEGER NOT NULL,
  chapter_id INTEGER NOT NULL,
  name VARCHAR(20) NOT NULL,
  content TEXT NOT NULL,
  PRIMARY KEY (doc_id, chapter_id),
  FOREIGN KEY (doc_id) REFERENCES doc(doc_id) ON DELETE CASCADE
);
```



## 文档 - 标签关系表

**文档 - 标签关系表（doc_tags）：**文档 ID（doc_id），标签 ID（t_id）

**主键：**（文档 ID, 标签 ID）

**外键：**文档 ID（doc_id）依赖于 文档表（doc）的文档 ID（doc_id）

**外键：**标签 ID（t_id）依赖于 标签表（tags）的标签 ID（t_id）

```sql
CREATE TABLE doc_tags (
  doc_id INTEGER NOT NULL,
  t_id INTEGER NOT NULL,
  PRIMARY KEY (doc_id, t_id),
  FOREIGN KEY (doc_id) REFERENCES doc(doc_id) ON DELETE CASCADE,
  FOREIGN KEY (t_id) REFERENCES tags(t_id) ON DELETE CASCADE
);
```



## 用户 - 标签偏好表

**用户 - 标签偏好表（user_tag_preferences）：**用户 ID（u_id），标签 ID（t_id），偏好分（pre）

**主键：**（用户 ID, 标签 ID）

**外键：**用户 ID（u_id）依赖于 用户表（users）的用户 ID（u_id）

**外键：**标签 ID（t_id）依赖于 标签表（tags）的标签 ID（t_id）

**约束：**偏好分（pre）CHECK 约束，范围在 -100 到 100 之间

```sql
CREATE TABLE user_tag_preferences (
  u_id VARCHAR(255) NOT NULL,
  t_id INTEGER NOT NULL,
  pre INTEGER NOT NULL CHECK (pre >= -100 AND pre <= 100),
  PRIMARY KEY (u_id, t_id),
  FOREIGN KEY (u_id) REFERENCES users(u_id) ON DELETE CASCADE,
  FOREIGN KEY (t_id) REFERENCES tags(t_id) ON DELETE CASCADE
);
```


## 文档评论表

**文档评论表（doc_comment）：**ID（id），用户 ID（u_id），邮箱（email），父评论 ID（fa），内容（content），文档 ID（d_id），章节 ID（c_id），创建时间（created_at），更新时间（updated_at）

**主键：**ID（id）

**外键：**用户 ID（u_id）依赖于 用户表（users）的用户 ID（u_id）

**外键：**（文档 ID, 章节 ID）依赖于 文档内容表（doc_contents）的（文档 ID, 章节 ID）

```sql
CREATE TABLE doc_comment (
  id BIGINT PRIMARY KEY,
  u_id VARCHAR(255) NOT NULL,
  email VARCHAR(255) NOT NULL,
  fa BIGINT DEFAULT -1 NOT NULL,
  content TEXT NOT NULL,
  d_id BIGINT NOT NULL,
  c_id BIGINT NOT NULL,
  created_at TIMESTAMP(6) NOT NULL,
  updated_at TIMESTAMP(6),
  FOREIGN KEY (u_id) REFERENCES users(u_id),
  FOREIGN KEY (d_id, c_id) REFERENCES doc_contents(doc_id, chapter_id)
);
```



## 通知表

**通知表（notifications）：**通知 ID（n_id），文档 ID（d_id），章节 ID（c_id），用户 ID（u_id），发送者用户名（from_u_name），内容（content），时间（time），是否已读（read）

**主键：**通知 ID（n_id）

**外键：**用户 ID（u_id）依赖于 用户表（users）的用户 ID（u_id）

**外键：**（文档 ID, 章节 ID）依赖于 文档内容表（doc_contents）的（文档 ID, 章节 ID）

```sql
CREATE TABLE notifications (
  n_id SERIAL PRIMARY KEY,
  d_id INTEGER NOT NULL,
  c_id INTEGER NOT NULL,
  u_id VARCHAR(20) NOT NULL,
  from_u_name VARCHAR(20) NOT NULL,
  content TEXT NOT NULL,
  time TIME NOT NULL,
  read BOOLEAN DEFAULT FALSE NOT NULL,
  FOREIGN KEY (u_id) REFERENCES users(u_id),
  FOREIGN KEY (d_id, c_id) REFERENCES doc_contents(doc_id, chapter_id)
);
```
